# v67 사냥터 지형 업데이트

v66 전체 소스를 기준으로 초원·잊힌 광산·달잠 숲의 지형 표현과 이동 판정을 개선했습니다. Godot 4.7.2, 세로형 `PortraitMain.tscn`에서 사용합니다.

## 적용 내용

| 지역 | 지형과 분위기 | 실제 장애물 |
|---|---|---|
| 초원 | 손으로 그린 풀 바닥, 완만한 흙길, 얕은 연못과 물결, 나무 흔들림 | 기존 17개 위치 유지 |
| 잊힌 광산 | 청회색 암반 바닥, 통행 가능한 폐광 레일, 바위·수정, 지하 웅덩이 | 11개 |
| 달잠 숲 | 청록색 이끼 바닥, 달빛 숲길, 나무·수정, 물결과 작은 빛 입자 | 13개 |

- 바닥 그림은 길·연못·장애물이 없는 새 PNG 3종으로 제작하고, 지형 요소를 별도 배치했습니다. 신규 바위 PNG와 정확한 이미지 생성 프롬프트도 포함합니다.
- `FieldTerrainCatalog.gd`의 한 좌표 목록으로 전장, 소품, 미니맵, 길찾기를 구성합니다. 그림에 보이는 연못과 실제 물 진입 금지 영역이 일치합니다.
- 초원에만 적용되던 장애물 회피를 광산·숲까지 확장했습니다. 지역 변경 시 이전 경로와 장애물 캐시를 초기화합니다.
- 길을 곡선으로 연결하고 지면 경계를 여러 투명 레이어로 부드럽게 처리했습니다. 중앙과 양쪽 전투 공터를 확보했습니다.
- 나무·바위·수정은 발 위치를 기준으로 영웅과 앞뒤를 구분합니다. 살아 있는 영웅이나 공격 대상이 가려질 때 소품이 최대 32% 불투명도까지 흐려집니다.
- 세 지역 모두 맵 끝까지 카메라를 따라갈 수 있도록 주변 지면을 확장했습니다. 실제 이동 필드는 기존 32×20을 유지합니다.
- 미니맵에 지형·길·공터·카메라 범위를 표시하고, 지역 선택 카드에서도 동일한 지형과 소품의 축소 지도를 보여줍니다.
- 지형 도형을 지역별로 캐시하고 화면 밖 소품을 숨깁니다. 환경 효과는 0.08초, 미니맵은 0.15초 간격으로 갱신합니다. 이는 갱신 제한이며 휴대폰 성능 측정값은 아닙니다.

## 참고 자료를 반영한 방식

| 자료 | 반영한 설계 |
|---|---|
| [2DPIXX Forest Tileset](https://opengameart.org/content/forest-tileset) | 둥근 숲 소품, 영웅을 읽기 쉽게 하는 지면·소품 분리 |
| [Kenney UI Adventure](https://kenney.nl/assets/ui-pack-adventure) · [Fantasy UI Borders](https://kenney.nl/assets/fantasy-ui-borders) | 지도 테두리와 억제된 색상, 지도 위 정보의 대비 |

| [Better Terrain](https://github.com/Portponky/better-terrain) | 여러 표시 계층이 공통 지형 규칙을 사용하는 구조 |
| [GDQuest ARPG](https://github.com/gdquest-demos/godot-make-pro-2d-games) | 전투 공터, 장애물 우회, 배경 환경 효과의 분리 |

설계와 표현 방식을 참고했습니다. 외부 플러그인 설치나 외부 이미지·소스의 복사 없이 현재 프로젝트에 맞춰 구현했습니다. 지면과 바위는 새로 생성했으며, 나무·수정은 프로젝트의 기존 자산을 재사용합니다.

## 검증

Godot 4.7.2 headless에서 프로젝트 가져오기와 스크립트 파싱을 확인했습니다. 아래 결과는 화면 기하와 실제 게임 로직의 자동 검사입니다.

| 검사 | 결과 |
|---|---|
| V67 지형 길찾기 | 432/432, 경로 160개 완주 |
| V67 가림 처리·미니맵 | 14/14 |
| V67 지역 전환·10인 자동사냥 | 60/60, 360초·이동 57,071회 |
| V28 기존 길찾기 | 70/70 |
| V47 이동 회귀 | 248/248, 가변 프레임 이동 1,346회 |
| V53 근접 접근 | 12/12, 전투 접근 525개 |
| V60 초원 표시 | 24/24 |
| V61 3지역·역할·모션 | 596/596 |
| V49 글자·화면 기하 | 22,025/22,025, 화면 상태 159개 |
| V64 실시간 레이드 | 33/33 |
| V66 UI 필터 | 6/6 |

통합 검사는 10인 편성이 해금되는 스테이지 25, 레벨 35 파티로 지역별 120초씩 실행했습니다. 초원 33무리·광산 27무리·숲 24무리를 처치했고, 영웅·몬스터의 지형 관통 없이 반복 사냥을 진행했습니다. 네 모서리 카메라에서 지면 이미지의 표시 범위와 영웅·지형 좌표가 일치했습니다. 이는 모의 시간의 게임 로직 검사이며 실기기에서 6분 플레이한 성능 검사는 아닙니다.

`V58ArtScrollSmokeTest`에서는 지형 관련 항목은 통과했지만, 예전 스크롤 조건 2개(드래그 임계값 0 및 합성 터치 드래그)가 실패했습니다. 이번 작업은 v66의 기본 터치 스크롤 코드를 수정하지 않았으며, 이 검사를 전체 통과로 집계하지 않았습니다. 실제 디스플레이 렌더링 캡처와 휴대폰 터치·프레임 성능은 이번 환경에서 검증하지 못했습니다.

## 적용과 실행

1. v67 전체 프로젝트 ZIP을 새 폴더에 풉니다. 기존 프로젝트 위에 덮어쓰지 않아도 됩니다.
2. Godot 4.7.2에서 `project.godot`을 열고 새 이미지 가져오기가 끝나면 F5로 실행합니다.
3. 모험의 지역 선택에서 초원·광산·달잠 숲을 차례로 선택해 사냥을 시작합니다.
4. 그래픽 화면이 연결된 Godot에서 `tools/ui/V67_ActualMapCapture.tscn`을 열고 F6을 누르면 세 사냥터의 실제 플레이 화면 PNG가 저장됩니다.

개인 저장 데이터는 포함하지 않습니다. 장비·보상·영웅 스킬 수치와 저장 형식은 이번 지형 업데이트에서 변경하지 않았습니다.
