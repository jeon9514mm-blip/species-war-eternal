# 승인된 사냥 UI 적용

사용자가 확인한 화면을 반영했다. 오른쪽 원정대 패널을 없애고 전장을 화면 너비에 맞춰 확장했다. 하단 메뉴 높이는 90에서 52로 줄이고, 영웅별 체력·각성 게이지를 그 위의 한 줄에 배치했다. 10명 편성도 모두 보이며 영웅을 터치하면 기존 성장·장비 화면으로 이동한다.

배속은 상단의 작은 `×1 / ×2` 버튼이다. 편성·일시정지/재개·사냥 조작·전체 메뉴는 상단에 있고, 자동 스킬·궁극기와 오프라인 보상은 사냥 조작 시트에서 사용할 수 있다. 영웅이 없으면 게이지 자리에서 바로 편성을 열 수 있다. 다른 메뉴의 기존 모양은 유지한다.

최근 원격 커밋 `6491aec`의 보스 전장·레이드 UI를 보존해 통합했다. 통합 후 사냥 HUD·메뉴 상태·터치/스크롤·카메라·공격 판정·장비 우편 및 레이드 디자인·터치·전투 검사를 실행했다. **9개 검사 묶음, 3,213항목**이 통과했다. 검사 엔진은 Linux Godot 4.6.3이며 Android 실기기 측정은 아니다. RaidDesign 검사는 요구한 별도 임시 `art-pilot-raid-validation` 저장 경로에서 재실행했다.
