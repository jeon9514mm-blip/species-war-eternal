# 영웅 골격 동작 1차 — Godot 4.7.2

작업 브랜치: `work/hero-skeletal-actions`. 이전 맵 시안은 그대로 보관하고 영웅 표현을 개선했다. main 병합은 별도다.

## 변경한 동작 방식

기존 `PortraitHeroSkeletalRig`는 2D에서만 변형되고, 3D 전투 화면은 원본 아틀라스 프레임을 Sprite3D로 복사했다. 이제 사냥과 레이드 모두 **Skeleton3D + Skin + ArrayMesh**로 같은 골격과 가중치를 렌더링한다. Sprite3D는 기존 위치·발밑 그림자·체력바 연결을 위한 부모로만 남는다. 몬스터의 기존 프레임 표현은 유지한다.

- 영웅마다 **21개 관절**, **725개 정점**, 정점당 최대 **4개 정규화 가중치**.
- 뿌리·골반·몸통·가슴·머리·머리카락·망토, 양쪽 어깨·팔꿈치·손목·허벅지·무릎·발, 무기·보조 무기.
- 30명 전원에게 명시적인 체형·속도·동작 크기·무기 쪽·의상 흔들림 설정. 검방패·활·창·검·쌍검·마법·회복·포·투척·발톱·주먹 등의 동작 패턴을 공유하면서 영웅별로 조정한다. 480개를 각각 수작업으로 키프레임 제작한 것은 아니다.
- 28명은 기존 256px 전신 원화를 사용해 작은 액션 아틀라스의 확대 흐림을 줄인다. 레온하르트·발레리아는 기존 승인된 v37 아틀라스의 대기 원화를 사용한다. 이미지 파일 자체는 수정하지 않는다.
- 움직임은 고정된 원화와 바인드 포즈에서 생성한다. 프레임별 크롭·여백 차이와 기존 구워진 움직임의 중복 적용을 피한다.
- 3D는 GPU 스키닝. 영웅마다 별도 SubViewport를 만들거나 매 프레임 정점 버퍼를 다시 만들지 않는다.

## 16종 동작

| 동작 | 골격 표현 |
|---|---|
| 대기 | 호흡, 작은 머리·팔 움직임, 머리카락·망토 지연 |
| 걷기 | 교차 다리, 무릎·발 분절, 반대쪽 팔 흔들림 |
| 달리기 | 빠른 보폭, 상체 기울기, 더 큰 의상 흔들림 |
| 공격 1 | 준비 → 타격 → 후속 움직임 → 복귀 |
| 공격 2 | 다른 상체 회전과 팔 동작 |
| 스킬 | 역할별 무기·시전 팔 동작 |
| 궁극기 | 강화된 상체·무기 동작과 의상 흔들림 |
| 피격 | 짧은 상체·머리 반동 |
| 넉백 | 더 큰 반동과 표현용 몸통 이동 |
| 회피 | 무릎 굽힘과 옆으로 몸 피하기 |
| 방어 | 보조 팔을 올리고 자세 낮추기 |
| 강화 | 가슴·팔을 펴는 동작 |
| 약화 | 처진 자세와 손 떨림 |
| 승리 | 주무기 팔 들어 올리기 |
| 사망 | 시간에 따라 무너진 뒤 자세 고정 |
| 등장 | 낮은 준비 자세에서 일어나기 |

기존 `play_visual`과 공격·피격·상태 관찰 연결을 유지한다. `spawn`은 실제 사냥/레이드 진입 때 실행한다. 같은 공격이 반복되어도 이벤트 번호로 재시작하며, 0.075초 자세 혼합으로 전환한다. 게임 속도·일시정지·좌우 반전·피격 색·사망 투명도도 반영한다. 표현용 이동은 골격 내부에서만 일어나며 전투 좌표·피해·쿨다운·저장 로직은 수정하지 않는다.

## 확인과 재현

최종 검사: GDScript **376/376** 컴파일, 선택한 런타임 테스트 **5/5 (4,282개 확인)**, 아키텍처 정적 테스트 **12/12** 통과.

- `scripts/HeroSkeletalRigSmokeTest.gd`: 30명×16종, 가중치/역바인드, 단순 평행이동이 아닌 변형, 반복 재생, 정지, 사망 자세, 반전, GPU 관절 전달, 실제 사냥/레이드 연결.
- `V62RigFxRewardSmokeTest`, `V61FieldRolesMotionSmokeTest`: 골격과 보상·장비 회귀. V61은 폐기된 PortraitSky 탐색을 현재 3D 전장 확인으로 갱신했다.
- `V8364CombatViewSmokeTest`, `V836RaidBattleSmokeTest`: 화면 회전·카메라·실제 레이드 결과 집계.
- 전체 결과와 실제 Forward+ 캡처: `checks/hero-rig/`.

```sh
godot --headless --path . --script scripts/HeroSkeletalRigSmokeTest.gd
godot --path . --script tools/preview_hero_rigs.gd -- --roster
godot --path . --script tools/preview_hero_rigs.gd -- --video
```

`--video`는 대표 6명의 16종 동작을 `checks/hero-rig/captures/frames/`에 출력한다. 각 동작을 24프레임으로 정규화한 검토 영상이며 게임 내 공격 속도 측정용이 아니다. `--action=ultimate` 등으로 정지 화면도 출력할 수 있다. 원본 프레임 디렉터리는 Git에서 제외한다.

## 범위와 한계

현재 표현은 **2D 원화 기반의 골격 변형**이다. 입체 3D 캐릭터, 옆·뒷면 원화, 손가락 골격, 원화 뒤에 숨겨진 팔이나 다리를 새로 그리는 작업은 포함하지 않았다. 겹친 의상과 팔을 크게 벌리는 동작에는 한계가 있어 움직임 폭을 제한했다. 다음 미술 단계에서는 부위 분리와 가려진 부분의 원화 보충, 영웅별 관절 위치·무기 마스크 세부 조정이 적합하다.

엔진 검증은 Godot 4.7.2, 실제 화면은 소프트웨어 Vulkan Forward+에서 진행한다. Android 실기기 FPS·발열·장시간 메모리 측정은 아직 하지 않았다.
