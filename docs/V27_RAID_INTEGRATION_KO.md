# V27 영웅·성장·레이드 통합 검증

보스 루프와 새 영웅별 공격력 기반 스킬 공식, 성장 코드를 통합한 상태에서 추가 검증했다. 전체 레이드 기능을 중복 검증하기보다 두 담당 코드 사이에서 어긋날 수 있는 동작을 점검했다.

## 발견 및 수정 확인

컨트롤러라는 역할만 보고 모든 궁극기를 보스 시전 차단용으로 보존하는 문제가 있었다. 새 영웅 스킬에서는 루네아 궁극기는 공격 약화, 닉스·모르가스 궁극기는 취약 부여이므로 기절 면역이나 예고 대기와 관계없이 사용할 수 있어야 한다.

통합 담당이 `HeroCombatRules.ultimate_status`를 도입하고 실제 궁극기 효과가 기절인 경우에만 시전 차단을 위해 보존하도록 수정했다. 추가 테스트에서 세 영웅 모두 예고가 없는 상황에 준비된 궁극기를 사용하고 올바른 약화·취약 효과를 부여함을 확인했다.

## 실행 결과

Godot `4.7.2.stable.official.ed1daf0bf`, headless. 테스트마다 독립 `XDG_DATA_HOME`을 사용했다.

| 테스트 | 결과 | 확인 내용 |
| --- | --- | --- |
| `V27BossLifecycleSmokeTest.gd` | 51개 통과 | 영웅 공식 통합 후 기존 레이드 생명주기, 배속 일관성, 양 진영 × 3보스 종료 |
| `V27RaidIntegrationSmokeTest.gd` | 19개 통과 | 비기절 궁극기 예약 해제, 실제 스킬 차단·면역 연결, 실제 피해 기반 흡혈, 개별/전원 수호, 자연 패배와 무보상 |

추가 통합 테스트는 다음 실제 게임 경로를 사용한다.

- 카이렌·브론·울리크 자동 스킬이 보스 HP를 감소시키면서 현재 예고를 취소한다. 제어 면역 중에는 재차단을 위해 스킬을 낭비하지 않는다.
- 발레리아·베이라는 보스 잔여 HP 17, 높은 공격력, 취약 상태에서 실제 HP 17만큼만 피해를 주고 그 실제 피해에 해당하는 소량만 회복한다. 보스 사망 후 스킬 쿨다운을 소모하지 않는다.
- 레온하르트 스킬은 자신을, 오르윈 스킬은 살아 있는 10명 전원을 보호한다.
- 초기 3인 원정대가 숲 보스와 실제 전투하여 아우렐리아 13.4초, 녹스페라 7.1초에 패배했다. 패배 시 골드·경험치·클리어 횟수가 증가하지 않았다. 각 상황은 승패를 강제로 지정하지 않았다.

## 결과 해석의 범위

기존 lifecycle의 양 진영 10인 전투는 지역을 순서대로 진행하면서 경험치·장비를 획득하므로, 클리어 시간 차이를 순수한 진영별 밸런스 통계로 해석하면 안 된다. 추가 3인 테스트는 저성장 원정대의 실제 패배 경로와 정산 안전성을 확인한다. 이 테스트들만으로 실제 모바일 성능이나 출시 밸런스가 완성됐다고 판정하지 않는다.
