# v25 전투 FX / 범위 예고 / 카메라 임팩트

## 목표
v24 모바일 가로 전체화면 전투를 기반으로, 자동사냥이 단순 수치 교환처럼 보이지 않고 실제 액션 전투처럼 읽히도록 전투 피드백을 강화했습니다.

## 구현

### 실제 스킬/원거리 투사체
- 원거리 기본 공격과 공격형 스킬에 화면 좌표 기반 이동 투사체 적용
- 시작점은 영웅 위치, 도착점은 현재 타깃 몬스터 위치
- 포물선형 이동, 트레일, 도착 임팩트 링 포함
- 궁극기는 더 큰 투사체와 강한 카메라 임팩트 적용

### 범위공격 표시
- 광역 스킬/제어 스킬 발동 시 적 무리 중심에 AoE 원형 인디케이터 표시
- 버프/회복 계열은 영웅 주변에 별도 범위 표시
- 전투 판정과 연출 코드를 분리하여 FX 변경이 AI/데미지 계산에 영향을 주지 않도록 구성

### 보스 공격 범위 예고
- 기존 텍스트 DANGER 경고에 실제 붉은 공격 반경을 추가
- 발동 전까지 범위 원이 맥동
- 16:9 및 20:9 모바일 레이아웃 모두 대응

### 피격/회피 연출
- 몬스터/영웅 피격 시 순간 플래시와 임팩트 버스트
- 큰 피해에는 약한 카메라 흔들림
- 비탱커 영웅에게 낮은 빈도의 실제 회피 판정을 연결하고 `DODGE` 연출 표시
- 탱커/도발 상태는 회피 대신 기존 방어 판정을 유지

### 전투 카메라 임팩트
- 궁극기, 보스 경고, 큰 피해에 짧은 흔들림 + 미세 줌 펄스
- 지속적인 카메라 이동이 아니라 순간 피드백 방식이라 모바일 멀미와 HUD 흔들림을 최소화

## 구조
새로운 `CombatFxDirector.gd`가 시각 연출을 전담합니다.

- `projectile()`
- `aoe_indicator()`
- `boss_telegraph()`
- `impact()`
- `hit_flash()`
- `dodge()`
- `camera_impact()`

전투 판정은 기존 `Main.gd` 자동사냥/스킬 로직이 유지하고, 판정 시점에 FX Director를 호출하는 방식입니다.
