# v24 모바일 APK 화면 / 가로 전체화면 업그레이드

## 목표
세로 기기 화면 안에 16:9 게임을 축소해 넣는 프로토타입 표시 방식을 제거하고, Android APK에서 가로 전체화면을 기본으로 사용하는 모바일 게임 UI로 전환했습니다.

## 프로젝트 표시 설정
- 기준 해상도: 1280×720
- 모바일 방향: Landscape
- Stretch Mode: canvas_items
- Stretch Aspect: expand
- PC 개발용 강제 window override 제거
- 모바일 런타임에서 fullscreen 요청

## 화면비 대응
- 16:9에서는 기존 기준 화면 유지
- 19.5:9 / 20:9에서는 추가 가로폭을 전투 필드 확장에 사용
- 오른쪽 정보 HUD는 330~390 논리 픽셀 범위로 제한
- 전투 필드는 화면폭 증가에 따라 자동 확장
- Safe Area를 계산해 카메라홀/노치 쪽 인터랙션 여백 확보

## 전투 화면 변경
- 약 75% 전투 필드 / 25% 정보 HUD 구조
- 원정대가 화면 중앙 부근에 유지되는 카메라 추적형 투영
- 몬스터와 월드 오브젝트가 원정대 기준 상대 이동
- 넓은 화면에서 영웅/몬스터 크기 자동 확대
- 사냥터 설명을 압축하고 행동 버튼을 2열 모바일 터치 구조로 배치
- 전술 카드, 교전 대상 마커, 정예/광폭화 경고 유지

## 전투 판정 안전성
카메라 투영 변경이 실제 공격 판정 타이밍에 영향을 주지 않도록 자연 교전 시 별도의 formation settle timer를 사용합니다. 화면 표현과 전투 판정을 분리해 모바일 화면비 변경이 전투 결과를 바꾸지 않도록 했습니다.
