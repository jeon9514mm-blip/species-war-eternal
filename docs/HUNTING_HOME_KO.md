# 홈은 사냥 화면

진영과 출전 영웅이 저장되어 있으면 게임 실행 즉시 실제 자동사냥 전장으로 들어갑니다. 타이틀이나 원정대 캠프 요약에서 사냥 버튼을 다시 누를 필요가 없습니다. 저장된 진영·편성·지역·스테이지와 진행한 무리 수를 사용합니다.

하단 **홈**은 사냥 화면으로 연결되며 사냥 중에는 홈이 선택 표시됩니다. 영웅 화면의 뒤로 가기와 일반 메뉴 화면의 기본 뒤로 가기도 사냥으로 돌아갑니다. 출전 편성에서 돌아갈 던전이나 상세 화면이 지정된 경우는 기존 복귀 경로를 따릅니다. **원정 캠프** 요약은 전체 메뉴의 별도 항목으로 남습니다.

사냥 중 홈을 다시 눌러도 현재 전장을 재생성하지 않습니다. 적·영웅 HP, 무리, 타이머, 사냥 진행과 보상 잔액을 유지하며 사용자가 일시정지한 상태도 그대로 둡니다. 처음 시작하는 플레이어는 진영 선택을 거치고, 출전 영웅이 없으면 편성 화면으로 이동합니다. 더 최신 버전의 저장본은 기존 보호 안내로 보내 사냥을 시작하지 않습니다.

휴대폰에서 메뉴를 닫거나 이동할 때 엔진이 변환한 마우스 종료와 실제 터치 종료를 모두 처리할 수 있도록 닫힌 메뉴를 숨긴 뒤 프레임 종료에 삭제합니다. 이 과정에서 이미 분리된 입력 대상을 참조하던 오류를 함께 수정했습니다.

두 진영의 저장본을 실제로 다시 로드해 첫 화면·지역·스테이지·편성·실제 사냥 진행·반복 홈 입력·수동 일시정지·영웅 복귀·가방 복귀·기기 계속하기·캠프 메뉴·초기 설정·저장 보호를 검사했습니다. 새 검사 53개와 터치 51개, 영웅 메뉴 1,065개, 장비 팝업·저장 복구 163개, 통합 화면 119개, 게임 로직 133개 및 별도의 전투 조작 검사를 통과했습니다. 변경 스크립트 10개도 파싱을 확인했습니다.

이번 검사는 Godot 4.6.3 headless에서 실행했습니다. 프로젝트 기준인 4.7.2와 Android 실기기 검증, APK 빌드는 아직 진행하지 않았습니다. [검사 기록](../checks/hunting-home/validation.json)을 확인하세요.
