# 종의 전쟁 v31 · 영웅 30명과 스킬 120개 아트 적용

2026-09-23 · Godot 4.7.2 · v30 전체 UI 개편 위에 적용

사용자가 확인한 여섯 시안 보드를 바탕으로 영웅 30명의 초상화와 스킬 120개의 아이콘을 연결했습니다. 액티브 2개, 패시브 1개, 궁극기 1개의 구성과 기존 영웅 ID, 수치, 진영별 15명·딜러 8/방어·보조 4/디버프 3 구성은 유지합니다.

## 아트와 화면

- 영웅 목록, 상세, 도감, 소환, 편성·전투 HUD에서 개별 초상화를 사용합니다.
- 상세 화면의 네 스킬에 실제 스킬 ID와 연결된 아이콘을 표시합니다.
- 원본 시안 보드는 `assets/heroes/v31/`에 보존하고, 화면에서는 Godot의 AtlasTexture 영역으로 읽습니다.
- 기존 레온하르트·미라·오르윈·다리우스·카엘룸의 4방향 애니메이션은 유지합니다. 나머지 25명은 새 투명 배경 아틀라스의 대기·걷기 2장·공격 포즈를 연결합니다.
- 새 25명의 방향은 우측 사선 원화와 좌우 반전으로 처리합니다. 상하 전용 원화와 개별 프레임 피격·사망 원화는 이번 적용 범위에 포함되지 않습니다. 피격 색 변화와 사망 페이드는 엔진에서 처리합니다.
- 영웅은 기존 작은 전투 크기와 발 위치 기준을 유지하며, 실제 이동 사냥과 연결됩니다.
- 전투 아틀라스는 격자를 단순 등분하지 않고, 검증한 개별 영역과 발 중심점을 읽습니다. n01·n11 시트는 이미지 생성 도구로 여백을 교정했습니다. 원본 PNG의 픽셀은 코드로 편집하지 않았습니다.

## 적용된 스킬 시각 효과

실제 판정에서 사용한 적·아군 위치를 기록해 짧은 발동 효과를 표시합니다. 120개 아이콘과 영웅별 30가지 시각 모티프를 연결하고 액티브 1/2·궁극기별 형상·강도 차이를 둡니다. 예를 들어 카이렌의 별시계, 엘리시아의 새싹, 오르윈의 황금 방진, 루네아의 낮은 안개, 코르빈의 음파, 셀레네의 실 격자를 구분합니다.

패시브는 실제 발동 판정을 통과한 경우에만 표시합니다. 효과 끄기와 사냥 일시정지를 따르며 화면을 벗어나거나 수명이 끝나면 정리됩니다. 이 작업은 짧은 스킬 발동 연출의 적용입니다. 원안의 모든 지속 효과를 전용 프레임 애니메이션으로 제작한 버전은 아닙니다. 스킬 원안 전체는 `hero-design-v31.json`에 보존했습니다.

## 실행

전체 ZIP을 새 폴더에 풀고 `project.godot`을 Godot 4.7.2에서 열어 실행합니다. 첫 열기에서는 에셋 가져오기가 끝날 때까지 기다리세요. 영웅 → 상세 보기에서 초상화와 네 스킬을 확인할 수 있습니다. 모든 영웅은 기존 스테이지 해금 규칙을 유지합니다.

로그인은 기존 기기 저장 방식입니다. 이번 파일은 게임 소스와 아트를 포함한 Godot 프로젝트이며 APK 또는 독립 실행 파일이 아닙니다. PDF는 포함하지 않습니다.

## 검증

- 영향받은 회귀 검사 **11/11 통과**: 전투 조작, 기존 스프라이트, 영웅 스킬 구성, UI 흐름, 저장 복구 포함.
- 영웅 아트 검사 **9,264항목 통과**: 30명 초상화·120개 고유 아이콘·필드 아트·발 정렬·공격 종료·일시정지·사망 복구.
- 스킬 효과 검사 **740항목 통과**: 스킬 런타임 180회, 실제 자동사냥/레이드 A1 진입 60회, 패시브 30개. 효과 ON/OFF의 피해·체력·상태·쿨타임·런타임 상태 일치를 확인했습니다.
- 실제 영웅 화면 Control 배치 **994항목 통과**: 30개 상세 화면, 120개 아이콘, 텍스트·패널 겹침과 스크롤 접근성.
- 6개 신규 전투 시트의 120개 포즈에서 알파 값 10 초과 픽셀을 누락·중복·인접 캐릭터 혼입 없이 포함합니다. 원본 PNG 해시와도 일치합니다.
- 편집기 캐시와 기존 사용자 저장이 없는 별도 복제본에서 첫 가져오기와 영웅 아트 실행 검사 통과.
- 정적 리소스 검사와 Godot 4.7 호환 검사 통과. 영웅 수치 정의·전투 수식·저장 관련 기준 소스는 이전 버전과 같습니다.

상세 결과는 `v31-validation-summary.json`, `v31-art-validation.json`, `v31-atlas-integrity.json`, `v31-hero-ui-layout.json`에 있습니다. V28FieldFx의 종료 시점 경고는 과거 v29 결과에도 있던 경고이며, 독립 재실행에서는 재현되지 않았습니다.

아트 원본 6장은 직접 시각 검토했습니다. 게임 실행 화면의 실제 PNG 캡처와 실기기 터치·애니메이션 품질 확인은 완료하지 않았습니다. 헤드리스 배치·실행 검사는 실제 렌더 이미지 검수를 대신하지 않습니다.
