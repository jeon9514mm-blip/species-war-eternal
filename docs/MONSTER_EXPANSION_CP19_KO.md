# Unity CP19 · 사냥 무리 확대와 타락한 몬스터 원화

2026-10-09. 기존 30명·120스킬·10인 사냥·직접 이동 조이스틱·전용 레이드·고정 중심 배율을 유지한다.

## 실제 게임 변경

| 스테이지 | 한 무리 | 등장 방식 |
|---|---:|---|
| 1~499 | 24마리 | 지도 외곽의 서로 어긋난 두 줄 |
| 500~999 | 28마리 | 광맥 분위기, 드워프 비중 증가 |
| 1000 이상 | 32마리 | 숲 구간 하피 비중 증가, 이후 500마다 분위기 순환 |

기존 12마리 고정을 확장했다. 실제 Unity 플레이에 적용하며 원본 규칙 비교용 리뷰 모드는 12마리를 유지한다. 일곱 타락한 종족이 모든 구간에 등장하며 초원은 엘프, 광맥은 드워프, 숲은 하피의 빈도를 높인다. 사냥터 정보와 도감에 실제 수량·종족·스킬을 표시한다.

새 3종은 각각 별도로 생성한 RGBA 원화, 네 자세(대기·예비 동작·공격·이동), 발 기준점과 릴리프 메시를 사용한다. 새 포즈의 무기·깃털이 이웃 칸을 침범하지 않도록 참조 편집 후 검사했다. 게임에서는 1024 BC7 아틀라스와 ASTC 모바일 가져오기 설정을 사용한다.

| 새 몬스터 | 모습 | 실제 행동 |
|---|---|---|
| 타락한 오우거 | 회녹색 피부, 청동 중갑, 돌 곤봉 | 높이 2.65, 체력 +20%, 방어 +6, 느린 이동·1.9초 평타, 특수 전조 1.05초, 쇠약·250부터 기절 |
| 타락한 리치 | 해골 왕관, 보랏빛 로브, 청록 지팡이 | 높이 2.1, 사거리 3.6, 쇠약 저주, 500부터 4거리 안의 체력이 낮은 아군 회복 |
| 타락한 하피 | 붉은·검은 깃털, 청동 갑옷, 갈퀴 | 높이 2.2, 빠른 접근, 쇠약·250부터 3초 출혈 |

특수 공격은 기존 규칙과 같이 100부터, 평타 두 번 후 최소 8초 간격으로 사용한다. 전조 동안 직접 이동으로 사거리 밖에 나가면 공격이 취소된다. 오우거·하피의 몸 간격을 별도로 넓혀 등장과 이동 시 충돌을 검사한다. 개체수 증가로 초반 난이도가 갑자기 배가되지 않도록 실제 플레이의 기본 체력·공격은 기존 역할 수치의 80%로 조정했다(최소 체력 40, 공격 4 유지).

보상 처리의 기존 최대 12마리 제한을 스테이지별 실제 수량 상한으로 수정했다. 무리 골드·경험치는 기존 수치를 유지하고 장비는 처치한 개체마다 기존 드롭 규칙으로 추첨한다. 저장 재시도·중복 보상 거부·가방/우편 초과 보관을 유지한다.

- monster-population-cp19.json: 1,552개 비교. 여섯 스테이지·세 시드의 24/28/32마리, 일곱 종, 등장/이동 간격, 지도 경계, 실제 아틀라스·릴리프, 수량 초과 및 중복 보상 거부.
- monster-skills-cp19.json: 1,913개 비교. 일곱 종의 스테이지별 실제 상태/피해/전조/쿨타임, 흡혈, 출혈, 일시정지 및 리치의 실제 아군 회복 이벤트. 회복 테스트는 영웅 반격 피해와 회복량을 분리한다.
- hunt-world-cp19.json: 443,867개 비교. 네 진형에서 80초 연속 이동, 몸 간격·경계·자연 사냥 진행과 기존 스테이지 경계/저장 실패/장비 보관/우편/편성 규칙.
- 실제 Windows 빌드·입력 결과는 build-cp19.json, native-monster-cp19.json을 참조한다. 새 종의 원화가 도감과 전장에 나타나고 24마리 무리를 자연 처치하여 보상이 저장되는 것을 검사한다.
- 최종 build_61c8e0ea9e5e: 성공, 오류 0개, 기존 개발 연결용 Pipeline 실행 설정 경고 1개. 실제 Windows 입력 검수 30개 통과(약 33.44초). 위 도메인 검사와 합산 447,362개 비교이며 실행 프레임 수나 FPS를 뜻하지 않는다.
