2026-10-05. 기본 `PortraitMain.tscn`의 세 사냥터에 적용한다.

원본은 사용자가 공유한 Meta AI `SoulStrike_Patch_Pack.zip`이다.
공유 주소: https://www.meta.ai/share/a/3e2dbfa3-3554-49ef-9474-84eca77d7c8f
ZIP SHA-256: `684217f86e678eb0a1632798e956a35504283b09d15599668f2ee32399a47a9e`
원본에는 새로운 맵 이미지·모델이 없으며 카메라/렌더링 코드, 진형/이동 코드,
페이드 셰이더와 설명서가 있다. 코드 전체를 덮어쓰지 않고 최신 main에 시각적 변경을 통합했다.

## 실제 적용

- 사냥 카메라 기울기를 `(0,14,11)` 방향으로 조정하고 기존 직교 카메라의 자동 구도 계산을 함께 수정했다.
  전체 전장에서 높은 구조물이 잘리지 않도록 카메라 거리의 여유는 유지했다.
  FOV 15는 직교 투영에 영향을 주지 않으므로 원근 투영으로 바꾸지 않았다.
- 빙하/협곡에는 기존 바위, 마력 성역에는 기존 고사리 메시로 앞쪽 깊이감을 추가했다.
  고정된 배치와 기존 리소스만 사용하며 게임 RNG를 소비하지 않는다.
- 장식의 실제 화면 경계를 계산해 영웅·몬스터와 겹치면 투명도를 낮춘다.
  화면 가장자리의 장식에는 충돌이나 사냥 경로가 없다.
- 모바일에서 지원되는 일반 안개를 지역별 색으로 적용했다.
- 영웅의 실제 스킨 메시와 몬스터 빌보드가 사냥터 조명을 받는다.
  영웅 원화에는 약한 자체 발광을 더해 얼굴이 검게 잠기지 않도록 했다.
- 보행 중 높이 변화에 따라 접지 그림자 크기를 조정했다.

가로 화면, 기존 사냥 방식·진형·저장 데이터·장비 200칸·레이드 강도와 레이드 화면은 유지한다.
이전에 취소한 잔디 바닥 교체 작업은 포함하지 않는다.

## 원본에서 수정 또는 제외한 부분

누락된 `bush_lowpoly.glb` 참조, 카메라 거리를 측정하지 않던 페이드 셰이더,
모바일/저전력 모드의 강제 볼류메트릭 안개, 영구 투명한 발밑 링을 그대로 적용하지 않았다.
전투 간격·요격·이동을 바꾸는 두 파일은 맵 디자인 범위를 넘으므로 기존 최신 코드를 유지했다.

## 확인

Godot 4.7.2에서 카메라·좌표 변환, 저전력 모드, 가로 HUD, 독립 사냥, 레이드 표시
기존 회귀 테스트 5개를 실행했다: 2,068개 검사, 실패 0개.
로그는 `checks/map-patch-01/logs`에 있다.

실제 기본 게임 장면의 캡처는 `tools/capture_map_patch.gd`로 재현한다.
테스트 전용 저장 위치에서 3인 파티로 실제 자동사냥을 진행하며 배우 위치·체력·포즈를 꾸미지 않는다.
PC 소프트웨어 Vulkan의 Mobile 렌더러로 캡처하며 실제 안드로이드 기기의 FPS 측정은 포함하지 않는다.
