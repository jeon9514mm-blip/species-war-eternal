# 사냥 중 편성·메뉴·복귀 상태 수정

같은 사냥에서 영웅을 편성 해제했다가 다시 넣어도 체력 비율과 사망 상태, 두 스킬의 대기시간, 보호막과 궁극기 게이지를 유지합니다. 홈을 들렀다가 다시 편성하는 경로도 포함합니다. 재출전 시 취소된 시전과 이전 공격 목표는 이어서 실행하지 않습니다. 편성 변경은 수호신의 대기시간도 초기화하지 않습니다. 다른 사냥터나 새 전투로 전환할 때는 기존 콘텐츠 규칙대로 상태를 새로 만듭니다.

영웅 화면은 사냥으로 바뀐 골드·정수·레벨·경험치·능력치·연구 포인트·영웅 조각을 기존 컨트롤에 반영합니다. 승급·연구·돌파 버튼도 현재 조건으로 갱신합니다. 선택 영웅과 탭, 두 스크롤 위치, 키보드 포커스는 유지합니다. 저장 실패 또는 연습 중의 변경 제한은 계속 적용합니다. 장비 가방의 골드 표시도 열린 화면에서 갱신합니다.

메뉴를 열어 둔 채 앱을 중단했다가 돌아오면 보상 계산 후 안내를 보류하고, 사냥 홈으로 돌아왔을 때 한 번 표시합니다. 수동으로 일시정지한 사냥에서도 안내합니다. 홈을 반복해서 눌러도 팝업이나 지급이 중복되지 않으며, 캠프에서 먼저 수령하면 보류 안내를 취소합니다. 보상이 없는 짧은 중단에는 안내하지 않습니다. 보상 확인 버튼은 터치·변환된 마우스의 종료 처리가 끝날 때까지 입력 대상을 트리에 유지해 팝업 삭제 오류를 막습니다.

검사는 두 진영의 실제 보상 발생과 터치 편성·수령 경로, 반복 재편성, 성장 후 체력 비율 보존, 저장 실패 복구, 보상 중복 방지를 포함합니다. 관련 홈·영웅·저장·사냥·터치·레이드·연습 회귀 결과는 [검사 기록](../checks/hunt-menu-state/validation.json)에 있습니다. Godot 4.6.3의 headless 환경에서 검사했으며 Android 실기기·APK 및 프로젝트 기준 Godot 4.7.2 검사는 포함하지 않습니다.
