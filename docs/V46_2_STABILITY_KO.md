# v46.2 게임 오류 점검 및 소스 개선

검사일: 2026-09-28 / 기준: pixel-rpg-v46.1-typefix.zip / 엔진: Godot 4.7.2.stable.official.ed1daf0bf (Linux headless)

## 수정 결과

| 항목 | 원인과 수정 |
|---|---|
| 하단 메뉴 생성 중단 | PortraitIcon에 없는 ink 속성을 지정하던 코드를 제거. 실제 하단 메뉴 7개와 버튼 콜백 확인. |
| 구버전 저장 파일의 파티 축소 | v17 이전 저장 파일에서 기존 파티 슬롯 권한을 복원 전에 설정. 양 진영 3인 파티와 재저장·재실행 유지 확인. |
| 빈 편성 저장 시 프리셋 소실 | 출전 영웅이 있을 때만 프리셋 저장. 빈 편성은 기존 안내를 표시하며 이전 프리셋 유지. |
| 필터에 맞는 해금 영웅이 없는 자동 편성 | 편성 후보가 없으면 현재 파티를 유지하고 안내 표시. |
| HP 바 크기 | 테마와 스타일 적용 후 실제 크기를 지정해 작은 HP/궁극기 바가 기본 최소 높이에 묶이지 않도록 수정. |
| 전쟁 명령 패널 | 하단 메뉴 위 여백을 20px 추가해 기존 세로 화면 경계 검사 충족. |
| 최신 버전 임시 저장 보호 | 새 버전의 .tmp 저장 파일도 덮어쓰기 보호 대상으로 포함. 저장 실패 후 남은 유일한 데이터 보호. |

게임 실행 코드는 Main.gd, SaveStore.gd, PortraitHud.gd, PortraitMenus.gd, PortraitSkin.gd의 5개 파일을 수정했습니다. HeroRosterCatalog.gd, HeroKitRuntime.gd, HeroSpriteFactory.gd, project.godot은 원본과 바이트 단위로 동일합니다.

## 검사 결과

- 전체 GDScript: 160/160 실제 엔진 컴파일 통과.
- 기능 회귀 테스트: 최종 재검증 결과 84/84 통과. 전체 실행과 수정 후 대상 재실행 결과를 함께 기록합니다.
- 세로 화면: 80/80 항목 통과. 720×1280, 720×1440, 720×1560 화면 경계, 크기 변경 중 전투 상태 보존, 편성/성장/가방/소환/레이드/영토전 진입 포함.
- 추가 안정성 검사: 51/51 항목 통과. 양 진영의 10인 자동 편성, 저장/불러오기, 하단 메뉴 콜백, 구버전 저장 및 미래 버전 임시 파일 보호 포함.
- 현재 영웅 30명 × 동작 15종의 리소스와 프레임 경계, 방향 전환, 공격 완료, 일시정지, 사망 유지, 부활 표시 검사 통과.
- 기존 양 진영 10인 파티의 180초씩 총 360초 가상 전투, 전멸 후 복귀, 보상·성장·장비·스킬·레이드·영토전·저장 복구 검사를 실행했습니다.
- 코드의 괄호·리소스 참조·문서 링크 검사와 Godot 호환성 정적 검사 통과.

처음 실행한 기존 테스트는 62/81 통과했습니다. 나머지 19개를 모두 게임 오류로 집계하지 않았습니다. 기존 슬롯 제한을 반영하지 않은 테스트 파티, 현재 세로 화면과 다른 가로 화면 전제, 현재 SD 동작 대신 이전 픽셀 그림을 요구하던 검사, 저장 단계 초기화 누락 등이 섞여 있었습니다.

테스트 조건은 다음과 같이 수정했습니다.

- 과거 다인 전투 테스트는 원래 스테이지 난이도를 유지하면서 지원되는 구버전 슬롯 권한을 명시.
- 프리셋 테스트는 현재 진영별 저장 함수를 통해 준비.
- 이전 픽셀 이미지 검사는 보존된 이전 컨트롤러를 직접 검사하며, 별도 최신 애니메이션 검사에서 현재 팩토리를 검사.
- 세로/기존 가로 화면 비교는 각각 동일한 스테이지 진행량과 독립된 저장 경로 사용.
- 이동 검사는 고정 난수로 실행하고, 사거리 검사를 시작하기 전에 다음 몬스터 무리 생성 대기시간을 해제해 유효한 대상을 준비.

## 오류 재발을 줄이는 검사 흐름

run_tests.py 기본 실행에 모든 .gd 파일의 --check-only 검사와 실제 앱 시작 장면인 PortraitMain의 검사를 추가했습니다. 이전에는 편집기 가져오기만 성공해도 실행되지 않은 스크립트 오류를 놓칠 수 있었습니다. 시간 초과가 나도 그전에 발생한 오류 로그를 보존하도록 개선했습니다.

```sh
python tools/static_validate.py
python tools/run_tests.py --godot "Godot 실행파일의 절대경로" --jobs 4 --output test-results.json
```

플레이어 저장 데이터와 검사 데이터는 분리됩니다. 출력 JSON의 passed/total 및 syntax 결과를 확인하세요. 통과 문구가 있어도 SCRIPT ERROR나 ERROR:가 있으면 테스트 실행기는 실패로 처리합니다.

## 수정 패치 적용

패치는 v46.1 소스 기준입니다. 기존 프로젝트의 복사본에서 적용하세요.

```sh
git apply --check /경로/pixel-rpg-v46.2-stability.patch
git apply /경로/pixel-rpg-v46.2-stability.patch
```

압축을 푼 프로젝트의 project.godot과 scripts 폴더가 보이는 위치에서 실행합니다. 패치는 변경된 소스·검사 도구·실행 안내·이 문서를 포함합니다. 이후 Godot 4.7.2에서 project.godot을 열면 됩니다.

## 검증 한계

실제 Godot 엔진의 headless 실행 결과입니다. Android APK 빌드, 휴대폰 실기기 터치, GPU 화면 캡처, 발열·메모리 장시간 측정, 앱 강제 종료 중 저장 및 네트워크 실서비스 연동은 검사하지 않았습니다. 전체 기기의 모든 상황에서 오류가 없다는 의미는 아닙니다. 이번 수정에서 이미지 자산이나 영웅/스킬 밸런스는 변경하지 않았습니다.
