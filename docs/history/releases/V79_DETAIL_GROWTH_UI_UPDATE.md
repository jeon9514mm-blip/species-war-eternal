# 종의전쟁: 이터널 v79 — 상세/성장/소환 편의성 UI

## 목표
v79는 v78의 가방·편성·하단 5탭 개편을 이어서, 영웅 상세 / 장비 상세 / 영웅 성장 / 소환·돌파 화면을 같은 정보 구조로 통일합니다. 전투 수치, 성장 비용, 드롭, 저장 구조는 바꾸지 않습니다.

## 참고한 상용 UI 패턴
- 세븐나이츠 키우기의 편성 화면처럼 **현재 상태와 선택 가능한 카드가 동시에 읽히는 구조**를 유지하고, 상세 화면에서도 핵심 수치를 먼저 보여 준 뒤 행동 버튼으로 이어지게 했습니다.
- 쿠키런: 킹덤의 성장 포털처럼 **여러 성장 기능의 상태를 한눈에 요약하고 관련 화면으로 바로 이동**할 수 있게 영웅 상세의 빠른 작업을 묶었습니다.
- 모바일 RPG 공통 패턴인 **상태 → 주요 행동 → 세부 옵션** 순서를 적용해 긴 설명과 보조 기능이 1차 행동을 가리지 않게 했습니다.

## 영웅 상세
- 등급/역할/레벨과 현재 편성 상태를 상단에 고정된 정보 위계로 정리합니다.
- HP / 공격 / 방어를 3개 지표 카드로 분리해 한눈에 비교할 수 있게 합니다.
- `성장 연구 / 장비 가방 / 조각·돌파`를 **빠른 작업**으로 묶고, 선택 영웅 ID를 다음 화면까지 유지합니다.
- 스킬 4개를 2열 카드로 정리해 세로 스크롤 길이를 줄입니다.
- 장비, 연구, 승급, 돌파 정보를 분리해 장비 카드에 모든 성장 정보가 몰리지 않게 합니다.

## 영웅 성장
- 기존 드롭다운을 유지하면서 `이전 / 직접 선택 / 다음` 3단 선택 동선을 추가합니다.
- 사용 가능 포인트와 누적 연구 포인트를 먼저 보여 줍니다.
- 역할별 추천 연구(딜러=공격, 탱커=생존, 서포터/컨트롤러=기능)를 안내만 하고 자동 투자하지는 않습니다.
- 공격/생존/기능을 각각 독립 카드로 표시하고 단계, 효과, 진행도, 사용 버튼을 같은 위치에 배치합니다.

## 장비 상세
- 장비 이미지, 이름, 등급/부위/전투력, 장착 상태를 스크롤과 별개인 상단 영역에 유지합니다.
- 정보/강화/옵션/이식 탭 아래에 현재 탭의 목적을 짧게 표시합니다.
- 정보 탭에 `강화 / 옵션 / 이식` 바로가기를 추가합니다.
- 장착 전에는 선택 영웅의 현재 장비와 새 장비 전투력 차이를 `이전 → 이후 (+/- 차이)`로 표시합니다.
- 강화 탭은 현재 단계/현재 전투력과 강화 후 전투력을 먼저 비교한 뒤 비용과 실행 버튼을 보여 줍니다.

## 소환·돌파
- 수호신/영웅 조각 모드를 상단 2탭으로 분리하고, 보유 젬/레이드 정수를 먼저 보여 줍니다.
- 영웅 소환은 보장 게이지와 남은 횟수를 소환 버튼 바로 위에 표시합니다.
- 돌파 대상도 성장 화면과 같은 `이전 / 직접 선택 / 다음` 선택 방식을 사용합니다.
- 현재 돌파 / 보유 조각 / 필요 조각을 3개 지표로 나눠 돌파 가능 여부를 즉시 알 수 있게 합니다.
- 수호신 소환은 전설 이상 / 신화 보장 누적을 각각 지표와 진행 바로 표시합니다.

## 보존 사항
- v71~v77 전투·레이드·자동사냥·성장 시스템 유지
- v78 장비 가방 / 10인 편성 / 하단 5탭 내비게이션 유지
- 영웅/장비/수호신 데이터와 수치 변경 없음
- 저장 포맷 변경 없음
