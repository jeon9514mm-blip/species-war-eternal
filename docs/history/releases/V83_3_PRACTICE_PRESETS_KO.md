# v83-3 — 연습전 · 통합 프리셋 · 저장 안전성

## 변경 범위

### 1. 공통 저장 대기

`SaveSafety`가 실제 저장 상태를 관찰하고 공통 배너/재저장 동선을 제공합니다. 저장 실패 시 보상을 메모리에 유지하되 새 도전·소탕·연습·프리셋·진영 변경과 이전 저장 로드를 제한합니다. 일반 자동사냥도 저장 대기 중 진행을 멈춥니다. 재시도 성공 시 차단을 해제하며 보상을 다시 지급하지 않습니다.

이는 로컬 실패 처리입니다. 지속적인 장치 오류 중 강제 종료의 완전한 무손실, 서버 권한, 온라인 거래의 원자성을 보증하지 않습니다.

### 2. 초반 가이드 20단계의 날짜 제한 완화

1~4장(첫 20단계)의 일일 원정 누적 조건을 던전·탑·심연·레이드 합계 완료로 바꿉니다. 기존 목표 ID·순서·보상·수령 개수는 그대로입니다. 이미 받은 목표를 다시 지급하지 않습니다. 5장 이후 누적 일일 목표, 일일/주간 미션과 업적은 유지합니다.

신규 계정이 첫 20단계를 몇 분 안에 완료한다는 의미는 아닙니다. 성장/사냥/탑 조건은 여전히 필요합니다.

### 3. 무보상 연습전

일일 던전 3유형(1~3단계), 이미 도달한 층과 현재 도전 층, 이번 주 90게임초 심연을 기존 자동전투 엔진으로 실행합니다. 레벨·연구·장비·수호신은 현재 상태 그대로 사용합니다. 임시 레벨 부스트는 없습니다.

입장 전에 실제 저장에 성공해야 시작합니다. 전투 중 세이브 쓰기를 막고, 종료/이탈에는 시작 전 경제 상태를 복원합니다. 승리 영수증을 발급하지 않아 재화·경험치·입장 완료 횟수·소탕 해금·미션·최고 기록을 올리지 않습니다. 앱 중단/복귀에도 연습 중 오프라인 보상을 정산하지 않습니다.

실전과 동일한 피해 관찰 경로로 분석 보고서를 만들되 연습 전용 비교 이력을 사용합니다. 같은 진영/지역/콘텐츠/난이도끼리만 비교합니다. 편성·장비·배속 차이가 포함되고 난수 완전 결정성을 보장하지 않습니다. 최근 보고서 1개와 연습 비교 요약 최대 6개는 메모리 전용이며 앱 종료 시 사라집니다. 최근 보고서는 실전/연습 표식을 명확히 표시합니다.

### 4. 진영별 통합 프리셋

P1~P3에 영웅 명단/배치 순서, 3부위 장비의 영구 ID, 수호신, 자동 스킬·궁극기를 저장합니다. 아이템이나 강화 수치의 과거 사본을 복제하지 않습니다. 같은 장비가 이후 강화됐다면 현재 강화 상태로 적용됩니다. 레벨/연구/돌파는 저장·되돌림 대상이 아닙니다.

적용 전 전체 후보를 검증합니다. 부위·역할·진영·해금 슬롯, 중복 ID, 가방 공간, 옵션 선택 대기, 미보유 수호신, 분해/판매된 장비 등을 확인합니다. 대상 파티 안의 장비 이동은 하나의 동기식 변경으로 적용하고 단일 저장을 요청합니다. 대상 파티 밖 영웅의 장비는 자동으로 빼앗지 않고 사용자가 먼저 정리하도록 안내합니다.

미리보기와 실제 적용 사이 상태가 바뀌면 오래된 확인을 거부합니다. 재화는 소비하지 않습니다. 기존 명단 전용 프리셋도 유지하며, 통합 기록이 없을 때는 명단만 적용할 수 있습니다.

## 유지와 제한

- 원래 맵/영웅/몬스터 이미지·음원은 유지합니다. 계정/클라우드/온라인은 미구현·보류입니다.
- 별도 폰트 파일 없이 SystemFont 리소스를 사용합니다. 기기별 대체 글꼴과 한글 표시/레이아웃은 실기기 확인이 필요합니다.
- 세이브36에는 통합 프리셋 참조만 추가합니다. 기존 저장 파일을 백업하세요.
- 연구 재배분, 임시 레벨 동기화, 새 적 기믹, 레이드 분석 확장은 이번 범위가 아닙니다.
- 엔진/규칙/렌더링 검사 결과와 초기 실패/수정 내역은 별도 검증 보고서를 따릅니다. 실제 Android 및 모든 조합/장기 경제 검증은 별도입니다.
