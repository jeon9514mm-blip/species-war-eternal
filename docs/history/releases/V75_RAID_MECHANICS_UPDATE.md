# 종의전쟁: 이터널 v75 — 레이드 고유 기믹/성과 보상 강화

## 보스별 고유 기믹
- 회색 초원: 페이즈 2·3에서 **대지 갑주/거목 철갑** 보호막을 전개합니다. 보호막을 파괴하면 3~3.5초 약점 노출이 발생합니다.
- 잊힌 광산: 페이즈 2·3에서 **광맥 수정핵 2~3개**가 보스를 대신 맞고 주기적으로 후열을 폭격합니다. 수정핵을 먼저 제거해야 보스 HP를 다시 깎을 수 있습니다.
- 달잠 숲: 페이즈 2·3에서 **월식 DPS 체크**가 시작됩니다. 제한 시간 내 요구 피해를 달성하면 3초 약점 노출, 실패하면 보스 회복과 공격 압박이 상승하며 3페이즈 실패 시 즉시 광폭화합니다.

## 공통 전투 개선
- 보스 예고 공격에 0~100% **차단 게이지**를 추가했습니다. 짧은 제어 효과는 게이지를 누적하고, 충분한 제어가 모이면 공격을 차단합니다. 기존 0.8초급 제어는 한 번에 차단되도록 기존 영웅 성능을 보존했습니다.
- 보호막 파괴, 수정핵 제거, 월식 의식 파훼 시 보스 약점 노출과 전투 FX가 발생합니다.
- 모바일 레이드 상태창에서 현재 기믹과 차단 진행도를 확인할 수 있습니다.

## 보상/성장 동기
- 기본 레이드 정수 보상은 그대로 유지합니다.
- 실제 전투에서 보호막 파괴/수정핵 제거/DPS 체크 성공/패턴 차단을 수행하면 **성과 레이드 정수 보너스(최대 +12)**가 추가됩니다.
- 강제 승리나 기믹을 수행하지 않은 테스트/정산은 기존 기본 보상과 동일합니다.

## 호환성
- 신규 상태는 모두 전투 중에만 존재하는 runtime 변수입니다. 저장 스키마는 변경하지 않았습니다.
- v71 자동사냥, v72 전투 연출, v73 역할 AI, v74 보스 패턴/텔레그래프를 유지합니다.
