# 종의전쟁: 이터널 v74 — 보스/레이드 AI 및 패턴 강화

## 핵심 변경
- 3개 지역 보스가 각 페이즈에서 **2개의 패턴을 결정론적으로 교대**합니다. 같은 기술만 반복하던 구조를 제거했습니다.
- 신규 위험 구역 기하: **부채꼴(cone), 십자(cross), 이중 통로(double lane)**. 화면 텔레그래프와 실제 피격 판정이 같은 `RaidBattlefield` 데이터를 사용합니다.
- 회색 초원: 원형 충격/연속 지진 + 전방 파쇄/십자 균열을 교대.
- 잊힌 광산: 전열·후열 교대 표적 + 단일/이중 낙석 통로와 십자 수정 폭쇄.
- 달쉼 숲: 낮은 체력 영웅 추적 + 흡혈 저주, 2~3중 표식, 부채꼴 추적.
- 지역별 기본 공격 타깃 성향 분리: 초원은 전열, 광산은 전·후열 교대, 숲은 부상자 압박. **도발은 항상 최우선**입니다.
- 레이드 포지셔닝을 v73 역할 AI와 연결: 탱커 전열, 근접 딜러 측면, 원거리 거리 유지, 서포터 후열, 컨트롤러 측면 캐스팅 레인.
- 2차 지진을 포함한 후속 파동에도 역할별 반응 시간으로 자동 안전지대 이동이 작동합니다.
- 페이즈 전환 시 패턴 순서를 리셋하고 다음 공격까지 짧은 준비 시간을 부여합니다.
- 세로 레이드 화면에 PHASE/광폭화 배너와 다음 패턴 정보를 추가했습니다.

## 보존 사항
- 영웅/장비 스탯, 드롭 확률, 보상량, 세이브 구조는 변경하지 않았습니다.
- v71 사냥 흐름, v72 전투 연출, v73 역할별 필드 AI를 유지합니다.
- 기존 회피 버튼, 수동 이동, 수동 스킬/각성, 제어 차단 시스템은 유지합니다.
