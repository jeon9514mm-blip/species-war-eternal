# v82-1 실제 Godot 검사 재현

사용자가 이미 제공한 표준 Linux x86_64 Godot4.7.2를 사용했습니다. 엔진을 다시 업로드할 필요가 없습니다.

```sh
python3 tools/run_v82_runtime_checks.py --godot /path/to/Godot_v4.7.2-stable_linux.x86_64 --output /tmp/v82-results.json
```

임시 전체 프로젝트/고유 앱명/테스트별 XDG데이터로 플레이어 저장과 소스를 격리합니다. 이번 실행은 임포트와 GDScript280개 컴파일 검사, 집중 스크립트29개를 수행했습니다. 이후 수정한 시험12개는 재컴파일했고, 게임 코드와 나머지 시험은 SHA가 동일함을 확인했습니다. 최종 결과는 시험별 마지막 성공 결과를 합친 것으로 최초 시도 실패/수정 로그도 별도 보존합니다. 등록된158개 전체 테스트가 아닙니다. `--test`는 선택 실행, `--skip-compile`은 미실행을 명시합니다. `--import-cache`는 동일 엔진의 캐시를 선택적으로 복사하지만 리소스를 엔진에서 다시 검사합니다. 최종 검증에는 이 캐시 옵션을 사용하지 않았습니다.

소리 파일의 실제 디코딩/AudioStreamPlayer 호출은 엔진에서 확인했지만 Headless/Dummy출력은 물리적인 사운드/진동 체감 검사가 아닙니다. Android 내보내기와 실기기 성능 검사는 별도입니다. 소프트웨어 OpenGL 가상 화면에서 설정배치/FPS상한7조건도 별도로 검사했으며 VSync드라이버 경고를 기록했습니다.

오류 로그/완료표식 누락/시간초과/비정상종료는 실패로 기록합니다. 테스트별 로그를 삭제해 실패를 숨기지 않습니다. 자세한 최초 오류/수정/한계는 V82_1_PRESENTATION_KO.md를 확인하세요.
