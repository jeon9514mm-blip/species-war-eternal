# v83-3 실행 안내

## 열기

1. 기존 프로젝트와 플레이어 저장 파일을 별도로 보관합니다.
2. `species-war-eternal-v83-3-full.zip`을 **새 폴더**에 풉니다. 이전 폴더에 덮어쓰거나 이전 누적 패치를 다시 적용하지 않습니다.
3. Godot 4.7.2 일반 에디터에서 안쪽 `species-war-eternal-v83-3/project.godot`을 가져옵니다.
4. 첫 이미지·음원 임포트가 끝나면 F5로 실행합니다. 시작 씬은 `scenes/PortraitMain.tscn`입니다.

이 ZIP은 게임 전체 소스이며 APK/엔진/폰트 바이너리가 아닙니다. 별도 글꼴 파일 없이 기기의 SystemFont 대체를 사용합니다.

## 이번 기능 찾기

`메뉴 → 던전 → 전투 연습실`: 일일 던전 3종, 이미 도달한 탑 층, 이번 주 심연을 무보상으로 연습합니다.

`메뉴 → 던전 → 통합 전투 프리셋`: 현재 편성·장비 ID·수호신·자동 스킬/궁극기를 진영별 P1~P3에 저장합니다. 적용 확인 화면은 누락 장비와 다른 영웅의 장착 충돌을 알려줍니다. 기존 영웅 편성의 P1~P3도 연결되어 있습니다.

연습전은 현재 레벨/장비를 사용합니다. 임시 레벨 동기화·연구 재배분은 추가하지 않았습니다. 연습 결과와 실전 최고 기록은 별개입니다.

## 저장 주의

게임 저장 버전은 **35 → 36**입니다. 이전 명단형 프리셋과 성장·재화·목표 기록은 유지하며, 통합 프리셋은 처음 직접 저장해야 합니다. 이전 버전으로 되돌릴 때는 그 버전에서 보관한 저장 파일을 사용하세요.

저장 대기 배너가 표시되면 다음 도전/소탕/프리셋 변경/이전 저장 불러오기가 제한됩니다. `다시 저장`은 현재 기록을 파일에 쓰는 기능이며 보상을 다시 지급하지 않습니다. 저장장치 오류가 지속되는 동안 앱을 강제 종료하면 메모리에만 남아 있는 진척은 유실될 수 있습니다.

## 개발 검사

```sh
python3 tools/run_v83_3_runtime_checks.py --godot /path/to/Godot_v4.7.2-stable_linux.x86_64 --workers 3 --timeout 600 --output /tmp/v83-3-results.json
```

Windows는 Python으로 실행하고 `--godot` 뒤에 Windows Godot 콘솔 실행 파일의 절대경로를 사용합니다. 실행기는 임시 프로젝트와 별도 사용자 데이터 공간에서 검사합니다. 실제 Android FPS·발열·터치·청취는 별도입니다.
