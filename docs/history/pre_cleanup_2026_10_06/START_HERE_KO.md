# v83-6.5 실행 안내

1. GitHub Desktop에서 저장소를 Clone하거나, 전체 소스 ZIP을 새 폴더에 풉니다.
2. Godot **4.7.2 일반 에디터**에서 `project.godot`를 가져옵니다.
3. 첫 리소스 임포트가 끝나면 **F5**로 실행합니다. 시작 씬은 `scenes/PortraitMain.tscn`입니다.
4. 맵만 확인하려면 `scenes/MapGallery.tscn`을 열고 **F6**를 누릅니다.

이 프로젝트는 소스이며 APK나 Godot 엔진 자체는 포함하지 않습니다. 이미지·음원·재질·3D 씬은 포함하고 `.godot` 임포트 캐시는 각 컴퓨터에서 생성합니다. PC 기본 렌더러는 Forward+입니다.

## 조작

- 사냥 화면의 **진형**: 균형 / 돌격 / 방벽 / 속공
- 전투 화면 오른쪽 위 **전장 보기 / 전투 보기**: 맵 전체와 부대 중심 확대 전환
- 메뉴의 **화면·소리·진동·성능 설정 → 화면 방향**: 세로 / 가로 / 기기 회전
- 갤러리: 1–4 또는 버튼으로 맵 변경, 왼쪽 드래그로 회전, 휠로 확대·축소

## 게임 저장과 코드 저장

게임 저장 버전은37입니다. 기존 성장·장비·재화를 유지하고 진형 값을 추가합니다. 화면 방향은 기기 로컬 설정에 저장합니다. 저장 실패 시 사냥을 멈추며, **다시 저장**은 보상을 중복 지급하지 않습니다.

**GitHub는 개발 소스를 동기화합니다. 플레이 진행도·재화·기기 설정은 자동으로 옮기지 않습니다.** 플레이 저장 위치는 실행 환경의 Godot `user://` 경로입니다. Godot 에디터의 **프로젝트 → 사용자 데이터 폴더 열기(Open User Data Folder)**에서 확인할 수 있습니다. 진행도를 옮길 때는 양쪽 게임을 종료하고 대상 저장 폴더를 백업한 뒤 별도로 복사하세요. 개인 플레이 저장은 이 저장소에 추가하지 않습니다.
