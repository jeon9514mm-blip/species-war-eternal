3. 첫 리소스 임포트가 끝나면 F5로 실행합니다. 시작 씬은 `scenes/PortraitMain.tscn`입니다.

그림·음원은 기존 것을 유지했고, `.godot` 임포트 캐시는 배포에서 제외했습니다.

- **사냥 화면 → 진형**: 균형 / 돌격 / 방벽 / 속공을 선택합니다.

- 가로 사냥 화면은 전장과 영웅·조작 패널을 좌우로 배치합니다.
- 다음 적 부대는 잔여 5마리 이하, 이전 진입 후 4게임초, 2부대·25마리 상한을 모두 만족할 때 들어옵니다.
