# v83-5 탑·심연 공략 및 진영전 개선

## 이번 구현
- 탑 1~9층 보존. 10층부터 마지막 무리에 회복 지원/차단 가능 강타/분산 진형 순환.
- 심연 첫 우두머리 보존. 두 번째 무리부터 해당 주의 패턴을 적용. 기존 주간 수치 변칙과 보상 유지.
- 회복 지원은 4초 간격, 지원몹당 최대3회, 우두머리 최대HP4% 회복. 사망/귀환/거리 검사.
- 강타는 2게임초 준비, 유효 기절로 차단, 고정 대상이 사거리 밖이면 불발. 기본 공격의 2배 단일 타격, 기존 방어/보호/회피 처리 사용. 화면 경고가 판정과 같은 게임 시간을 사용.
- 분산 진형은 현 이동 가능 영역 안에서 기존 팩을 펼침. 신규 지도/몬스터 그림 없음.
- 심연 추가 부하는 기존 개체 HP/공격 예산을 분배. 회복된 HP 재공격은 실효 피해 점수에 중복 반영하지 않음. 지원몹 HP도 기존 총예산 안에서 집계하고 전체 무리를 처치해야 다음 개체.
- 탑/심연 입장과 연습실에 패턴/대응 설명. 분석 비교키에 패턴ID+규칙버전.
- 진영전은 정찰/실제 교전의 전술·피로·부상·지형 보정 계산 공유. 전력 합계는 승리 예측 보장이 아님. 여러 수비대 순차 교전/타깃/회복에 따라 결과는 다름.
- 출정 직전 편성/전술/부상/경로/수비대/자원/기간을 재확인. 이전 확인창·중복 클릭으로 새 명령 실행 방지.
- 자원 확보/끊긴 보급 연결/요새 공략별 추천은 목표 선택만 하며 자동출정 없음.
- 보고서에서 현재 부대 위치의 수비 등록/귀환/다음 목표로 연결. 과거 전투 좌표에 자동 명령하지 않음.

## 보존 및 의도된 변경
연구/레벨/재화/보상 산식/저장36과 그림/음원은 유지. 새 패턴은 전투 행동/난이도를 바꾸므로 밸런스가 전혀 바뀌지 않았다고 표현하지 않음.
기존 주간 최고점은 지우지 않음. 이전 패턴으로 얻은 저장 최고점은 동일조건 비교로 보지 않으며 화면에 안내. 실행 중 보고서는 패턴 버전을 구분.
진영전은 로컬 권한/NPC 구조 개선이며 온라인 PvP 서버/계정/길드 구현 아님. 자동 영토 침공/오프라인 영토 손실 규칙 추가 없음.
