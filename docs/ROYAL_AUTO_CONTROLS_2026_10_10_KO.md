# 사냥 HUD 자동 전투·배율 조작

사용자가 표시한 기존 ×3 위치의 원형 버튼 하나로 ×1 → ×1.5 → ×2 → ×3 → ×1을 순환합니다. 배율은 카메라 확대이며 전투 속도를 변경하지 않습니다.

왼쪽부터 **자동사냥 AUTO · 각성기 AUTO · 스킬 AUTO · 배율**입니다. 상단 오른쪽의 기존 AUTO는 제거했습니다. 현재 지도·영웅 외형과 사냥·영웅·레이드·던전·진영전·가방 하단 메뉴는 그대로 사용합니다.

- 자동사냥은 추적 이동과 자동 일반 공격을 켜고 끕니다. 꺼도 적 행동·전투 시간과 직접 이동은 계속됩니다. 다시 켜면 조이스틱 수동 이동 모드를 해제합니다.
- 스킬은 일반 스킬 a1/a2 자동 사용, 각성기는 ultimate 자동 사용을 각각 제어합니다. 수동 스킬 버튼은 이 설정에 영향을 받지 않습니다.
- 일반 전투 설정은 저장 후 재실행해도 유지됩니다. 기존 저장은 자동사냥 ON을 기본으로 읽습니다. 패턴 훈련과 연습은 실제 계정 설정을 덮어쓰지 않습니다.
- 해당 자동 설정을 끄면 대기 중인 해당 종류의 자동 공격도 다음 전투 틱에 취소합니다.
- 레이드에도 세 AUTO 설정을 연결했습니다. 기존 레이드 전용 카메라를 보존해 배율 버튼은 사냥에서 표시합니다.
- 화면이 좁아 선택 영웅 정보와 겹칠 경우 AUTO·배율 줄을 한 줄 위로 올립니다.

Unity Play 모드에서 자동 설정 저장·복원, 독립 토글, 수동 이동·스킬, 레이드, 준비 중 공격 취소, 배율 순환, 실제 HUD 배치 등 23개 확인 항목을 통과했습니다. 실제 Unity GameView 촬영은 별도 로컬 검수 자료입니다. 기존 0.1.21 APK는 이번 수정이 들어간 새 빌드가 아닙니다.
