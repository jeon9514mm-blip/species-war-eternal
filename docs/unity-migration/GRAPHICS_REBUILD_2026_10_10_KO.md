# 그래픽 전면 개편 · 제작 진행

영웅 그래픽·맵 디자인·사냥터 UI를 공동 최우선으로 제작한다. **시안 → 개발 → 묶음 검수 → 최적화** 순서다. 시안은 목표 이미지이며 실제 Unity 실행 화면이 아니다. 현재 APK는 새 그래픽이 반영된 버전이 아니다.

## 이번 제작 대상

| 영웅 | 원화에서 유지할 특징 | 새 모델 제작 중심 |
|---|---|---|
| 레온하르트 | 금발, 백금 중갑, 청색 망토, 검과 청금 방패 | 판금 겹침·금속 테두리·검/방패 실루엣·청색 천의 접힘 |
| 엘리시아 | 엘프 귀, 옅은 분홍 은발, 녹색/상아색 겹옷, 꽃과 녹색 지팡이 | 긴 머리 덩어리·겹옷의 부피·잎 장식·꽃과 보석 |
| 미라 솔렌 | 붉은 포니테일, 붉은 망토, 백금/가죽 의상, 황금 활 | 포니테일의 흐름·활 시위와 곡선·가죽/금속 분리·화살통 |

미라는 레온하르트와 같은 아우렐리아 진영의 원거리 궁수다. 가름은 이번 3인 제작 대상에서 제외하며 원본 영웅 목록에서 삭제하지 않는다. 기존의 승인되지 않은 구형 입체 초안을 최종 모델로 재사용하지 않는다.

## 제작 시안

- [아우렐리아 3인 다각도 시안](../../assets/graphics-rebuild-v1/concepts/aurelia-three-hero-turnarounds.png): 원화 정체성·재질·후면 구조·무기 기준.
- [왕립 수림 + 사냥 HUD 시안](../../assets/graphics-rebuild-v1/concepts/royal-grove-hunt-hud.png): 중앙 전투 공간·진입로·건축·가장자리 UI 기준.
- 생성 방식: 내장 imagegen. 프롬프트와 원본 참조는 [provenance.json](../../assets/graphics-rebuild-v1/concepts/provenance.json)에 저장한다.

시안의 스테이지·골드·HP·몬스터 배치는 예시다. 실제 게임 데이터·실제 전투 캡처가 아니다. 캐릭터 후면과 작은 장식은 원화에 없던 모델링 제안이다. 새 메시·리깅·애니메이션·맵·UI가 모인 뒤 실제 Unity 화면에서 함께 검수한다. 기존 그래픽을 보존한 상태로 새 개발 경로를 만든다.

## 개발과 남은 작업

왕립 수림의 석판 광장, 청동 상감, 테라스, 계단, 기둥, 아치, 수정과 수목을 실제 Unity 메시로 제작한다. 전투 영역과 주변 몬스터 진입 공간을 먼저 확보하며 중앙에 건축물을 넣지 않는다. 이 개발 메시를 시안과 같은 최종 완성도로 보고하지 않는다.

새 영웅 3인의 첫 입체 메시 제작본을 Blender에서 만들고, 뼈대와 Idle/Walk/Attack 애니메이션을 FBX로 내보냈다. 이는 시안 수준의 최종 아트가 아니다. 정교한 얼굴·머리 카드·텍스처·옷의 물리·공격별 동작은 계속 제작해야 한다. 생성된 원본은 `assets/graphics-rebuild-v1/models/`에, Unity FBX는 `Unity/Assets/Game/Resources/Eternal/GraphicsRebuild/Heroes/`에 있다.

`RoyalGroveDevelopment.unity`는 새 입체 맵과 세 영웅만 사용하는 개발 장면이다. 기존 `PaintedActor`, 입체처럼 보이는 relief 그리드, 시안 이미지를 월드 배경으로 사용하는 코드와 독립적이다. Unity에서 이 장면을 열거나 `Eternal > Graphics rebuild > Create royal grove development stage`로 생성한다. 10칸 원형 초상·배율·영웅 선택·기본 동작 버튼을 개발했으며, 나머지 7칸과 실제 사냥 판정·조이스틱·고유 스킬 연결은 아직 완성되지 않았다. UI 초상은 2D를 사용할 수 있지만 월드 캐릭터와 맵은 실제 메시다.

첫 제작본을 기존 APK 진입점에 자동 적용하지 않는다. 먼저 새 아트와 실제 사냥 HUD 연결을 개발한다. 개별 작업마다 APK 재빌드·검수 이미지·성능 벤치마크를 반복하지 않는다. 구현이 모인 마지막 단계에서 Unity 컴파일·캐릭터 겹침·재질 오류·타격감·조작·레이드·UI·실기기 성능을 점검한다.
