# 통합 사냥터 · 타락한 몬스터 · 영웅 스타일

사냥터는 하나의 확장된 전투 공간입니다. 지역 이동을 스테이지 구간으로 바꿨습니다. 기존 5무리마다 스테이지가 오르는 규칙과 30명 영웅·120개 스킬·성장 기록은 유지합니다.

| 스테이지 | 분위기 | 몬스터 구성 |
|---|---|---|
| 1~499 | 이끼 초원 | 고블린·들개 + 타락한 4종 |
| 500~999 | 호박빛 광맥 | 광산 오크·철갑 두더지 + 타락한 4종 |
| 1000~1499 | 달빛 숲 | 달 늑대·숲 망령 + 타락한 4종 |
| 1500 이후 | 세 분위기를 500 스테이지마다 순환 | 해당 분위기의 구성 |

전투 가능 범위는 기존 23×13에서 **46×26**으로 넓혔습니다. 가로·세로 각각 2배, 면적 4배입니다. 같은 전투 공간과 충돌 범위에서 배경·몬스터 구성을 바꿉니다. 별도의 장애물·입체 지형은 추가하지 않았습니다.

기본 **×1은 멀리서 전체를 보는 배율**입니다. 작은 원형 **×1.5·×2·×3** 버튼으로 같은 중심을 확대합니다. **드래그와 수동 화면 이동은 없습니다.** ×2가 이전 기본 카메라의 캐릭터 표시 크기에 해당합니다. 배율은 이번 실행 안에서만 유지하며 레이드에는 적용하지 않습니다. 확대하면 가장자리 몬스터가 화면 밖으로 나가는 것은 의도한 보기 방식입니다.

원정대는 원형·돌격·방벽·일제사격의 실제 초기 배치가 다릅니다. 작은 원형 초상으로 순서를 선택해 앞으로·뒤로 옮깁니다. 편성 3개에는 **영웅 순서와 진형**을 저장합니다. 장비·레이드 연계까지 포함하는 프리셋은 아닙니다. 불러온 편성도 편성 저장을 눌러 다음 무리부터 적용합니다. 완료한 무리의 경험치는 기존 원정대가 받습니다. 전투 중에는 적에게 접근하므로 시작 대열을 강제로 고정하지 않습니다.

몬스터는 맵 둘레의 여러 방향에서 등장합니다. 발의 투영 타원 간격과 이동량 제한을 유지합니다. 큰 망토·무기 그림까지 모든 상황에서 절대 겹치지 않는다는 뜻은 아닙니다.

| 신규 몬스터 | 기본 행동 | 스테이지별 스킬 |
|---|---|---|
| 타락한 엘프 | 후방 우선 궁수, 사거리 3.2 | 저주 화살: 100부터 약화, 500부터 짧은 기절 추가 |
| 타락한 드워프 | 체력 +12%, 방어 +4, 느린 망치 | 갑옷 파쇄: 100부터 약화, 250부터 방어 4 감소, 1000부터 짧은 기절 추가 |
| 타락한 뱀파이어 | 보조 영웅 우선, 실제 피해의 30% 흡혈 | 흡혈 저주: 100부터 약화·추가 자기 회복 |
| 타락한 늑대인간 | 빠른 접근, 발톱 공격 | 출혈 발톱: 100부터 약화, 250부터 3초 출혈 |

특수 공격은 두 번의 실제 공격 이후, 8초 재사용 대기를 두고 시도합니다. 0.75초 전조가 실제 공격 타이머를 보여 줍니다. 사거리 밖으로 벗어나거나 적이 기절하면 공격이 취소됩니다. 보호막으로 실제 피해를 모두 막으면 디버프를 적용하지 않습니다. 출혈은 같은 영웅에게 중첩하지 않고 갱신합니다. 일시정지·장비 보관 대기 때 타이머와 피해도 멈춥니다. 학습된 모델이 아닌 직접 작성한 전투 규칙입니다. 구간 전체 난이도와 해금 수치는 추가 밸런싱 대상입니다.

장비는 기존 Godot의 난이도별 희귀도 확률, 직업 제한, 지역 세트·이름·옵션 규칙을 가져왔습니다. 쓰러뜨린 몬스터마다 한 번 굴리고 무리 격파 시 골드·경험치와 함께 정산합니다. 무리 번호와 저장되는 프로필 난수 소금을 묶어 재실행·저장 재시도로 같은 보상을 다시 굴리지 않습니다. 가방 200칸을 넘으면 보관함 3000칸으로 배송합니다. 둘 다 차면 이미 받은 물품을 대기 목록에 보존하고 다음 전투를 멈춥니다. 분해 후 보관함에서 빈칸만큼 수령하면 이어집니다. 보호 장비를 자동 분해하지 않습니다. 레이드·오프라인 장비와 전체 우편 서비스 이관은 남아 있습니다.

30명 원화를 비교해 청금색 기사 3명과 연보라 마도사 쌍을 우선 분리했습니다. **오르윈**은 녹색 타바드·각형 방패·창·흰 투구 장식, **카엘룸**은 구리빛 머리·주황 망토·태양 대검, **카이렌**은 짧은 남색 머리·별자리 코트·바지·천문 지팡이를 사용합니다. 레온하르트·루네아를 포함한 나머지 27명은 기존 원화를 유지합니다. 새 스타일을 편성·도감·전투·초상·잔상에 연결하고 영웅 ID·스킬·성장은 바꾸지 않습니다.

새 몬스터 4종과 영웅 3명은 **내장 이미지 생성·편집 도구**로 제작했습니다. 각 시트는 대기·준비·공격·보행의 원화 4자세이며 반복 프레임은 이를 공유합니다. 새로 리깅한 3D 애니메이션이나 영웅 30명 전원 재제작은 아닙니다. 발 기준점을 알파에서 읽고 새 실루엣 전체를 담는 절차적 릴리프 면을 사용합니다. 원본 PNG는 그대로 보관합니다. 1024 BC7·투명 알파·프레임 여백을 확인했습니다. Android ASTC는 설정만 있으며 기기 검수는 남았습니다.

- 영웅 스타일·프롬프트: `Unity/Assets/Game/Resources/Eternal/HeroStyles/{orwin,caelum,kairen}/poses.png`, 각 폴더 `SOURCE.json`

기능·디자인을 묶어 점검했습니다. 프레임 최적화는 마지막에 진행하며 모바일 60fps·200MB 달성을 의미하지 않습니다.
