# Unity 기능 연결과 왕립 수림 UI

사용자 범위: Godot에서 만들었던 기능·데이터의 Unity 이식을 계속한다. 사냥 화면은 1000124825.jpg의 Unity UI를 사용한다. 영웅·맵·조명 디자인 개편은 보류한다.

## 실제 실행 경로

`Unity/Assets/Scenes/Eternal.unity` → `EternalBootstrap` → 저장된 `NativePlayerSession` → `HuntingMigrationReview` → `RoyalGroveHuntHud`.

현재 저장 세션에서도 왕립 수림 헤더, 재화, 우측 2열 10칸, 좌측 조이스틱, 선택 영웅 HP/각성, 원형 스킬 3개, ×1/×1.5/×2/×3, 하단 사냥·영웅·레이드·던전·진영전·가방을 사용한다. 가로 영웅 목록과 이전 HUD는 숨긴다. 저장된 편성이 바뀌면 우측 슬롯을 갱신한다. 레이드도 실제 전투의 HP/쿨타임을 읽고 선택한 a1/a2/궁극기를 정확히 시전한다. 배율은 사냥에 적용한다. 조이스틱은 사냥·던전·레이드의 실제 이동 명령에 연결된다.

`RoyalGroveDevelopment.unity`는 보상 미저장 그래픽 개발 장면이다. 실제 계정의 기능 검수에는 Eternal 장면을 사용한다. 개발 장면의 영웅을 완성된 10인 계정으로 보고하지 않는다.

## 이식한 동작

- 원본 30명/120개 스킬 정의, 편성, 성장·연구·승급·돌파, 수호신, 소환, 장비·연계와 기존 Unity 사냥/레이드를 유지한다.
- 목표 100개, 일일 6개, 주간 6개, 업적 18개, 칭호, 핵심 퀘스트, 첫 원정 가이드를 실제 저장 명령과 연결한다. 자동 사냥 XP로 ‘직접 성장’ 가이드를 완료 처리하지 않는다.
- 일일 던전 3종/공유 완료 3회, 직접 승리한 단계 소탕, 무한탑, 주간 심연/5회/실제 HP 감소 점수, 패턴 3종을 실제 10인 전투와 보상에 연결한다. 사냥의 무리 보상을 던전에 중복 지급하지 않는다.
- 연습은 임시 복제 상태로 진행한다. 실제 보상·횟수·성장·재화는 변경하지 않는다. 맞춤 레벨과 영웅별 피해·피격·회복·보호막·첫 전투 불능, 최근 6회와 같은 조건 비교를 지원한다.
- 원본 40×40 영토, 수도 성역, 보급/BFS 경로, 군량, 행군·지원·후퇴·취소, 부상/피로/정비, 전술, 주둔, 집결, 실제 수비대 전투, 대기 공격 FIFO, 시즌·기여·보상을 연결한다. 공격력 숫자 비교만으로 점령하지 않는다.
- 로컬 권한 명령은 수정 번호와 진영을 확인하고 성공 영수증을 최대 256개 보관한다. 같은 명령 ID를 재전송하면 재실행하지 않는다. 연결 중지·재접속과 시간 보정 진단을 제공하며 캐시 월드를 권한 데이터로 덮어쓰지 않는다.
- 동일 계정의 진영 변경은 원본 진영별 영토·행군·편성·프리셋 은행을 사용한다. 전역 재화/성장 기록은 공유한다. 이미 별도로 존재하는 다른 Unity 계정 파일을 자동으로 합치거나 덮어쓰지 않는다.
- 원본 로컬 거래소 에스크로, 매물 5개/48시간/수수료 5%, 구매 귀속·옵션 거래 이력, 취소 배송·정산 수령·중복 명령 방지를 연결한다. 원본에 없는 플레이어/매물을 생성하지 않는다.
- 공방 후보·선택·제거·추출·이식·초점, 실제 결정 소비·아이템 ID·오래된 옵션 검사, 통합 전투 프리셋 P1~P3를 연결한다.
- 자동 장착/분해, 우편·이월 장비, 원본 오프라인 8시간·최대 5스테이지·장비 추첨 제한·보관 보상, 스테이지 상자, 레이드 결정/장비/5회 보장·수호신 XP를 연결한다.

## 저장과 호환 범위

원본 저장의 83개 필드를 복제하고 알 수 없는 최상위 필드도 유지한다. 원본 Godot 저장은 읽기 대상이며 Unity 저장 파일로만 기록한다. Unity 저장 봉투 v2는 기존 v1을 읽고, 동일 계정의 활성 진영이 바뀌어도 계정의 원래 경로와 SHA-256/원자적 교체/백업/수정 번호를 사용한다. 저장 실패 후 다음 재화 변경을 막고 같은 후보 저장을 재시도한다.

원본의 일일/주간 날짜 계산을 KST로 연결한다. 시계 역행으로 횟수를 다시 채우지 않는다. 기존 단계 내 진행도는 Unity의 기존 5무리/스테이지에 보수적으로 대응시키고 원본 수치와 진행 비율도 보존한다. 기존 Unity 사냥/레이드 기본 밸런스는 유지하며 Godot의 전투 프레임·난수열까지 동일하게 재현하는 이식은 아니다. 새 수비대 전투는 System.Random을 사용하므로 Godot PCG와 같은 시드의 새 결과가 다를 수 있다. 저장된 과거 전투 보고서는 다시 계산하지 않는다.

원본 생산성 표본은 보존하고 Unity의 실제 사냥 표본을 새로 수집한다. 새 엔진의 이동/처치 속도를 원본 표본으로 과대평가하지 않는다. 기본 스테이지·몬스터 변경과 신규 보상은 실제 저장 명령에서만 정산한다.

원본 `remote_server` 어댑터도 미구현이었다. 이 변경은 인터넷 다중 사용자 진영전/거래소 서버를 새로 배포하지 않는다. 원격 모드 저장은 로컬 온라인 서비스로 가장하지 않고 명령을 차단한다. 집결의 원본 시범 동맹 두 부대는 ‘프로토타입 동맹’으로 표시한다.

## 검수 자료

`LegacyFeatureVerification.Run`: 원본 정의·83필드·Godot 행군 오라클·던전 실제 전투·보상 중복 방지·거래소·공방·프리셋·오프라인·저장 실패·진영 전환/v1-v2 재시작·권한 영수증·첫 가이드·a2 시전·실제 전투 통계·공격 큐를 검사한다.

`LegacyFeaturePlayCapture.Begin`: 분리된 검수 계정과 실제 Unity Play Game View를 사용한다. 사냥·던전·진영전·목표·거래소·프리셋·연습·던전 전투·레이드·녹스페라 화면을 캡처한다. 이미지 합성/생성 시안이 아니다. 현재 공개 그래픽을 유지한 기능/UI 검수이며 새 APK 설치 검수와 구분한다.

검수 체크아웃의 Unity Search 인덱스 내부 예외는 별도의 `editor_search_errors`에 원문을 남긴다. 게임 실행 오류와 분리하며 원본 로그도 보존한다. 성능 벤치마크와 영웅 그래픽 평가는 이번 범위에 포함하지 않는다.

GitHub에는 기능·UI 코드, 원본에서 내보낸 정의, 이 문서와 검수 도구/기록을 올린다. 로컬 미게시 그래픽 커밋, Rapid Assets 모델, 새 텍스처, 조명/패키지/프로젝트 자동 설정 변경은 포함하지 않는다.
