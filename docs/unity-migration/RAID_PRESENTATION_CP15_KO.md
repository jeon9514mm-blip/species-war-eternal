# 레이드 산개·기믹 표시·조작 정리

기존 세 레이드와 30명 영웅·성장·스킬 구성은 유지합니다. 이전에 정리한 로스트아크 참고 방향 중 **패턴 대응을 먼저 읽고, 기믹 상태를 구분하며, 산개 명령으로 움직이는 방식**을 이번 묶음에 적용했습니다. 다른 게임의 레이드를 그대로 복제하거나 네 가지 참고 게임의 전체 기능을 완성한 상태는 아닙니다. 영상 관찰과 남은 적용 항목은 [참고 기록](REFERENCES.md)에 있습니다.

| 레이드 | 표시하는 실제 상태 | 화면 표현 |
|---|---|---|
| 초원왕 그룬 · 하늘 유적 | 기존 공용 갑주 체력 | 청동 갑주 조각 6개와 연결선 |
| 광맥의 거인 모르굴 · 채석장 | 기존 공용 수정핵 체력·핵 수 | 2단계 2개, 3단계 3개의 수정과 연결선 |
| 월식의 여왕 셀레네 · 달빛 성소 | 기존 의식 제한 시간·필요 피해·누적 피해 | 의식 문양 3개와 연결선 |

표현물은 **기존 집계 기믹의 시각화**입니다. 개별 수정·갑주를 선택해서 공격하는 새로운 타깃, 별도 체력, 장애물이나 충돌체를 만들지 않습니다. 기존 갑주·수정핵 흡수 순서, 보스 피해·무력화·카운터·보상 규칙은 유지합니다. 의식 문양도 새로운 독립 타이머를 갖지 않습니다.

상단 왼쪽에 P1/P2/P3와 60%·30% 전환 기준을 표시합니다. 전환 안내는 1.8초 동안 왼쪽 영역을 쓰고, 이어서 같은 위치에 공용 기믹 체력이나 의식 진행도가 나타납니다. 중앙 패턴 안내, 영웅 스킬 알림, 보스 얼굴을 가리지 않도록 실제 실행 캡처를 보고 위치를 수정했습니다. 위험 전조가 나오면 기믹 조각을 어둡게 하고 상태·전환 안내를 숨겨 위험 구역과 대응 안내를 우선합니다. 배경도 잠시 어둡게 합니다.

조작을 두 줄로 묶었습니다. 첫 줄은 스킬·각성·카운터, 둘째 줄은 추적 복귀·산개 대형·자동 회피·훈련입니다. 가능한 훈련 모드에서는 카운터 연습도 표시합니다. 사용자 추가 요청에 따라 **긴급 회피 버튼을 삭제**했습니다.

**산개 대형**은 열 명을 두 줄로 벌리는 지속 이동 명령입니다. 기존 이동 속도·투영 몸통 충돌·장판 회피를 거쳐 이동하며, 순간이동하지 않습니다. 자동 회피를 켜면 장판 탈출이 산개보다 우선합니다. 추적 복귀는 기존 역할별 접근을 다시 사용합니다. 바닥 집결 명령을 누르면 산개를 대체합니다. 일시정지·전투 종료 때 산개와 추적 버튼을 비활성화합니다. 초대형 망토·무기 그림이 어떤 상황에서도 절대 겹치지 않는다는 보장은 아닙니다.

**사냥·레이드 공통 조이스틱**을 누른 채 드래그하면 원정대가 화면 방향으로 이동합니다. 중앙 12%는 데드존, 바깥쪽은 최대 속도이며 대각선 입력도 속도를 제한합니다. 원 밖으로 드래그해도 입력을 잡고 있다가 놓으면 즉시 0으로 돌아갑니다. 손을 떼면 자동 추적이 끼어들지 않고 현재 자리에서 멈춥니다. 사냥에서는 옆의 **자동 추적**, 레이드에서는 **추적 복귀**로 자동 이동을 다시 켭니다.

직접 조작 중에는 자동 장판 탈출이 개입하지 않습니다. 기존 공격 준비를 끊고 이동할 수 있지만, 기절 상태에서는 움직일 수 없습니다. 충돌과 맵 경계를 거치는 실제 이동이며, 새 무적·순간이동·회피 쿨다운을 주지 않습니다. 보스와 몬스터의 공격 구역에서 실제로 벗어나야 피합니다. 창 포커스 상실·포인터 취소·일시정지·메뉴·전투 전환 시 입력을 해제합니다. 사냥 카메라 드래그는 추가하지 않으며 기존 ×1/×1.5/×2/×3 확대 중심을 유지합니다. 직접 이동 상태는 이번 전투 세션에만 존재하며 저장 프로필을 바꾸지 않습니다.

## 검수

- 산개·표시 상태 도메인: **69,372** 비교. 세 지역 300틱씩 실제 이동, 이동량 제한·투영 몸통 간격·맵 경계·일시정지·재사용 시 표시 초기화·전조 우선 확인.
- 기존 레이드 도메인: **33,593** 비교. 원본 피해·제어·장판 규칙과 기존 전투 시나리오 유지. 앞서 바꾼 세 영웅의 6,144 삼각형 표면을 검사의 기대값에 반영했습니다. 다른 27명은 기존 6,000 삼각형 표면입니다.
- 기존 대응/연계 저장: **21** 비교.
- 공통 직접 이동 도메인: **72,210** 비교. 네 방향 이동·정규화·몸통 충돌·손 떼면 정지·일시정지·자동 추적 복귀·추가 무적 없음 확인. 기존 사냥 세계 검사 **285,036** 비교도 다시 통과했습니다.
- 실제 Windows 입력·표시 **75**, 처음 시작 **34**, 별도 프로세스 재실행 **7** 검사 통과. `raid-native-cp15.json`, `native-game-first-cp15.json`, `native-game-reload-cp15.json`에 기록했습니다. 공통 조이스틱은 실제 마우스 누르기·원 밖 드래그·놓기를 통해 이동·정지·자동 추적 복귀를 검사했습니다. 기믹 화면은 명시적인 **Lv50 임시 훈련·일시정지·강제 페이즈/전조 검수 조건**이며, 실제 플레이로 자연스럽게 해당 페이즈를 격파한 증거가 아닙니다. 공격 수치를 억제하고 상태 안내 검수용 시계만 2초 앞당긴 조건도 포함합니다. 이 조건에서도 선택·산개·복귀·훈련·사냥 복귀는 실제 마우스 이벤트를 사용합니다. 기존 처음 시작/재실행 검사는 자연 사냥 보상과 저장 복구를 포함합니다. 첫 시작/재실행은 최종 글자 표기 조정 전 빌드에서 검사했고, 조정 후 최종 빌드에서는 조이스틱·레이드 입력 검사를 다시 확인했습니다.
- Windows 최종 빌드 성공: 오류 **0**, 예상된 Player Pipeline 비활성화 경고 **1**. C# 컴파일 오류·경고 **0**. 이번 묶음은 FPS/메모리 벤치마크가 아닙니다. 최종 성능 최적화는 마지막 단계로 남깁니다.

## 남은 범위

이번 변경은 새로 리깅한 보스 3D 모델, 독립 수정 타깃 전투, 새 맵 페인팅, 모든 영웅의 새 원화나 120개 고유 이펙트 전체 검수를 포함하지 않습니다. 기존 세 전용 맵 위에서 기믹과 조작을 개선했습니다. 동료 독립 공격, 레이드·오프라인 장비 보상 이관, 전체 콘텐츠·고단계 밸런스와 최종 그래픽·모바일 성능 작업은 계속 남습니다.

작업용 batch Editor에서 컴파일·빌드를 수행했습니다. 앞서 확인한 일반 GUI Editor의 UPM/초기화 문제까지 해결됐다는 뜻은 아닙니다. 시스템 UAC 설정 변경이나 재부팅은 하지 않습니다. 이번 작업용 Editor는 검수 후 저장하고 닫아 같은 프로젝트 중복 실행을 남기지 않습니다.

Windows 로그에는 이전 빌드부터 있던 DOF/Panini 후처리 셰이더 누락 메시지가 있습니다. 해당 후처리가 이 빌드에서 작동한다고 주장하지 않습니다. 최종 렌더러·성능 정리에서 확인할 항목으로 남깁니다.

이번 직접 조작 수락 검사는 Windows 마우스 포인터로 수행했습니다. 휴대폰 실제 터치·동시 다중 터치 기기의 검수는 아직 하지 않았습니다.
