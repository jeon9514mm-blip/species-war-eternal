# Pixel RPG v53 · 사냥 흐름과 조작 개선

실제 사냥에서 멈춤·불필요한 귀환·치유 누락을 재현하고 수정했습니다. 사냥 정보창의 입력 오류를 고쳤고, 사냥 중 누적 보상을 받을 수 있게 했습니다.

## 수정 내용

| 항목 | 확인한 문제 | 변경 후 |
| --- | --- | --- |
| 장애물 옆 근접 추격 | 공격 간격을 맞출 목표가 나무 안에 생겨, 공격 거리 밖에서 영구 정지 | 막힌 간격 목표 대신 몬스터까지 길을 찾고, 접근 공간이 확보되면 정상 간격 유지 |
| 원거리·지원 몬스터 후퇴 | 아군을 피하다 스스로 서식지를 벗어나 귀환·체력 초기화 반복. 재현 조건에서 60초 동안 8회 | 방어적 후퇴를 서식지 안으로 제한하고, 경계에서는 전투 유지 |
| 몬스터 귀환 끝점 | 짧은 프레임에서 남은 거리를 즉시 이동하여 속도 제한 초과 | 실제 이동량으로 귀환 완료 후 체력 초기화 이벤트 한 번 처리 |
| 탐색·전리품 수집 중 지원 | 유효한 치유가 준비되어도 적과 싸울 때만 실행 | 치유 스킬을 기존 시전 시간·행동 간격·쿨다운으로 실행 |
| 위급 시 치유와 후퇴 | 준비된 치유보다 후퇴 판정이 먼저 발생 | 실행 가능한 치유의 준비 시간 동안 후퇴 판단을 유예하고, 치유 후 여전히 위급하면 재정비 |
| 교전 전환 | 새 몬스터 생성·교전 시작이 치유를 취소하고, 교전 해제 후 공격 준비가 남아 이동·치유 정지 | 시작 시 진행 중 치유 보존. 해제 시 무효 공격 준비를 정리하고 치유는 유지 |
| 탱커 생존 판단 | 건강한 후열 때문에 평균 체력이 높으면 빈사 탱커도 방어기 보류 | 탱커 본인의 위급 체력을 방어기·방어 궁극기 판단에 반영 |
| 사냥 정보창 | 보이는 정보창 뒤 자동사냥·속도·메뉴 버튼이 눌리고 ESC로 닫히지 않음 | 정보창이 배경 입력을 차단하고 닫기·ESC·크기 변경·사냥터 이동 처리 |
| 누적 보상 | 사냥 화면에서 바로 받는 동작이 없음 | 상단 ‘보상 받기’ 버튼. 현재 전투·HP·일시정지 상태를 유지하며 기존 보상 수령 실행 |
| 빈 편성 안내 | 영웅이 없는데 ‘사냥 재개’만 표시 | ‘영웅 편성하기’로 편성 화면 연결 |

치유를 기다리는 동안 적의 행동은 계속됩니다. 힐러가 죽었거나 기술·행동이 준비되지 않았으면 후퇴를 지연하지 않으며, 전멸은 바로 재정비로 이어집니다. 시전 준비 중 다른 영웅이 회복시켰다면 불필요해진 치유는 쿨다운을 소비하지 않습니다. 지원과 전투 업데이트가 같은 영웅을 한 프레임에 중복 처리하지 않도록 연결했습니다.

후퇴 제한은 몬스터가 자기 간격을 잡는 이동에 적용합니다. 영웅에게 멀리 끌려간 몬스터의 정상 귀환·귀환 중 공격 제외·귀환 후 한 번의 체력 회복은 유지합니다.

보상은 기존 누적 골드·경험치·스테이지 상자를 수령합니다. 보상이 없으면 버튼을 비활성화하며 경험치만 있거나 상자만 있어도 받을 수 있습니다. 연속 클릭으로 중복 수령하지 않습니다. 수치·드롭 확률·정산 단위는 바꾸지 않았습니다.

## 검증

Godot 스크립트 **187/187개**, 전체 회귀 테스트 **106/106개**를 통과했습니다. 신규 검사 4개는 **182개 조건**을 확인했으며, 이동 검사는 별도로 장애물 주변 **525개 접근 경로**를 포함합니다. 실행 로그는 `pixel-rpg-v53-test-results.json`에 수록합니다.

| 신규 검사 | 통과 조건 수 |
| --- | ---: |
| 지원·전투 전환·탱커 생존 | 50 |
| 사냥 화면 실입력·보상 | 73 |
| 지형 주변 추격 | 12 |
| 몬스터 후퇴·귀환 | 47 |

기존 전체 세로 UI 검사도 158개 화면 상태, 21,975개 조건을 통과했습니다.

전체 검사에서 기존 V7 논리 테스트가 종료할 때 WAV 재생 리소스 2개의 정리 경고가 발생했습니다. 음향 검사가 아닌 해당 테스트에서 불필요한 효과 재생을 끄고, 전체 187개 구문 검사와 해당 테스트를 재검증했습니다. 추가 병렬 4회도 오류·경고 없이 통과했습니다. 게임의 효과 재생 및 전용 FX 검사는 유지하며, 원래 경고 로그와 재검증 결과를 JSON에 함께 남깁니다.

- 신규 이동 검사: 모든 17개 장애물 주변 525개 접근 방향, 속도 제한, 장애물 통과 금지, 원거리 이동 회귀.
- 신규 생태 검사: 근접 추격 중 원거리·지원 몬스터의 반복 귀환, 정상 귀환, 짧은 프레임의 이동량, 가속 및 재정비 상태.
- 신규 지원 검사: 실제 사냥 업데이트로 탐색·전리품 수집·위급 상황·교전 전환·중복 시전·적 행동 지속·전멸·일시정지·탱커 방어 확인.
- 신규 UI 검사: 실제 viewport 입력으로 정보창 열기·닫기·배경 차단·크기 변경·사냥터 이동·보상 수령·큰 수치·빈 편성 확인.
- 기존 30인 스킬, 반복 사냥, 레이드·보스·진영전·저장, 전체 세로 UI 회귀 검사.

검증은 Godot 4.7.2 headless 환경에서 진행합니다. 실제 GPU 화면 캡처 및 휴대폰의 터치감·발열·프레임 성능은 확인하지 못했습니다. 사냥 효율 증가율이나 모든 기기에서의 성능 향상은 이번 결과로 주장하지 않습니다.

## 적용

현재 작업 소스에는 v53이 반영되어 있습니다. `pixel-rpg-v53-hunt-reliability.patch`는 최초 **v46.1 원본 소스 기준 누적 패치**입니다. 앞선 수정도 포함하므로 이전 패치를 적용한 폴더에 중복 적용하지 마세요.

```bash
git apply --check /path/to/pixel-rpg-v53-hunt-reliability.patch
git apply /path/to/pixel-rpg-v53-hunt-reliability.patch
```

이미지·음원은 기존 프로젝트의 자산을 사용하며 개인 저장 파일은 포함하지 않습니다. Godot 4.7.2에서 `project.godot`을 열고 가져오기 후 실행하세요.

```bash
python3 tools/run_tests.py --godot /path/to/Godot --jobs 4
```
