# 종의 전쟁 — UI v30

## 디자인 방향

밝고 살짝 귀여운 픽셀 판타지. 눈부신 초록 대신 세이지, 크림, 짙은 초록 글씨를 사용한다. 모험 시작·출격·수령 같은 중요한 행동에만 짙은 초록 채움을 사용하고, 금색은 보상·진행 강조에 제한한다.

| 요소 | 값 |
|---|---|
| 배경 | `#e5e8dc` |
| 기본 패널 | `#fbf7ed` |
| 보조 패널 | `#edf0e4` |
| 본문 | `#254239` |
| 보조 글자 | `#65766b` |
| 주요 행동 | `#316c56` |
| 보상 강조 | `#a27130` |
| 보조 진영색 | `#74649a` |

기본 화면 1280×720. 전투의 큰 맵·작은 캐릭터·밝기 0.90/채도 0.88은 유지한다. 글자는 NanumGothic을 쓰며 동봉된 OFL 라이선스를 유지한다. 제목/본문/설명 크기를 분리하고, 원래 작은 글자를 강제로 키우던 동작을 제거했다. 긴 정보는 상세 화면 또는 스크롤 안에 둔다.

## 구현 파일

- `GameUiTheme.gd`, `GameUiIcon.gd`: 공통 스타일, 버튼 상태, 포커스, 스크롤바, 26종 선 아이콘.
- `UiChrome.gd`: 공통 헤더, 6개 하단 메뉴, 전체 메뉴, 요청 시 열리는 가이드.
- `LandingScreens.gd`: 타이틀 → 기기 로그인 → 원정대 로비.
- `OnboardingScreens.gd`: 진영 선택, 소개, 출격 준비.
- `HeroScreens.gd`: 15명씩의 영웅 명단, 최대 10인 편성, 상세·4개 스킬·강화.
- `GrowthInventoryScreens.gd`: 동료/영웅 훈련, 장비 관리, 빈 보관함 안내.
- `ContentScreens.gd`: 성장 콘텐츠, 소환, 보상센터, 월드맵, 보스선택, 도감.
- `RaidScreen.gd`: 보스/공략, 전투 상태, 10인 HP, 전투 시작·재도전.
- `WorldWarScreen.gd`: 지도와 지휘 명령 분리, 정보 스크롤, 시즌·전투기록 모달.
- `RewardDialogs.gd`: 방치 보상, 소환 결과, 레이드 결과, 비차단 스테이지 완료 안내.
- `Main.gd`: 기존 플레이·저장 로직과 새 화면 연결. 효과 설정은 별도 `ui-preferences.cfg`로 저장한다.

## 실제 동작 범위

계정 인증 서버가 없으므로 로그인 화면의 실제 기능은 이 기기 저장으로 시작/계속하기다. 소셜 로그인이나 클라우드 저장의 성공 상태를 만들지 않았다. 상점 구매는 준비 중으로 표시하며 실제 결제는 실행하지 않는다. 기존 보상 테스트는 무료 지원 보상으로 명확히 표현하고 지급량·횟수 제한을 유지한다. 전쟁 모드는 기기 내 전선임을 표시한다.

30명·120개 스킬·진영별 8/4/3 역할 구성과 저장 스키마 29를 유지한다. 기존 승인 영웅 스프라이트를 재사용하고, 전용 아트가 없는 영웅은 역할 문장으로 표시한다. 새 25명의 완성된 캐릭터 아트가 추가된 것으로 표시하지 않는다.

## 신규 아트

`assets/ui/v30/expedition-key-art.png`는 2026-09-23 내장 이미지 생성 도구로 만든 원본 숲 배경이다. 주요 프롬프트: cozy pixel fantasy meadow, winding trail, stone forest gateway, stream/bridge, calm sage/cream palette, moderate brightness, no text/UI/characters, independent original scene. 실제 타이틀/로그인/소개에 기존 승인 캐릭터를 겹쳐 사용한다. 화면을 그린 목업이 아니라 실제 게임에 사용되는 배경 이미지다.

## 검증과 한계

Godot 4.7.2에서 실제 SceneTree 구성, 버튼 신호, 전투 상태, 저장/영웅 호환을 검증한다. 결과는 `../v30-validation-summary.json`, `../v30-regression-results.json`, `../v30-final-targeted-results.json`을 확인한다.

`control-geometry.json`과 `layout-analysis.json`은 실제 Godot Control의 배치를 수집한 자료다. 정상 스크롤 바깥의 항목은 넘침으로 계산하지 않는다. 이 자료는 PNG 렌더 검사 결과가 아니다.

이 실행 환경은 로컬 디스플레이 소켓이 차단되어 Xvfb를 시작할 수 없었으며, 화면 캡처를 위한 실행 승인도 자동 정책에서 거절되었다. 실제 렌더 이미지·기기 터치·애니메이션의 최종 시각 검수는 남아 있다. 전체 테스트 통과만으로 상용 출시 인증이나 디자인 최종 승인을 의미하지 않는다.
