# v48 진영전 개선 및 검증

현재 v47 소스에서 진영전의 지도 조작, 출정 안내, 전투 기록과 진행 안정성을 개선했습니다.

## 지도와 출정 화면

- 지도에 확대·축소, 전체 보기, 드래그 이동, 내 부대 위치로 이동, 목표 추천, 보급 표시 전환을 추가했습니다. 드래그는 영토 선택으로 처리하지 않습니다.
- 출발 전에 실제 행군 경로를 표시합니다. 행군 중에는 부대 표식이 경로 위로 이동하고 진행률·남은 시간·취소 환급량이 표시됩니다.
- 광산·숲·유적·요새·수도를 지도 기호로 구분합니다. 진영 색상, 안전지대와 최후 방어선 테두리, 고립 영토의 빗금 표시를 함께 사용합니다.
- 목표 추천은 보급망과 군량으로 접근할 수 있는 가까운 중립 영토를 우선 선택하며, 비슷한 거리의 자원 영토에 가점을 줍니다. 선택만 바꾸며 출정이나 자원 소비는 실행하지 않습니다.
- 군량 부족, 부상, 높은 피로, 보급 단절, 보호 영토, 시즌 정산 등의 사유를 출정 버튼 위에 안내합니다.

## 세로 화면과 전투 기록

- 세로 화면에서 숨겨져 있던 시즌·보상과 전선 갱신 버튼을 상단에 배치했습니다.
- 지도와 명령 패널을 분리하고 하단 메뉴가 명령 버튼을 가리지 않도록 조정했습니다. 크기 변경 시 부대나 행군을 재생성하지 않습니다.
- 시즌 안내와 전투 결과 창을 실제 화면 크기에 맞춰 가운데 배치했습니다. 닫기 버튼도 화면 안에 유지합니다.
- 최근 전투 기록에서 이전·다음 기록을 조회할 수 있습니다. 현재 전쟁 기록은 기존 저장 한도인 최근 10개이며, 이전 저장 형식의 전역 기록도 표시할 수 있습니다.
- 집결 보고서에 참여 부대 이름과 격파 수를 표시합니다. 팝업을 바꿀 때 입력 차단 배경이 누적되지 않습니다.
- 시즌 창에서 현재 군량·명예 생산량과 보유 명예, 피로를 확인할 수 있습니다.

## 진행 오류 수정

| 확인한 문제 | 수정된 동작 |
| --- | --- |
| 군량이 부족하면 연결된 수도로도 귀환하지 못함 | 느린 긴급 귀환을 선택하여 군량 없이 수도에서 부상과 피로를 회복할 수 있음 |
| 전멸 부대가 지원 출발·수비 등록 및 공헌 획득 가능 | 살아 있는 병력이 없으면 지원·등록 거절, 군량과 공헌은 그대로 유지 |
| 이미 등록한 수비대를 갱신해도 이전 병력 정보가 남음 | 기존 등록을 갱신하며 병력 정보 반영, 부대와 공헌은 중복 생성하지 않음 |
| 고립 부대가 집결을 통해 단독 공격의 보급 제한을 우회 | 집결 준비와 출정에서 보급 연결을 다시 검증 |
| 집결 준비 후 목표 소유권 또는 보급이 변경됨 | 출정을 거절하고 참여 예약 해제, 변경된 전선 기록 번호를 반영 |
| 잘못된 시간값으로 행군이 완료되거나 상태가 깨질 수 있음 | 비정상 시간값을 무시하고 기존 행군 유지 |

행군 상태 갱신은 0.15초 간격으로 제한했습니다. 도착 판정은 계속 권한 측 시각을 사용합니다. 검사에서는 화면 갱신 60회당 행군 갱신이 6회 발생했습니다. 이는 갱신 횟수 측정이며 실기기 FPS 측정은 아닙니다.

## 검증 결과

Godot **4.7.2.stable.official.ed1daf0bf** 사용.

- 전체 GDScript 컴파일: **165/165 통과**.
- 전체 회귀 검사: **88/88 통과**.
- 최종 행군 문구·이전 보고서 표시 수정 후 영향받는 UI 검사 2개를 재실행하여 모두 통과했습니다. 결과 JSON은 각 검사의 마지막 실행 결과를 제공합니다.
- 새 진영전 안정성 검사: **31개 항목 통과**. 양 진영의 군량 없는 귀환, 부상 복구, 수비대 갱신, 집결 조건 변경, 잘못된 시간 입력을 확인했습니다.
- 새 진영전 UI 검사: **124개 항목 통과**. 720×1280, 720×1440, 720×1560, 810×1440에서 배치, 팝업, 버튼, 마우스·터치·드래그, 경로 미리보기, 추천의 무소비 동작, 행군 완료의 중복 방지를 확인했습니다.
- 기존 저장/복구, 보급, 주둔, 중립 점령, 전투, 시즌 보상, 성장, 영웅·애니메이션, 자동사냥 검사도 포함됩니다.

검증 범위는 헤드리스 엔진의 동작과 UI 좌표입니다. 실제 그래픽 화면 캡처·육안 비교, Android 기기의 터치 감각과 FPS는 미검증입니다. 현재 구현된 기기 내 전선·권한 시뮬레이션을 개선한 것이며, 실제 다른 플레이어와 연결하는 원격 서버는 구현된 것으로 표시하지 않습니다.

## 적용 방법

`pixel-rpg-v48-faction-war.patch`는 **v46.1 typefix 원본용 누적 패치**이며 v46.2 안정화와 v47 개선을 모두 포함합니다. v47 패치 위에 중복 적용하지 마세요.

1. 원본 `pixel-rpg-v46.1-typefix.zip`을 새 폴더에 풉니다.
2. `project.godot`가 있는 프로젝트 폴더에서 아래 명령을 실행합니다. 패치 경로는 실제 다운로드 위치에 맞춥니다.

```sh
git apply --check /path/to/pixel-rpg-v48-faction-war.patch
git apply /path/to/pixel-rpg-v48-faction-war.patch
```

3. Godot 4.7.2로 `project.godot`를 열고 실행합니다. 원본 아트 리소스가 필요한 소스 패치이며 APK가 아닙니다.

전체 검사 명령:

```sh
python tools/run_tests.py --godot /path/to/Godot_v4.7.2 --jobs 4 --output test-results.json
```
