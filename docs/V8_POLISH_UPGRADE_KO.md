# v8 체감 완성도 업그레이드

v8은 v7의 10인 개별 전투 시스템 위에 전투 연출과 장기 성장 루프를 보강한 버전입니다.

- 영웅 궁극기 전용 컷인 배너와 화면 플래시
- 레이드 보스 위험 공격 사전 예고 UI
- 일반 스테이지/레이드 클리어 결과 팝업
- 진영 동료 전투 경험치·레벨업·Lv.5 각성·Lv.10 초월
- 영웅별 공격/생존/기능 3갈래 스킬트리
- 영웅 3레벨마다 스킬 포인트 1개 지급
- 스킬트리를 전투력/HP/방어/쿨다운/궁극기 충전에 반영
- 성장 연구 화면 추가
- 저장 데이터에 동료 성장 및 영웅 스킬트리 포함

`V8PolishSmokeTest.gd`에서 스킬 포인트 경제, 동료 성장/진화, 궁극기 컷인, 보스 예고, 전투 결과 팝업을 검증합니다.
현재 패키징 환경에는 Godot 4.5.1 실행 파일이 없어 엔진 기반 테스트는 별도 실행이 필요합니다.
