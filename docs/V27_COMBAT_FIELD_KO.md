# v27 실시간 전투 AI·필드 생태

## 실제 변경
- 3배속/낮은 프레임 속도에서도 입력 시간을 작은 구간으로 모두 처리하여 사냥 시간·쿨다운 누락 방지.
- 회복의 소수 HP 누적 보존: 높은 프레임 속도에서 불필요한 최소1HP 보너스나 정수 버림으로 회복률이 달라지지 않음.
- 회피를 화면 프레임 카운트에서 실제 피격 시도 횟수로 분리.
- 기절·공격 약화·취약을 개별 몬스터에 적용. 범위 안 대상에게만 적용하며 해당 타이머가 끝나면 효과 종료.
- 기절한 몬스터만 이동/공격 정지. 회복 몬스터는 가까운 부상 동료만 치료하며 만피 집단에서는 공격 지원.
- 13개 몬스터 종의 역할·감지 거리 고정. 같은 이름이 매 전투마다 힐러/암살자로 바뀌지 않음.
- 서식지 주변 배회·추격 범위·서식지 귀환·귀환 시 HP/광폭화/상태이상 초기화. 귀환 중 무적·타겟 제외, 처치 보상 발생 없음.
- 몬스터 재생성 대기와 스테이지 압박을 명시적이고 제한된 수치로 관리.
- 0/음수 피해 방어, 비정상 거대 피해의 정수 오버플로 방지, 실제 감소한 HP만 피해·흡혈 계산에 반환.

## 완료 기준

1. 사거리 실패가 다른 영웅/몬스터 차례를 중단하지 않음.
2. 시전 중 대상 사망/이탈 시 유효 대상 재선택 또는 자원 보존.
3. 추격 중 지원 행동, 다수 영웅의 역할별 스킬 처리.
4. 타겟 떨림/근접 경계 정체/회복 중 행동 방지.
5. 1~3배속 시간 보존과 프레임에 따른 회복량 차이 최소화.
6. 종별 역할·감지·서식지·귀환이 실제 전투 데이터와 연결됨.
7. 상태이상/치유의 대상·거리·만료가 일관됨.
8. 리셋/귀환/처치 과정의 보상은 일회성 유지.
