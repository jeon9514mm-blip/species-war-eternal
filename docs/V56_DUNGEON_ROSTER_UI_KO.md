# Pixel RPG v56 · 던전과 편성 UI 개선

던전 선택, 영웅 편성, 출전 준비와 레이드 화면을 정리했습니다. 콘텐츠 선택과 편성 변경을 연결하고, 보상·조건·전투 안내가 서로 겹치지 않도록 영역을 나눴습니다.

## 던전과 지역 선택

- 일일 던전·무한탑·주간 심연·목표 보상을 **4개 탭**으로 분리합니다. 선택한 콘텐츠의 상세만 표시합니다.
- 이번 도전의 실제 보상, 남은 횟수, 필요 전투력과 부족 조건을 보여줍니다. 편성이 비었거나 전투력이 부족하거나 횟수가 소진되면 도전 버튼을 비활성화합니다.
- 일일 던전·무한탑·주간 심연은 기존의 **조건 충족 시 즉시 완료** 규칙을 유지하며, 화면에도 이를 안내합니다.
- 사냥터와 지역 레이드는 **초원·광산·숲 선택 → 해당 지역 상세**로 표시합니다. 레이드 전용 세트·정수·전설 보장까지 남은 승수를 구분합니다.
- 던전에서 편성하고 완료하면 보고 있던 탭으로 돌아옵니다. 지역 레이드에서 편성하면 선택했던 보스의 준비 화면으로 돌아옵니다. 편성 완료만으로 전투를 시작하거나 보상을 지급하지 않습니다.

## 영웅 편성과 출전 준비

- 출전 슬롯 10개를 **5개씩 두 줄**로 표시해 가로 스크롤을 없앴습니다. 현재 해금된 최대 인원과 잠긴 슬롯의 해금 스테이지를 표시합니다.
- 역할 필터와 정렬을 서로 다른 줄로 분리하고 영웅 카드를 **3열**로 넓혔습니다. 이름·역할·레벨·등급·편성 버튼을 구분합니다.
- 미해금 영웅, 가득 찬 편성과 빈 편성의 버튼 상태를 명확히 표시합니다. 최소 한 명을 편성해야 완료할 수 있습니다.
- 영웅을 배치하거나 해제한 뒤 읽던 목록 스크롤 위치를 유지합니다.
- 편성 중 영웅 상세와 장비 상세를 보고 돌아와도 기존 던전 복귀 정보를 유지합니다. 캠프로 이동해 편성을 벗어나면 이 정보를 정리합니다.
- 편성 변경은 기존처럼 즉시 저장됩니다. 상단 뒤로가기는 변경을 취소하는 버튼이 아니며, 변경한 상태로 이전 콘텐츠에 돌아갑니다.
- 출전 준비에는 사냥 시작·편성 수정 버튼을 위에 두고, 영웅은 이름이 줄바꿈되는 **2열 카드**로 표시합니다.

## 레이드

- 보스 정보, 전투 장면, 보상, 공략·스킬 예고·결과, 액션 버튼, 10인 파티를 각각 분리합니다.
- 긴 전투 결과는 전용 영역 안에서 스크롤하며, 편성·시작 버튼과 영웅 슬롯을 밀어내지 않습니다.
- 영웅 이름을 키우고 체력바를 별도로 배치합니다. 전투불능 영웅은 초상을 어둡게 표시합니다.
- 진행 중에는 시작·편성 변경을 비활성화합니다. 화면 크기를 바꿔도 HP·경과 시간·전투 인스턴스와 버튼 상태를 유지합니다.

## 유지한 규칙

영웅 능력치, 전투 계산, 해금 조건, 던전 보상·도전 횟수, 레이드 장비와 정수 지급 규칙은 그대로입니다. v55 장비 상세·강화·옵션 추출·거래 기능도 유지합니다. 저장 형식은 31이며, 이번 변경에 별도 데이터 변환은 없습니다.

텍스트 높이·가로 넘침·버튼 글자·서로 다른 부모 아래의 글자 겹침과 주요 영역 충돌을 검사합니다. 긴 한글 이름, 큰 숫자, 긴 스킬 예고와 결과를 포함합니다. 물리 창은 320×568, 360×640, 720×1280, 810×1440, 720×1560에서 기존 720폭 캔버스 설정을 사용했습니다. 짧은 논리 화면 720×960도 통과했습니다. 지원 기준 밖인 논리 600폭 탐색에서도 발견된 문제는 없었지만, 이를 추가 지원 규격으로 선언하지 않습니다.

별도 레이드 검사도 3개 지역×3개 높이에서 103개 항목을 통과했습니다. 패치는 각각의 기준 소스에 적용한 뒤 변경 파일의 바이트 일치까지 검증합니다.

## 적용

현재 작업 소스에는 v56이 반영되어 있습니다. 자신의 소스 버전에 맞는 패치 **하나만** 적용하세요.

- `pixel-rpg-v56-from-v55.patch`: v55 장비 상세 UI까지 적용된 소스 기준.
- `pixel-rpg-v56-dungeon-ui.patch`: 최초 v46.1 원본 기준 누적 패치. 이전 사냥·장비·옵션·거래·진영전 개선을 포함합니다.

```bash
git apply --check /path/to/pixel-rpg-v56-from-v55.patch
git apply /path/to/pixel-rpg-v56-from-v55.patch
```

기존 소스와 플레이 저장을 따로 보관한 뒤 적용하세요. 개인 저장 파일과 Godot 실행 파일은 패치에 포함하지 않습니다.

Godot 4.7.2에서 프로젝트를 가져와 F5로 실행합니다. 시작 화면은 세로형 `PortraitMain.tscn`입니다. 검사를 다시 실행하려면:

```bash
python3 tools/run_tests.py --godot /path/to/Godot --jobs 4
```
