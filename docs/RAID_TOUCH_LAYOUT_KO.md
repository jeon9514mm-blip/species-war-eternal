# 레이드 터치 선택과 전장 겹침 수정

가로 화면에서도 영웅 선택 영역을 최소 128×108 논리 픽셀로 유지합니다. 10명을 모두 화면 너비에 억지로 줄여 넣던 방식 대신 공간이 부족하면 손가락으로 좌우 이동하는 목록을 사용합니다. 마지막 영웅도 완전히 표시해 선택할 수 있고, 드래그 종료와 취소된 터치는 영웅 선택으로 처리하지 않습니다. 명령 버튼과 하단 메뉴의 영역도 목록과 겹치지 않도록 검사했습니다.

전장의 실제 바닥 투영 위치를 측정해 회피·자동 추적 버튼 위에 여백을 둡니다. 1280×720 조건에서 바닥 아래쪽의 위치는 전장 내부 y=222.65에서 y=182로 올라가며, 회피 버튼은 y=192에서 시작합니다. 전장 높이 284는 유지합니다. 배우·공격 예고·터치 변환은 같은 카메라와 좌표를 사용하므로, 화면에서 누른 이동 위치와 전투에서 사용하는 목적지가 일치합니다.

화면 크기가 바뀌어 레이드 화면을 다시 만들 때도 선택한 영웅을 유지하며, 해당 카드가 보이도록 목록 위치를 조정합니다. 진행 중인 HP·쿨다운·보스 상태·지갑은 보존합니다.

두 진영, 세 레이드, 네 화면 크기에서 엔진의 실제 터치→마우스 변환을 이용한 852항목 검사를 통과했습니다. 좌우 드래그, 마지막 영웅 탭, 취소 터치, 전장 이동 탭, 회피 탭, 크기 변경, 바닥 모서리 투영과 버튼·목록·메뉴 겹침을 검사했습니다. 기존에 실패하던 전투 품질 검사도 669항목 모두 통과했고, 전투 좌표·레이드 전투·회피·일반 터치·맵 검사까지 총 7개 묶음 3,126항목을 통과했습니다.

[검사 기록](../checks/raid-touch-layout/validation.json)은 Godot 4.6.3 headless 결과입니다. Android 실기기 실행, APK 빌드, 프로젝트 기준 Godot 4.7.2 검사는 별도로 필요합니다.
