# V27 영웅 역할·스킬 마감 기록

## 구현 범위

## 마감 기준과 증거

| 기준 | 이 브랜치의 검증 |
|---|---|
| 20명 스킬이 실제 상태를 변경하고 정상적으로 쿨다운을 소모 | 양 진영 20명 각각 실행 통과 |
| 처형·정예 피해·연타 재선택·타격 대상 제한 | 실제 피해와 대상 HP로 검증 |
| 1인·2인·광역 회복 및 보호 범위 구별 | 아군별 HP·보호 상태로 검증 |
| 만피 치유·사망 아군·초과 피해 흡혈 방지 | 쿨다운·궁극기 보존, 사망 유지, 실제 피해 흡혈 검증 |
| 제어가 사거리 밖 적에게 전파되지 않음 | 기절·약화·취약 각각 근거리 2명/원거리 1명 경계 검증 |
| 중복 상태 재사용 억제 | 전원 보호 보존, 이미 제어된 대상 유지, 단일 저주 새 대상 재선택 검증 |
| 레이드가 필드와 같은 조건부 스킬을 사용 | 처형 보너스와 죽은 보스 자원 보존 검증 |
| 성장 시 전투 중 상태 보존 | HP 비율·사망·궁극기·보호·쿨다운·준비 동작 보존 검증 |
| 기존 AI·행동 안전성 회귀 없음 | 아래 기존 8개 스크립트 통과 |

- `V27HeroRolesSmokeTest.gd`: **49개 검사 통과**, exit 0, 스크립트 오류·종료 경고 없음.
- 기존 `SkillSmokeTest`, `V6CombatSmokeTest`, `V18CombatAISmokeTest`, `V19HeroAIIdentitySmokeTest`, `AutoCombatTacticsSmokeTest`, `HeroIdentityBalanceSmokeTest`, `V26ActionSafetySmokeTest`, `V26CombatDecisionSmokeTest`: 모두 exit 0 및 성공 마커 확인.
- `HeroIdentityBalanceSmokeTest`의 기존 수치 예산 진영 차이: 0.70%. 새 조건부 효과까지 포함한 실전 승률의 검증을 의미하지 않는다.
- 기존 `SkillSmokeTest`와 `V6CombatSmokeTest`는 종료 시 ObjectDB 객체 2개 경고를 출력한다. 새 검증과 다른 기존 6개는 해당 경고가 없다.
- 원본 실행 로그: `docs/v27-heroes-logs/`.

## 통합 계약

- `Main._apply_enemy_status(index, kind, duration)` / `_enemy_status_remaining(index, kind)` 및 `CombatStatusRules.gd`는 영웅 브랜치 제공. 지원 종류는 `stun`, `weaken`, `vulnerable`; 필드는 각각 `stun_seconds`, `weaken_seconds`, `vulnerable_seconds`. 죽은 적·잘못된 인덱스·음수·NaN 지속시간을 거부하며 지속시간을 합산하지 않는다.
- 필드의 개별 상태 시간 감소, 적 이동·행동 기절 차단, 개별 약화·취약 피해 반영은 메인 통합 담당 변경과 함께 사용한다. 이 브랜치 단독 검증은 상태 부여·범위·중복 방지를 검증한다.
- 모르가스는 편성 역할 `서포터`를 유지하되 `ultimate_role`은 `컨트롤러`. `_combat_action_needs_enemy`도 이 궁극기 역할을 사용해야 한다.
- 레이드 어댑터는 `_raid_apply_control(duration)`가 있으면 호출한다. 보스 담당 구현과 통합해 예고 취소·제어 면역을 처리한다. 없는 이전 버전에서는 기존 기절 타이머를 사용한다.
- 레이드 반환 피해는 실제 `hero_battle_state.attack` 기준 원시 피해다. 보스 담당 `_apply_raid_damage`가 취약 1.25배와 남은 HP 상한을 적용한다. 흡혈은 같은 배율과 상한으로 계산한다.
- `_refresh_hero_growth_stats()`는 성장 담당의 XP·장착·강화·스킬 투자·승급·돌파 성공 경로에서 호출한다. 전투 상태 전체를 보존하면서 계산 스탯·스킬 프로필·동료 레벨만 갱신한다.

## 남은 판단

이 기록은 초기 20명 핵심 전투 규칙의 구현·자동 검증 결과다. 필드 상태 피해·실제 성장 행동은 [전투 중 성장 통합 검사](V27_LIVE_GROWTH_KO.md), 레이드 예고 차단·수호·흡혈은 [레이드 통합 검사](V27_RAID_INTEGRATION_KO.md)로 확인했다. 양 진영 10인 × 3종 보스 전투 종료도 확인했으나, 모든 조합의 승률이나 긴 기간의 성장 밸런스를 증명하는 표본은 아니다. 장시간 플레이 체감, 영웅별 완성 애니메이션·음성·콘텐츠 다양성은 이 자동 검증의 범위 밖이다.
