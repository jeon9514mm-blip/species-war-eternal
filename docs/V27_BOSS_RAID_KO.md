## 실행 검증

Godot `4.7.2.stable.official.ed1daf0bf`, headless 실행. 각 스크립트에 독립 `XDG_DATA_HOME`을 지정해 실제 사용자 저장 상태에 의존하지 않았다.

- `V27BossLifecycleSmokeTest.gd`: 51개 판정. 양 진영 × 3개 지역 자연 자동 전투의 종료와 HP·시간 범위도 포함한다.
- 기존 `RaidSmokeTest.gd`, `BossEncounterSmokeTest.gd`, `SkillSmokeTest.gd`, `AutoCombatTacticsSmokeTest.gd`, `V26CombatDecisionSmokeTest.gd`, `V7SystemsSmokeTest.gd`, `V11ProgressionSmokeTest.gd`, `V18CombatAISmokeTest.gd` 회귀 실행.
- `V7SystemsSmokeTest`는 레이드 화면만 지정하고 보스 HP가 기본값 0이던 검증 준비를 수정하여 살아 있는 보스 HP 5000을 명시했다. 사망한 보스에 펫 피해를 허용하도록 게임 코드를 되돌리지 않았다.
- `git diff --check` 확인.

## 통합 계약

영웅 담당의 `_cast_hero_skill`, `_cast_raid_ultimate`는 원시 공격 피해를 반환한다. 보스 담당 `_apply_raid_damage`가 취약 배율 1.25와 남은 HP 제한을 적용한다. 흡혈은 이 배율과 남은 HP를 반영한 실제 피해를 기준으로 계산한다. 레이드 기절은 `_raid_apply_control(duration)`을 호출한다. 영웅 어댑터 통합 뒤 [실제 궁극기·차단·흡혈·수호·패배 연결 검사](V27_RAID_INTEGRATION_KO.md) 19개를 통과했다. 이전의 원정대 전투력 분배 기반 피해와 신규 영웅별 공격력 기반 피해의 클리어 시간은 같은 밸런스로 취급할 수 없다.

## 남은 검증 범위

- 이 문서는 로컬 단일 원정대 보스 시스템의 검증이다. 실시간 다중 사용자 협동 레이드나 서버 보상 원장은 이 변경에서 새로 구현하지 않았다.
- headless 화면 경계 검사는 수행했으나 Android 실제 기기의 터치·가독성·장시간 프레임 성능은 여기서 확인하지 않았다.
- 3개 보스와 현재 영웅·장비에 대한 기능 검증이며, 수치의 출시 적합성은 영웅 피해 공식 통합 후 전투 시뮬레이션 결과를 기준으로 별도 판단한다.
