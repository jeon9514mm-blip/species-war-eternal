# 레이드 전용 맵 디자인 1차 — Godot 4.7.2

사용자가 제공한 숲·협곡·유적 참고 이미지의 구조를 실제 3D 레이드 씬으로 구현했다. 작업 브랜치는 `preview/raid-arena-quality`이며, 이전 영웅 골격 작업을 포함한다. main 병합 전 검토용이다.

## 실제 레이드 연결

| 레이드 ID | 전용 맵 | 주요 미술 요소 |
|---|---|---|
| `gray_meadow` | 거목의 숲 성역 / EvergreenRaid | 거목·뿌리·폐허 관문, 낮은 이끼 돌담, 개울·폭포, 열린 잔디 전장 |
| `forgotten_mine` | 붉은 협곡 광산 / CrimsonRaid | 안팎 면이 있는 연속 절벽, 지층·돌출 바위, 목조 갱도·하역장·상자·철길, 호박색 수정과 등불 |
| `moonrest_forest` | 월식 유적 / ArcaneRaid | 경기장 가까운 아치 회랑·세로 홈 기둥, 뿌리·등나무 꽃, 수정 받침대, 차분한 달빛 돌바닥과 마법 문양 |

사냥의 기존 지역 연결은 유지하며 레이드 전용 선택표를 추가했다. 레이드 화면의 지역 이름도 전용 맵에 맞췄다. IceCavernRaid에는 얼음 관문·외곽 수정·빙결 바닥을 추가해 독립 갤러리에서 검토할 수 있다. 새 보스나 네 번째 레이드 해금은 추가하지 않았다.

## 구현 방식

`tools/RaidArenaArt.gd`는 저장 가능한 메시와 MultiMesh를 만들어 `RaidDesign` 아래에 배치한다. 기존 사냥용 바깥 장식을 보관하고, 레이드에서는 가까운 전용 구조물로 공간을 구분한다. 높은 구조물은 뒤와 양옆, 전면은 낮은 폐허·돌담으로 처리한다.

- `raid_ground.gdshader`: 잔디·토양·불규칙 돌바닥·균열·중앙 문양을 지역별로 조정. 실제 전투에서는 기존 `combat_readability` 연결로 대비와 발광을 낮춘다.
- `raid_crystal.gdshader`: 단색 발광 덩어리 대신 면별 밝기와 가장자리 반사 표현.
- `RaidArenaMood.gd`: 보스 페이즈·광폭화 상태를 읽어 외곽 수정과 주변 조명을 조정한다. 원래 밝기로 복구할 수 있으며 전투 수치를 쓰지 않는다.
- 그림자·접촉 음영·약한 안개·색온도를 지역마다 조정. 투명 안개 평면이나 영웅별 추가 뷰포트는 만들지 않는다.
- `MapGallery`에 레이드 보기 토글과 터치 드래그를 추가했다.

바닥 충돌과 레이드 이동 사각형, 경고 범위 투영, 영웅 골격, 피해·보상 로직을 유지한다. 협곡의 보이는 지면은 절벽 안쪽 원형 고원에 맞췄으며 실제 레이드 이동 사각형 전체를 덮는다. 장식에는 새 충돌체를 추가하지 않는다.

## 검토 화면

`checks/raid-quality/captures/`의 이미지는 생성형 콘셉트 그림이 아니라 실제 Godot Forward+ 캡처다.

- `Evergreen.png`, `Crimson.png`, `Arcane.png`, `IceCavern.png`: 동일한 검토 카메라로 렌더한 3D 씬.
- `<raid_id>-mobile.png`: 실제 세로 레이드 UI와 영웅·보스.
- `<raid_id>-warning.png`: 기존 보스 공격 패턴과 경고 오버레이가 표시된 검토 장면.

검토용 경고 캡처는 테스트 저장에서 실제 레이드를 시작한 후 시뮬레이션을 멈추고 지정한 패턴을 표시한다. 자연 진행이나 실기기 성능 측정 영상이라는 의미는 아니다.

## 재현

```sh
godot --path . --script tools/polish_raid_maps.gd
godot --path . --script tools/capture_raid_art.gd
godot --path . --script tools/capture_raid_battles.gd
godot --headless --path . --script scripts/RaidArenaQualitySmokeTest.gd
```

제작/저장은 실제 렌더러에서 실행해야 MultiMesh의 저장 버퍼가 보존된다. `MapArtPolish.gd`에도 레이드 미술 호출을 연결했으므로 전체 맵 재생성 시 전용 장식이 다시 만들어진다.

새 검사는 레이드별 씬·재질 선택, 장식 저장 버퍼, 평평한 이동 영역의 충돌, 새 충돌 장애물 부재, 페이즈 조명 복구를 확인한다. 기존 맵 로더·카메라·경고 좌표·영웅 골격·자연 레이드 집계 검사도 실행한다. 최종 결과는 `checks/raid-quality/regression.json`에 보관한다.

381개 GDScript 구문 검사와 7개 실행 검사가 통과했다. 추가한 모바일 캡처 도구도 별도로 구문 검증했다. 맵·충돌·경고 좌표·영웅 골격·자연 레이드 동작의 세부 검사 합계는 3,841개이며, Python 아키텍처 검사 12개도 통과했다.

## 검증 범위

Godot 4.7.2와 소프트웨어 Vulkan Forward+ 기준이다. 모바일 화면 크기로 렌더한 결과와 Android 실기기 실행은 다르며, 실기기 FPS·발열·장시간 메모리 측정은 아직 하지 않았다. 참고 이미지와 같은 손그림 원화나 고유 3D 에셋을 모두 새로 제작한 단계는 아니다. 현재 구현은 보유한 텍스처·절차적 구조물로 만든 첫 레이드 미술 패스다.
