# v32 픽셀 그래픽 업그레이드

2026-09-23. 사용자가 제시한 16/32-bit RPG, SNES 감성, 디더링 명암, 선명한 외곽선과 색 대비를 기준으로 기존 게임의 아트를 교체했습니다. 초원과 마을은 밝고 귀여운 분위기를 유지하며, 광산·달빛 숲에는 지역별 보라·청록 조명을 적용했습니다.

## 게임에 적용한 내용

| 영역 | 적용 범위 |
|---|---|
| 지역·마을 | 회색 초원·잊힌 광산·달잠 숲 3개 필드와 원정대 마을 배경. 타이틀·기기 로그인에는 마을, 로비에는 현재 사냥터 이미지 연결 |
| 영웅 | 기존 30명 정체성을 유지한 새 초상화 30개와 스킬 아이콘 120개 |
| 전투 캐릭터 | 카이렌의 대기·보행 2장·시전 4포즈 신규 원화. 나머지 29명은 기존 애니메이션 유지. 30명 모두 절제된 공용 색상 마감 적용 |
| 몬스터·보스 | 기존 일반 몬스터 13종·보스 3종에 각각 대기·보행 2장·공격 4포즈, 총 64포즈. 월식의 여왕 등 기존 보스 설정 유지 |
| 장비 | 12개 픽셀 아이콘 원화 중 실제 장비 9종과 시작 장비 2종에 연결. 화염 지팡이 1종은 미사용 아트 예시이며 새 아이템으로 추가하지 않음 |
| 마법 효과 | 화염·번개·치유·보호막 각 4프레임. 카엘룸·테사·엘리시아·셀레네의 실제 효과 종류에 맞춰 추가. 기존 30명 전용 모티프와 120개 발동 아이콘 유지 |
| UI | 크림·세이지 패널과 버튼의 선명한 테두리, 장비 아이콘, 지역 배경을 적용. 한글 읽기 편한 기존 폰트 유지 |

## 실제 동작과 호환

- 필드 이동 공간은 기존 32×20이며 기존 이동 사냥·장애물·전투 판정을 유지합니다.
- 광산·숲의 장식 벽·나무는 이동 영역 밖에 배치하고 카메라가 그 외곽 원화를 볼 수 있도록 시각 범위만 넓혔습니다. 초원의 카메라 범위는 유지합니다.
- 지형 밝기 90%, 채도 88%를 유지합니다. 이미지 보간은 nearest를 사용합니다.
- 몬스터는 원본 알파 0.5 미만의 가장자리 잔상을 셰이더에서 제거합니다. 이후 노드 투명도를 적용하여 사망 페이드가 유지됩니다. 영웅 알파에는 이 임계값을 적용하지 않습니다.
- 진영별 15명, 역할 8/4/3, 영웅당 액티브 2·패시브 1·궁극기 1, 스킬 수치·저장 형식은 유지합니다.
- 전투 FX OFF·일시정지·재개와 실제 대상 위치에 따른 연출 경로를 유지합니다.

## 원본과 검증 기록

새 아트는 `assets/backgrounds/pixel-v32`, `assets/heroes/pixel-v32`, `assets/sprites/pixel-v32`, `assets/monsters/pixel-v32`, `assets/ui/pixel-v32`, `assets/fx/pixel-v32`에 있습니다. 생성 프롬프트·원본 해시·아틀라스 영역은 관련 JSON에 기록했습니다. 원본 PNG를 보관하고 엔진의 AtlasTexture로 영역을 읽습니다.

실행·연결 검증은 Godot 4.7.2 headless 모드에서 수행합니다. `v32-graphics-runtime.json`, `v32-hero-art-validation.json`, `v32-mechanics-baseline.json`과 최종 검증 요약을 함께 확인하세요. 최종 ZIP은 전체 파일의 CRC와 SHA-256 일치를 검사한 독립 실행용 소스 프로젝트입니다.

## 구분해야 할 범위

- 채팅에 표시한 두 장은 새 원화로 구성한 그래픽 미리보기입니다. 실제 엔진 화면 캡처는 아닙니다. 실기기에서의 최종 시각 검수는 남아 있습니다.
- 필드 배경은 전체 맵 원화이며 모든 가장자리가 연결되는 자동 타일셋은 아닙니다.
- 30명 모두의 전투 애니메이션을 새로 그린 버전은 아닙니다. 이번 신규 영웅 전투 원화는 카이렌 1명입니다.
- 120개 스킬 아이콘이 모두 새로 적용되었지만, 120개 전체에 독립적인 신규 다프레임 VFX를 만든 것은 아닙니다.
- 로그인은 기존 기기 저장 기반이며 계정 인증·클라우드 저장을 추가하지 않았습니다. APK와 Windows 실행 파일은 별도 빌드가 필요합니다.
