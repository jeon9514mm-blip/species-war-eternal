# V27 영웅·성장·필드 상태 통합 검증

`V27LiveGrowthSmokeTest.gd`를 통합 프로젝트에서 Godot 4.7.2 headless로 실행했다. **34개 검사 전부 통과**, exit 0, 스크립트 오류·종료 경고 없음.

스탯 보존 헬퍼를 직접 호출하는 대신 실제 게임 행동 함수로 검증한다.

| 실제 호출 경로 | 검증한 결과 |
|---|---|
| `_grant_hero_xp(10800)` | 3인에게 정확히 분배해 Lv.1→10, 전투 중 공격력·최대 HP 즉시 증가 |
| `_enhance_equipment(hero, "weapon")` | 무기 +1→+2, 골드 정확히 175 차감, 전투 공격력 즉시 증가 |
| `_equip_inventory_item(0, hero, item_id)` | 전설 +6 무기 장착, 공격력·최대 HP 즉시 증가, 기존 +2 장비 보존 |
| `_upgrade_skill_tree(hero, "offense")` | 스킬 포인트 사용 후 전투 공격력 증가 |
| `_upgrade_skill_tree(hero, "survival")` | 스킬 포인트 사용 후 전투 최대 HP·방어력 증가 |
| `_upgrade_skill_tree(hero, "utility")` | 다음 스킬의 설정 쿨다운 감소, 현재 남은 쿨다운은 보존 |

위 6개 행동마다 다음을 함께 확인했다.

- 활성 전투와 영웅 상태가 유지된다.
- 살아 있는 영웅의 HP 비율이 정수 반올림 오차 이내로 유지된다.
- 이미 쓰러진 영웅은 HP 0·사망 상태를 유지한다.
- 궁극기 게이지, 보호·도발 지속시간이 유지된다.
- 스킬·기본 공격 쿨다운, 이미 시작한 준비 동작과 선택 대상이 유지된다.
- 원정대 좌표와 동료 공격 타이머가 유지된다.

추가 필드 연계 4개 검증:

1. 루네아의 실제 스킬이 사거리 안 적에게만 약화를 부여한다.
2. 약화된 적에게서 받는 실제 피해만 감소한다.
3. 개별 취약 대상에게만 실제 피해 1.25배가 적용된다.
4. 시간 경과로 상태가 만료되면 받는 피해와 주는 피해 모두 기본값으로 복귀한다.

검증 전 코드 점검에서 장착·스킬 투자 후 화면 재생성이 전투 상태를 지우는 연결 문제를 확인했다. 메인 통합 담당이 전투·레이드 중에는 화면 재생성을 생략하고 관련 표시만 갱신하도록 수정했으며, 이 검증은 해당 수정이 포함된 실제 호출 경로를 통과했다.

실행 결과:

```text
v27_live_growth_smoke_test checks=34 passed=34 failures=[]
```

테스트 저장 데이터는 `XDG_DATA_HOME=/tmp/v27-live-growth-check`로 격리했다. 이 작업은 새 테스트와 이 기록만 작성했으며, `Main.gd` 수정이나 Git 커밋은 수행하지 않았다. 보스 제어 면역·레이드 전투 밸런스는 이 테스트의 범위 밖이다.
