# V61 · 세 사냥터 그래픽, 역할 장비, 영웅 2D 모션

기준: V60 초원 시범 구간. 현재 세로 화면의 사냥터 세 곳에 적용했다. 기존 영웅 ID·성장·스킬·자동사냥·레이드·전투 피해 계산은 유지한다.

| 사냥터 | 기존 배경 | 앞뒤 지형 소품 | 사냥 장비 세트 |
| --- | --- | --- | --- |
| 회색 초원 | V60 밝은 초원 | 장애물 좌표와 연결된 나무 11개 | 개척자 |
| 잊힌 광산 | 기존 채색 광산 바닥 + 지하 갱도 헤더 | 가장자리 수정 기둥 8개 | 강철 |
| 달잠 숲 | 기존 채색 숲길 + 밤하늘 헤더 | 가장자리 달빛 나무 8개 | 월광 |

세 곳 모두 영웅과 몬스터의 접지 그림자, 적 처치 보상 파편, 카메라와 동기화된 소품 깊이를 적용했다. 광산과 숲 소품은 이동 판정을 새로 만들지 않는 장식이다.

각 사냥터에서 **딜러·방어·보조** 전용 장비가 각각 드롭된다. 역할 세 종류의 선택 확률은 동일하다. 딜러 장비는 딜러, 방어 장비는 탱커, 보조 장비는 서포터·컨트롤러에게만 장착된다. 희귀 이상 사냥 장비에는 각각 공격력·체력·궁극기 충전 옵션이 붙는다. 지역 세트, 출처, 거래 상태, 옵션 추출은 기존 체계를 유지하고, 장비의 `hunt_role`을 저장·거래 경로에서 보존한다. 기존 장비와 레이드 장비는 역할 제한이 없다.

배치된 영웅에게 공격·피격·이동·대기 상태로 움직이는 어깨, 팔꿈치, 보조 손, 망토 관절 레이어를 추가했다. 손의 장비 외형은 역할군에 따라 달라지며, 기존 영웅별 행동 그림을 동시에 재생한다. 관절은 화면 표현만 바꾸고 전투 좌표나 판정에는 관여하지 않는다. **현재 단계는 30명 각자의 완전한 전신 분할 스켈레톤 제작이 아니라, 기존 영웅 그림 위에 얹는 독립 관절 2D 모션**이다.
