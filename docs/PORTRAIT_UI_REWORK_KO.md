# v32 기반 세로 UI 작업본

시작 씬은 `scenes/PortraitMain.tscn`, 화면 기준은 720×1280 세로입니다.

원본 v32의 Main.gd와 게임 규칙/영웅/스킬/에셋/테스트 파일은 수정하지 않았습니다. 원본 546개 파일을 SHA-256으로 비교했으며 변경 파일은 project.godot 하나입니다. 새 UI는 scripts/portrait 아래의 표현 전용 하위 클래스로 구현했습니다.

## 실제 검증

- 업로드된 Godot 실행파일: 4.7.2.stable.official.ed1daf0bf
- 새 세로 UI 및 동작 검사: 80/80 통과
- 기존 테스트: 77/79 통과. 가로 방향을 강제하는 V24 검사 및 원본 가로 Main 카메라의 V32 검사는 세로 설정과 충돌하며, 통과로 표기하지 않았습니다. 원본 테스트는 삭제/수정하지 않았습니다.
- 세로 방향, 720×1280/1440/1560 리사이즈, 10인 HP/궁극기 표시, 자동추적, 두 진영 동일 시드 전투 결과 일치, 세 지역 카메라 끝 배경/좌표, 레이드/영토전/메뉴 연결을 별도 검사했습니다.
- 720×1280 및 720×1560의 실제 렌더링 화면을 캡처했습니다.

이 작업은 UI/배경 아트 1차 구현입니다. 실제 Android APK/기기별 노치·성능 검증은 이번 범위에 포함하지 않았습니다. ZIP은 생성하지 않았습니다.
