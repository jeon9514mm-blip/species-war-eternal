# v12 종의전쟁 월드맵 프로토타입

v12는 기존 개인 자동사냥 RPG에 **진영 영토전 레이어**를 처음 연결하는 버전입니다.
이번 버전은 범위를 의도적으로 좁혀, 네트워크 PvP나 행군 시간을 한꺼번에 섞지 않고 월드맵의 데이터 구조와 점령 루프부터 검증합니다.

## 구현 범위

- 20×20 = 400 타일 전쟁 월드
- 아우렐리아(휴먼·엘프) / 녹스페라(뱀파이어·늑대인간) 수도
- 양 진영 3×3 시작 영토
- 평원 / 숲 / 구릉 지형
- 수정 광산 / 마력 숲 / 고대 유적 / 전선 요새 / 중앙 대성 랜드마크
- 플레이어의 10인 원정대를 월드맵에서 **부대 1개**로 표현
- 아군 인접 타일 이동
- 현재 부대와 인접한 중립 타일 점령
- 점령 즉시 소유색 변경 및 개인 점령 횟수 기록
- 우리/적 영토 수, 전선 타일 수 표시
- 월드전 상태 저장/복원
- 하단 메뉴에 `전쟁` 진입점 추가

## 아직 구현하지 않는 것

아래 기능은 소스 구조가 섞이지 않도록 이후 버전으로 분리합니다.

- v13: 행군 시간, 군량, 출정/귀환 명령, 주둔
- v14: 플레이어 부대 vs 플레이어 부대 비동기 10vs10 전투
- v15: 지원, 집결, 요새 효과, 보급선 연결/차단
- v16: 시즌 점수, 개인 공헌도, 시즌 초기화/보상, 서버 동기화 어댑터

현재 적 진영 타일을 선택하면 전투를 즉시 실행하지 않고 PvP 연결 예정 상태로 표시합니다.
