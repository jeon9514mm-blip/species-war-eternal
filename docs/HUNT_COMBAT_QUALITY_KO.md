# 자동 사냥 전투 개선

자동 사냥과 개별 영웅의 역할을 유지하면서, 공격 대상·공격 예고·화면 표현을 일치시켰다. 기본 메뉴와 F6 아트 실험 화면의 자산은 변경하지 않는다.

## 비교 근거

공식 배급사 소개를 읽고 다음 특징을 적용 대상으로 삼았다. 직접 플레이하거나 트레일러를 분석했다는 의미는 아니다. 원문과 주소는 `checks/hunt-quality/comparison-sources.json`에 보관했다.

| 게임 | 공식 소개의 특징 | 이번 적용 |
|---|---|---|
| 세븐나이츠 키우기 | 자동 전투, 최대 10명 파티 | 자동 사냥 유지, 다인 교전의 간격과 화면 가독성 |
| AFK Journey | 여섯 역할, 배치, 궁극기 타이밍 | 역할별 이동 유지, 실제 준비한 대상을 향한 타격 |
| Torchlight: Infinite | 근접·마법·원거리 공격, 효과 밝기·투명도 설정 | 근접 궤적과 원거리 탄도 구분, 효과 설정 연동 |

## 변경된 행동

- 영웅은 준비할 때 고른 적을 타격한다. 적이 죽거나 사정거리 밖으로 나가면 다른 적으로 순간 변경하지 않고 다시 준비한다. 치유·방어의 필요성은 기존처럼 타격 직전에 다시 평가한다.
- 일반 사냥 몬스터의 공격 간격 마지막 0.22초를 준비 구간으로 사용한다. 방향 표시와 몸의 전진을 보여주고, 이동을 잠깐 멈춘 뒤 접촉한다. 기존 공격 간격에 별도 대기 시간을 추가하지 않는다.
- 준비한 영웅이 멀어지거나 몬스터가 기절하면 준비를 취소한다. 영웅이 아무도 공격할 수 없는 이동 단계에서도 취소해 몬스터가 멈춘 채 남지 않게 한다.
- 같은 영웅에게 접근하는 적은 접촉 자리 두 곳과 바깥 대기 원을 이용한다. 장애물 반대편에 접촉 자리가 잡히면 영웅 쪽의 통로를 다시 고른다. 원거리 적의 근접 회피는 유지한다.
- 침입 몬스터와 영웅의 추적에 같은 전장 이동 규칙을 적용한다. 예전 서식지 제한이 전장 이동과 충돌해 단독 영웅의 사냥이 멈추던 경우를 해결한다.
- 전멸 시 적의 HP와 공격 상태를 동결한다. 재정비가 끝나면 오래된 공격 준비를 취소하고 새로운 준비 시간을 확보한다.

## 화면과 타격 표현

- 생존한 모든 영웅·몬스터가 보이도록 카메라를 유지하면서 가까운 교전의 최소 확대 범위를 줄인다. 전체 전장 보기 버튼은 그대로 제공한다.
- 몬스터 아틀라스의 크기 보정값을 실제 덩치 보너스로 잘못 적용하던 계산을 수정한다.
- 하나의 전장 캔버스가 카메라 좌표로 근접 궤적, 준비 중 날아가는 탄도, 방향을 가진 타격을 그린다. 피해와 보상은 기존 시뮬레이션만 계산하며 시각 효과 타이머가 피해를 발생시키지 않는다. 동시 타격 표시는 최대 32개다.
- 일반 적 처치마다 화면 전체를 흔들거나 큰 파편 효과를 반복하지 않는다. 중요한 충격은 월드 카메라에만 적용하고 HUD·터치 좌표를 고정한다.
- 피격 때문에 적이 강제로 왼쪽을 바라보던 동작을 제거한다. 영웅의 공격 포즈를 타격 준비 시간에 맞추고, 2배속·일시정지·앱 중단·우편 대기에 시각 시계를 연동한다.
- 피해 숫자는 실제 전장 영역에 배치하고 일반 숫자 크기와 겹침을 줄인다. 치명타 숫자를 별도로 읽고, 영웅의 HP 피해와 적의 피해 색을 구분한다.

## 검증 범위

Godot 4.6.3 Linux에서 임시 XDG 저장소로 검사했다. 검증 결과와 로그는 `checks/hunt-quality`에 보관한다. 두 진영, 1·3·10명 파티, 8방향 진입, 장시간 반복 교전, 전멸·재정비, 대상 사망·거리 이탈·기절, 2배속·정지, 전장 보기, 터치 스크롤, 우편 용량 보호를 확인한다. 공격력·장비 보상 수량·우편 한도는 변경하지 않았으나 접근 방식이 달라져 시간당 사냥 효율은 달라질 수 있다.

별도로 실행한 오래된 검사 세 가지는 기준 커밋 f73e568에서도 같은 실패가 재현된다: V51 레이드 반격(8), V53 과거 순찰 복귀(1), V63 과거 보상 UI/정산 fixture(3). 이 실패를 이번 수정의 통과 항목으로 계산하지 않는다. 기준/현재 로그를 함께 보관한다. 현재 V51 실행에는 종료 시 리소스 1개가 남았다는 엔진 진단도 추가로 나타났으며, 이를 기준 실패와 구분해 기록했다.

실제 Android 기기의 터치·배터리·프레임 성능 및 출시용 Godot 버전에서의 검증은 아직 수행하지 않았다. 캡처는 데스크톱 소프트웨어 렌더러의 화면 확인 자료이며 모바일 성능 측정 자료가 아니다.

## 화면 확인 도구

`tools/capture_hunt_quality.gd`를 임시 XDG 환경과 X11 디스플레이에서 실행한다. `HUNT_CAPTURE_COUNT`(기본 3), `HUNT_CAPTURE_SMALL_SCREEN=1`(720×405 가로), `HUNT_CAPTURE_DIR`로 검토용 구성을 정할 수 있다. 별도 저장 파일을 쓰며 생산 게임 저장에는 사용하지 않는다.
