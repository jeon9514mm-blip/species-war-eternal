# v22 전투 HUD · 월드맵 · 전쟁 UI 업그레이드

## 전투 HUD
실시간 배회 자동사냥의 핵심 상태를 상단 4개 칩으로 분리했습니다.

- 사냥 상태: 자유 순찰 / 추격 / 교전 / 회복 + 격파 횟수
- 원정대: 생존 인원과 HP 퍼센트
- 교전 대상: 현재 적 이름과 생존 수
- 스테이지: 현재 스테이지와 처치 진행도

기존처럼 긴 한 줄 텍스트를 읽지 않아도 전투 상태를 즉시 파악할 수 있습니다.

## 월드맵
상단에 4개 원정 대시보드를 추가했습니다.

- 해금 지역 수
- 현재 선택 지역 / 난이도
- 원정대 인원 / 전투력 / 역할 구성
- 보스 누적 클리어 기록

지역 카드는 하단에 정렬해 `상태 확인 → 지역 비교 → 출격` 흐름을 명확하게 했습니다.

## 영웅 편성
영웅 수가 늘어도 빠르게 찾을 수 있도록 탐색 도구를 추가했습니다.

- 역할 필터: 전체 / 탱커 / 딜러 / 서포터 / 컨트롤러
- 정렬: 등급 / 레벨 / 전투력
- 카드 테두리: R / SR / SSR / UR 등급 색상
- 카드 내부에 등급 + 역할 그룹 표시

필터/정렬 변경은 편성 화면을 즉시 재구성하며 현재 파티는 유지됩니다.

## 종의전쟁
기존 긴 상태 문장을 4개 지휘 지표로 분리했습니다.

- 시즌 점수 / 개인 공헌
- 우리/적 영토 수
- 군량 / 피로도
- 서버 연결상태 / revision / sync

아래에는 시즌 상태, 고립 영토, 열세 진영 버프를 요약하고 기존 타일 명령·지원·집결·귀환 기능은 유지합니다.

## UI 방향
v21의 공통 헤더/대시보드 디자인을 v22에서 실제 플레이 핵심 화면까지 확장했습니다. 정보 밀도는 유지하되 플레이어가 판단에 필요한 항목을 카드·칩 단위로 분리하는 방향입니다.
