# 게임플레이 안정성과 사냥 진행 개선

저장 실패 후 재화를 계속 소비하는 동작, 자동 입금과 맞지 않는 초반 가이드, 큰 부대의 추가 무리가 보상에서 빠지는 계산을 수정했습니다. 오프라인 사냥은 실제 격파 속도를 참고하며 후반 일반 사냥의 난이도와 보상이 점진적으로 증가합니다.

## 저장 실패 중 조작

`SaveSafety`의 공통 규칙으로 영웅·수호신 소환, 승급, 돌파, 수호신 교체, 수동·일괄 장비 강화, 추천 장착, 공방·추출·이식·거래, 일일·지원·오프라인 보상 수령을 보호합니다. 저장 대기, 더 최신 버전의 저장본, 연습 중에는 해당 조작이 재화나 난수를 소비하지 않습니다. 저장 실패를 일으킨 첫 동작의 결과는 기존 방식대로 메모리에 보존하고, 재시도는 현재 기록만 저장합니다. 저장 성공 후에는 조작을 다시 할 수 있습니다.

## 초반 안내와 부대 보상

초반 4/6 안내는 온라인 보상이 자동 입금된다는 점과 스테이지 2 도달 목표를 설명합니다. `목표 화면으로 이동`은 사냥으로 진입합니다.

15마리 부대의 보상 단위는 기존처럼 3무리입니다. 16~20마리 부대는 마지막 부분 무리까지 포함해 4무리로 정산하며 골드·영웅 경험치·장비 탐색·목표·스테이지 진행에 같은 단위를 적용합니다. 부대 입장 간격, 2부대/25마리 상한과 일회성 정산 규칙은 유지합니다.

## 오프라인 사냥 기준

`HuntProductivity`는 일반 사냥에서 최소 12무리를 실제로 격파한 뒤 경과 게임 시간으로 무리당 시간을 기록합니다. 재정비에 쓰는 시간도 포함하며 일시정지 시간과 던전·레이드·연습 전투는 포함하지 않습니다. 기록은 진영과 지역별로 저장하고 편성·진형·장비·연구·수호신·자동 스킬 설정을 구분합니다. 기록보다 전투력이 10% 이상 낮아지면 재사용하지 않습니다. 이후 스테이지의 몬스터가 강해졌을 때는 기록된 시간을 그 난이도 증가에 맞춰 늘립니다.

오프라인 계산은 기존 보수적인 예상 속도와 실제 기록 중 느린 쪽을 사용합니다. 검증된 기록이 없는 새 지역이나 변경한 편성은 기본 전장 보상으로 계산하고, 선택한 온라인 지역은 바꾸지 않습니다. 기본 전장 자체의 미측정 지급은 기존 저장본과 신규 플레이어를 위한 초기 보상입니다. 보상창에서 적용한 지역과 기준을 확인할 수 있습니다.

8시간 상한, 기본 골드·경험치 88% 지급, 최대 5스테이지 진행, 최대 32회 장비 탐색을 유지합니다. 온라인 처치 수를 오프라인 목표 진행에 새로 추가하지 않습니다. 이전 저장본에 사냥 기록이 없으면 빈 기록으로 시작하며 기존 영웅·장비·재화는 유지합니다. 저장 버전 37에 선택적인 기록 필드를 추가한 것으로 별도 저장 파일을 만들지 않습니다.

## 후반 난이도와 검증

각 지역의 해금 후 첫 28스테이지는 기존 난이도 계산을 사용합니다. 그 이후에는 `0.15 × ln(1 + 추가 진행 / 28)`만큼 체력 배율을 점진적으로 늘리고 공격력은 기존처럼 그 제곱근을 따릅니다. 추가 일반 사냥 보상 배율은 `sqrt(난이도 배율 / 1.35)`이며 1 미만이 되지 않습니다. 레이드의 10배 강화 수치와 해금 조건은 변경하지 않습니다.

`GameplayReliabilitySmokeTest.gd`는 두 진영에서 저장 실패와 재시도, 가이드의 실제 버튼 이동, 15~20마리 보상, 실제 저장·복원, 오프라인 기준 변경, 자연스러운 HP 전투의 사냥 기록을 검사합니다. 기존 부대·저장·성장·도메인·연습·장비·연구·레이드 회귀도 실행했습니다. 최종 집계는 [검증 결과](../checks/gameplay-reliability/validation.json)에 있습니다.

이번 실행 환경의 엔진은 **Godot 4.6.3**입니다. 저장소의 목표인 4.7.2와 Android 실기기에서의 플레이·성능·장기 밸런스 검증을 대신하지 않습니다. 새 난이도와 오프라인 수치는 후속 실제 플레이 기록에 맞춰 추가 조정할 수 있습니다.

재현 시 기존 저장과 분리된 경로를 사용합니다.

```bash
XDG_DATA_HOME=/tmp/species-gameplay-check \
XDG_CACHE_HOME=/tmp/species-gameplay-cache \
XDG_CONFIG_HOME=/tmp/species-gameplay-config \
godot --headless --path . --script scripts/GameplayReliabilitySmokeTest.gd
```
