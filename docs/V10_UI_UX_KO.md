# v10 모바일 UI/UX 리뉴얼

v10은 v9의 메타게임 기능을 유지하면서 화면 이동과 정보 구조를 상용 모바일 방치형 RPG에 가까운 형태로 재정리한 버전입니다.

## 주요 변경

- 로비/영웅/월드/성장/소환 5개 하단 고정 내비게이션
- 수령 가능한 퀘스트와 소환 가능 상태를 하단 메뉴 배지로 표시
- 지역 해금, 권장 전투력, 보스, 보상을 한 화면에서 보는 월드맵
- 해금된 지역 보스를 직접 선택하는 보스 선택 화면
- 영웅 카드에서 바로 진입하는 영웅 상세 화면
- 실제 발견/미발견 상태, 레벨, 돌파, 조각을 보여주는 영웅 도감
- 소환 직후 영웅 스프라이트와 획득 조각을 보여주는 소환 결과 연출
- 장비 인벤토리 추천장착
- 현재 원정대 장착장비 일괄강화
- 자동분해 등급을 실제 장비 데이터(일반/희귀/전설)와 통일
- v9의 영문 자동분해 저장값을 v10에서 자동 마이그레이션
- 전투 화면에서 월드맵으로 즉시 이동
- 레이드 종료/뒤로가기 흐름을 보스 선택 화면 중심으로 정리

## UI 원칙

메뉴 개수를 늘리기보다 핵심 루프를 5개 축으로 고정했습니다. 플레이어가 어디에 있든 `로비 → 영웅 → 월드 → 성장 → 소환`의 위치 관계를 이해할 수 있게 하고, 세부 기능은 각 축 안으로 배치합니다. 전투 화면은 전투 정보 밀도를 유지하기 위해 하단 메뉴를 강제로 덮지 않고 월드맵 바로가기만 제공합니다.

## 검증

`V10UiUxSmokeTest.gd`에서 하단 내비게이션, 월드맵, 영웅 상세, 도감, 추천장착, 일괄강화, 소환 연출, 퀘스트 배지, 자동분해를 검증합니다.

현재 패키징 환경에는 Godot 실행 바이너리가 기본 설치되어 있지 않아 실제 엔진 런타임 검증은 별도 실행이 필요합니다. 정적 검사기는 리소스 참조, 중복 함수, 테스트 진입점, 문서 링크를 검사합니다.
