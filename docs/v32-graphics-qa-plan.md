# v32 그래픽 검증 범위

이번 검증은 그래픽 교체가 기존 전투·성장·탐색·저장을 바꾸지 않는지 확인한다. 화면 캡처와 실제 기기에서의 시각적 품질 검증을 완료했다는 의미가 아니다.

## 변경 자산

- 지역 배경 3개와 캠프 배경: 실제 게임 화면이 신규 경로를 사용하고 월드 좌표와 카메라 변환을 유지하는지 검사한다.
- 영웅: 30명의 초상화와 120개 스킬 아이콘이 각각 고유한 원본 영역에 연결되는지 검사한다. 카이렌의 신규 4개 전투 포즈와 기존 영웅들의 발 기준점, 작은 필드 크기, 애니메이션 종료 동작을 유지한다.
- 몬스터: 기존 16종을 모두 신규 4포즈 아틀라스로 연결하고 필드·레이드·초상화 경로에서 누락이 없는지 검사한다. 투명 배경, 이미지 안쪽의 자르기 영역, 옆 캐릭터 혼입, 이동/공격 프레임과 사망·복귀 동작을 검사한다.
- 장비 아이콘과 VFX: 신규 아이콘 12개, 원소 효과 4종 × 4프레임이 고유하고 비어 있지 않은지 검사한다. 실제 대상·타격 수·스킬 상태를 바꾸지 않고, 일시 정지·화면 이동·효과 끄기·수명 종료 때 정리되는지 검사한다.
- UI: 시작·로그인·메뉴의 한국어 폰트, 본문 대비, 터치 크기, 화면 경계 및 기존 화면 전환을 검사한다.

## 기존 검사 조정 원칙

신규 아트로 바뀌는 경로와 레이아웃 이름만 갱신한다. 프레임 고유성·픽셀 필터·발 기준·캐릭터 크기·대상 수·전투 상태 불변 조건은 유지한다. v31의 `6장 × 20포즈` 고정값은 카이렌 전용 아틀라스가 추가되므로 실제 소유 영웅 수에 따른 검증으로 바꾼다. v28의 몬스터 `bright` 레이아웃 조건은 `pixel_v32` 기준으로 갱신한다.

## 한계

헤드리스 Godot 검사는 이미지 연결과 UI/전투 기하 구조를 확인한다. GPU 셰이더 출력, 움직임의 미적 품질, 실제 모바일 기기에서의 선명도와 프레임률은 별도 실기기 검수가 필요하다. 공개 미리보기는 생성된 실제 소스 아트이며 게임 실행 캡처로 표시하지 않는다.
