# 레이드 전장·UI 개선 — 2026-10-04

사용자가 세 전장 시안을 확인하고 “그 시안대로, 퀄리티 우선”으로 기본 적용을 승인했습니다. 일반 실행의 레이드 진입과 화면 크기 변경 모두 새 화면을 사용합니다.

## 바뀐 화면

| 보스 지역 | 전장 | 디자인 |
|---|---|---|
| gray_meadow | 거목의 성역 | 큰 나무, 폭포, 이끼 낀 석조 유적, 금빛 숲 |
| forgotten_mine | 수정 용광로 | 검은 현무암, 주황 용광로, 수정 광맥, 쇠사슬 |
| moonrest_forest | 월식의 정원 | 달빛 유적, 보랏빛 수정, 물안개, 폐허의 아치 |

세 배경은 새로 제작한 원화입니다. 고정 원화에 가장자리의 미세한 입자와 기존 3D 공간의 영웅·보스 빌보드를 결합한 2.5D 화면입니다. 입체 모델로 새로 제작한 보스나 다층 패럴랙스 지형은 아닙니다. 세븐나이츠·쿠키런 계열에서 기대하는 보스 중심의 읽기 쉬운 구성을 참고했으며, 해당 게임의 원화나 UI 자산을 복사하지 않았습니다.

- 1280×720 기준 전장 폭을 약 778px에서 1256px로, 높이를 284px에서 438px로 확대했습니다.
- 상단에는 보스 이름·HP·페이즈·시간을, 하단에는 실제 전투 버튼과 영웅 선택을 배치했습니다.
- 공략·자동 시전 설정·편성·기여도·보상 설명은 오른쪽 시트에서 접근합니다. 공격 예고의 대응법은 전장에서도 바로 보입니다.
- 영웅 카드는 최소 128×108 크기를 유지합니다. 스크롤바의 높이 때문에 카드가 화면 아래로 나가던 문제를 수정하고 터치·휠 스크롤을 유지했습니다.
- 공략 창 바깥을 눌러 닫을 때 같은 터치가 바닥 이동 명령으로 전달되지 않습니다.
- 불필요한 이전 맵 장식·조명·충돌을 로드하지 않는 가벼운 전장 루트를 사용합니다. 사냥의 기존 맵 생성 경로는 유지합니다.

## 전투와 상태

레이드 HP·공격력 10배, 보스별 패턴, 판정 범위, 이동 좌표, 회피, 수동 스킬·각성기, 보상·저장 로직을 유지했습니다. 변경은 화면과 표시 상태 복구에 집중했습니다.

화면 크기 변경 후 사망 영웅이 다시 서 보이던 문제를 수정했습니다. 사망 동작과 투명도, 이동한 보스의 위치, 활성 집결 표식을 복구합니다. 기본 화면에서는 “보스 레이드”, 저장 없는 F6 검토 장면에서는 “저장 없는 시범”을 표시합니다.
