# Pixel RPG v52 · 사냥터 UI·몬스터 배치·역할별 AI

사냥 화면에서 전장이 더 잘 보이도록 HUD를 재배치하고, 필드 몬스터를 여러 작은 무리로 늘렸습니다. 영웅 30인의 기존 스킬 조건을 자동 시전·이동·대상 선택에 연결했습니다. 세로 화면, 최대 10인 편성, 영웅 능력치와 스킬 계수·쿨타임은 유지합니다.

## 사냥 화면

- 목표, 스테이지 진행, 미니맵, 남은 몬스터 수를 상단에 모았습니다.
- 하단에는 자동사냥·속도·사냥 정보와 파티 카드를 모았습니다. 720×1280에서 전장을 가리던 하단 영역을 64px 줄였고, 개방 슬롯 5개 이하에서는 파티를 한 줄로 줄여 추가 92px을 확보했습니다.
- 파티 카드에 공격·방어·지원·제어 역할, 저체력 표시, 기술 대기시간, 궁극기 준비, 전투불능 상태를 표시합니다.
- 화면 크기나 편성이 바뀌어도 전투 HP·시간·진행을 초기화하지 않고 배치만 갱신합니다.

## 몬스터 배치

| 편성 인원 | 기존 | 기본 사냥터 | 난도 2~3 |
| --- | ---: | ---: | ---: |
| 1~3명 | 2 | 4 | 4 |
| 4~6명 | 3 | 6 | 8 |
| 7~9명 | 4 | 8 | 10 |
| 10명 | 5 | 10 | 12 |

한 지점에 모두 몰아넣지 않고 **2~4마리씩, 2~3개 무리**로 배치합니다. 무리는 연속해서 찾아갈 수 있는 동선에 두고 파티·장애물·다른 몬스터와 간격을 둡니다. 맵 가장자리에 공간이 부족하면 더 넓은 후보 영역을 찾습니다. 남은 무리가 있으면 그쪽으로 순찰을 이어갑니다.

추가된 몬스터의 배열 순번 때문에 공격력이 계속 올라가지 않도록 기존 최대 순번의 공격 배율에서 제한했습니다. 종별 체력·공격 공식과 정예 한 마리 조건은 유지합니다. 벽 너머 대기 몬스터는 시야만으로 교전에 합류하지 않습니다.

늘어난 몬스터를 모두 처치해도 예전 한 무리 보상만 주면 사냥 효율이 크게 떨어졌습니다. 따라서 서식지 전체를 정리할 때 실제 처치한 작은 무리 수만큼 기존 보상·장비 드롭·격파 수·스테이지 진행을 정산합니다. 같은 조우를 다시 정산하지 못하는 보호 장치는 유지합니다. 부분 처치 상태에서는 이 완료 보상을 지급하지 않습니다.

## 영웅별 사냥 판단

| 역할·기전 | 개선 |
| --- | --- |
| 탱커 | 후열·지원가 가까이 접근한 위협을 저지. 적이 멀리 있는데 방어기를 먼저 쓰는 행동 억제 |
| 근접 공격 | 편성 위치 때문에 사거리 값이 늘어도 실제 근접 영웅은 적에게 접근 |
| 원거리 공격 | 공격 거리 안에서 안전한 위치 선택. 벽·연못 주변 측면 이동, 좌우로 흔들리는 후퇴 완화 |
| 지원 | 아군과 지나치게 떨어지지 않도록 이동. 단독 생존 시에는 정상 추격. 위급한 아군 치유와 보호막 실효를 우선 판단 |
| 제어 | 이미 적용 중인 기절·약화·취약의 중복 사용 억제, 상태가 없는 유효 대상 우선 |
| 범위 공격 | 실제 시전자 사거리 안의 유효 대상 수에 따라 단일기·범위기 선택. 보조 대상도 스킬 조건으로 정렬 |
| 처형·특화 피해 | 처형 체력 조건, 높은 체력 추가 피해, 정예 보너스, 디버프 연계가 유효한 대상 우선 |
| 흡혈 | 위급할 때 흡혈 우선순위를 높이고, 남은 HP가 너무 적어 회복량이 나오지 않는 대상보다 실제 회복 가능한 대상 선택 |
| 연속·이동 패시브 | 동일 대상 연속 공격을 유지하고, 이동 조건 영웅은 공격권 안에서 측면 이동 |
| 궁극기 | 평타 한 번으로 끝낼 수 있는 적 하나에 공격 궁극기를 낭비하지 않도록 보류 |

이동 목표와 공격 목표가 서로 달라지는 현상을 줄이도록 우선순위를 공유했습니다. 시전 준비 뒤 다른 영웅의 회복·처치·제어로 상황이 바뀌면 실행 직전에 다시 확인합니다.

실제 필드에서는 월드 거리가 사거리 안에 있으면 공격할 수 있습니다. 예전 앞줄·뒷줄 번호가 인접 몬스터 공격을 막던 조건은 공간 사냥에서 제거했고, 공간 좌표 없는 행 기반 시뮬레이션에는 기존 규칙을 유지합니다. 몬스터 전멸 후에도 유효한 치유 시전으로 부상 아군을 회복할 수 있습니다.

## 검증

Godot 4.7.2에서 스크립트 **183/183개**, 전체 회귀 테스트 **102/102개**를 통과했습니다. 최종 전체 실행의 스크립트 오류·엔진 경고는 0입니다. 새 사냥 관련 검사 5개의 **3,414개 조건**도 통과했습니다.

| 신규 검사 | 통과 조건 수 |
| --- | ---: |
| 역할별 스킬·대상 선택 | 306 |
| 역할별 이동 | 28 |
| 몬스터 배치 | 439 |
| 사냥 UI | 2,530 |
| 실제 사냥 통합 | 111 |

기존 전체 세로 UI 검사도 **158개 화면 상태, 21,891개 조건**을 통과했습니다. 실행 로그와 밸런스 측정은 `pixel-rpg-v52-test-results.json`에 기록합니다.

- Godot 4.7.2의 실제 스크립트 구문 검사와 전체 회귀 테스트.
- 역할별 스킬·이동·배치·UI·통합 사냥 신규 검사 5개.
- 192개 배치 조건, 지형·속도 제한, 사거리·대상 전환·효과 중복·기술 보류 검사.
- 양 진영 1·3·10인 반복 사냥, 일시정지·재개, 전멸 후 회복, 정산 중복과 보스·스테이지 문턱 검사.
- 기존 30인 스킬 실제 시전과 보스·레이드·진영전·저장 회귀 검사.
- 세로 UI의 실제 Control·한글 폰트·클리핑·버튼 영역 검사.

초기 통합 검사에서 기존의 고정 5마리·조우당 1회 정산 가정, 유효한 적이 없는 제목 화면의 스킬 검사, 정상적인 상태 지속시간 감소를 오류로 판정한 검사를 새 동작에 맞춰 보완했습니다. 이 과정에서 실제로 몬스터 전멸 후 치유가 막히던 회귀도 발견해 수정했습니다. 피해·보상 중복·사거리·생존 검증은 유지합니다.

사냥 효율은 지역·편성·이동 경로와 측정 구간에 따라 달라집니다. v51과 동일한 15개 조건의 60초 측정에서 시작 능력치는 모두 같았고, 골드 변화는 평균 **+7.3%**, 범위 **-14.3~+34.3%**였습니다. 10인 180초 반복 전투에서 처치한 무리는 아우렐리아 25→36, 녹스페라 26→36이며, 강제 전멸 후 복귀는 양쪽 모두 4.4초였습니다. 모든 조건의 효율이 증가한 결과는 아닙니다. 전체 비교값을 결과 JSON에 포함합니다.

검증 환경은 Godot headless입니다. 실제 GPU 화면 캡처나 휴대폰의 터치감·발열·프레임 성능은 검사하지 못했습니다.

## 적용

현재 작업 소스에는 v52가 반영되어 있습니다. `pixel-rpg-v52-hunt-ai-ui.patch`는 **최초 v46.1 원본 소스 기준 누적 패치**이며, 앞선 v46.2~v51 변경도 포함합니다. 이전 패치를 적용한 폴더에 중복 적용하지 말고 원본 프로젝트를 별도 폴더에 풀어 적용하세요.

```bash
git apply --check /path/to/pixel-rpg-v52-hunt-ai-ui.patch
git apply /path/to/pixel-rpg-v52-hunt-ai-ui.patch
```

이미지·음원은 원본 프로젝트를 사용합니다. Godot 4.7.2에서 `project.godot`을 열고 가져오기를 마친 뒤 실행하세요. 개인 저장 파일은 패치에 포함하지 않습니다.

```bash
python3 tools/run_tests.py --godot /path/to/Godot --jobs 4
```
