# v62 영웅 리그 · 전투 이펙트 · 보상 표시

## 적용 범위

- 영웅 30명의 기존 전신 아틀라스를 각자 유지하면서 `Skeleton2D`와 13개 `Bone2D`, 가중치가 있는 12×12 `Polygon2D` 메시로 화면에서 변형합니다. 걷기, 공격, 스킬, 궁극기, 피격, 전투 불능 모션이 뼈를 움직입니다. 화면 효과는 전투 데이터와 충돌 판정을 변경하지 않습니다.
- 각 영웅의 역할에 따라 방패 파편, 베기 궤적, 지원 입자, 제어 회전 문양을 기존 스킬 효과 위에 짧게 더합니다.
- 피해 숫자에 등장 타이밍, 그림자·외곽선, 색상, 크기, 위치 분산을 적용했습니다. 보스 레이드는 기존 가독성 규칙을 사용합니다.
- 사냥 골드·경험치와 실제 드랍된 장비가 버튼 위쪽의 하단 알림에 나타납니다. 알림은 골드가 즉시 지갑에 들어온 것처럼 표시하지 않으며, 기존 **보상 받기**를 눌러 수령하면 수령액을 표시합니다. 장비 자동 장착·자동 분해 처리는 기존 규칙을 유지합니다.
- 한글 UI의 본문과 제목 글꼴 두께를 구분하고, 필드 격파/돌파 알림을 한글로 통일했습니다.

## 원본 그림에 관한 제한

제공된 영웅 원화는 팔다리가 별도 레이어로 분리된 파일이 아니라 1장의 아틀라스 프레임입니다. 메시 변형은 원본 그림을 가중치로 휘게 만듭니다. 어깨와 다리의 가려짐을 제작사가 수작업으로 그린 파츠처럼 완벽하게 분리할 수는 없습니다. 원화의 레이어 파일이 생기면 개별 팔·손·무기 스프라이트로 교체할 수 있습니다.
