# v58.1 레이드 안내 스크롤 보정

레이드 화면의 상태 문구는 전투 중 자주 바뀝니다. v58에서는 문구가 바뀔 때마다 안내 영역의 스크롤을 맨 위로 옮겨 긴 결과나 전투 설명을 읽기 어려웠습니다. 이제 공략 안내·전투·보스 스킬 예고·결과 사이로 화면 상태가 전환될 때만 스크롤을 처음으로 옮깁니다. 같은 상태에서 숫자나 문장만 바뀌면 읽던 위치를 유지합니다.

레이드 안내에도 다른 메뉴와 같은 터치 드래그·스크롤 손잡이 설정을 적용하고, 레이드 카드와 버튼 색을 사냥 UI 색상에 맞췄습니다. 보스 판정과 보상 규칙은 변경하지 않았습니다.

v58 전체 소스를 기준으로 변경 파일과 패치 적용 결과를 정적 검사했습니다. 작업 공간 정리로 Godot 실행 파일이 제거되어 이번 수정본의 런타임 회귀 검사는 실행하지 못했습니다. 실제 기기에서 긴 레이드 결과를 스크롤하면서 수치가 갱신될 때 위치가 유지되는지 확인해야 합니다.
