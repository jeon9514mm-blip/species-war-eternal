# 자동사냥 RPG v5 기반 개선판

## 이번 버전의 목표

v4의 자동 이동·타깃 유지·스킬 전투를 유지하면서, 프로토타입을 장기 운영형 방치 RPG 구조로 확장하기 위한 기반을 정리했다. 핵심은 **3인 데모 → 최대 10인 원정대**, **단순 숫자 성장 → 편성 시너지**, **무제한 지역 이동 → 스테이지 해금**, **불안정한 저장/장비 처리 → 재접속 가능한 안정적 루프**다.

## 실제 수정 사항

- 진영별 영웅 풀을 4명에서 10명으로 확장했다.
- 최대 편성 인원을 3명에서 10명으로 확장하고 3-4-3 전투 배치 좌표를 추가했다.
- 편성 영웅 ID를 저장 파일에 기록하고 재실행 시 복원한다. v4 저장 파일에는 편성 정보가 없으므로 기존 세이브는 진영별 초기 3인으로 자동 마이그레이션한다.
- 영웅 선택 화면을 스크롤형 10인 로스터와 10개 편성 슬롯으로 변경했다.
- 영웅을 다시 누르면 편성에서 제외되는 토글 방식으로 변경했다.
- 사냥 스테이지에 따라 영웅과 지역이 순차 해금된다.
- 3인/6인/10인, 종족 구성, 역할 균형에 따른 원정대 시너지를 추가했다.
- 신규 영웅 12명의 임시 스킬 프로필을 추가해 탱커·딜러·서포터·컨트롤러가 모두 동작한다.
- 10인 전투에서 HUD가 넘치지 않도록 스킬 상태와 성장 정보 표시를 요약형으로 변경했다.
- 자동 장착된 드랍 장비가 인벤토리에도 남던 중복 문제를 수정했다.
- 인벤토리 30칸이 찼을 때 오래된 장비를 조용히 삭제하지 않고, 낮은 가치 장비를 자동 분해해 골드를 돌려주도록 변경했다.
- 일반 사냥 중 지역 보스가 실제로 출현하기 전에는 레이드 바로가기 버튼을 잠근다.
- 절차적 맵의 환경 픽셀 애니메이션을 매 프레임 다시 그리지 않고 약 12.5 FPS로 제한해 모바일 렌더링 부담을 줄였다.
- 오프라인 보상 상한을 4시간에서 8시간으로 늘렸다.

## v4에서 발견한 핵심 문제

1. `deployed_heroes`가 저장되지 않아 재실행 직후 오프라인 영웅 경험치가 배치 영웅에게 들어가지 않을 수 있었다.
2. 높은 등급 드랍 장비를 자동 장착하기 전에 인벤토리에 먼저 넣어 장착 장비와 인벤토리 장비가 동시에 존재할 수 있었다.
3. 인벤토리가 30칸을 넘으면 `pop_front()`로 장비가 경고 없이 사라졌다.
4. 장기 목표는 10인 파티인데 UI/스킬 HUD/맵 배치가 3인 전제였다.
5. 사냥터가 시작부터 모두 순환 가능해 성장에 따른 콘텐츠 해금감이 약했다.
6. 보스가 맵에 등장하지 않아도 별도 레이드 버튼으로 진입할 수 있어 오픈맵 보스 출현 루프의 의미가 약했다.
7. `MapTerrainRenderer`가 작은 환경 입자 애니메이션 때문에 전체 지형을 매 프레임 다시 그렸다.

## 다음 v6 우선순위

가장 효과가 큰 다음 작업은 **개별 영웅 HP/어그로 + 다수 몬스터 동시 전투**다. 지금은 원정대가 공용 HP를 사용하고 한 번에 한 몬스터를 상대하므로 10명을 편성해도 실제 전투의 역할 차이가 충분히 보이지 않는다. v6에서는 전열 탱커가 공격을 받고, 힐러가 특정 아군을 회복하며, 후열 딜러가 거리/타깃 규칙으로 공격하도록 전투 모델을 분리하는 것이 좋다.

그 다음은 펫 1칸, 유물/도감, 일일 던전, 진영별 영토 보스, 월드맵 노드 진행 순으로 붙이면 장기 성장 루프를 만들기 쉽다.

## 검증 상태

원본 v4 프로젝트에 포함된 `test-results.json`은 Godot 4.5.1 환경에서 기존 스모크 테스트 14/14 통과 기록을 갖고 있다. 이번 v5에는 `V5FoundationSmokeTest.gd`를 새로 추가했다. 현재 작업 환경에는 Godot 실행 파일이 없어 v5 변경분을 실제 엔진에서 재실행하지 못했으며, 대신 함수 중복·괄호/문자열 균형 등의 정적 검사를 수행했다.

Godot 4.5.1이 설치된 환경에서 아래 명령으로 전체 테스트를 다시 실행해야 한다.

```bash
python tools/run_tests.py --godot /path/to/godot
```

또는 v5 기반 테스트만 실행한다.

```bash
godot --headless --path . --script res://scripts/V5FoundationSmokeTest.gd
```
