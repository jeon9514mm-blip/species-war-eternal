# v64 · 움직이는 실시간 레이드

세 레이드에 공통 전장 좌표와 실제 위험 구역 판정을 적용했습니다. 보스는 영웅을 추적하며 전장을 이동하고, 영웅은 보스를 따라 접근해 공격합니다. 영웅이 멀리 떨어지면 공격할 수 없습니다. 기존 자동 스킬과 장비·보상·페이즈 시스템은 유지됩니다.

## 조작

- 바닥을 터치하거나 드래그하면 원정대가 해당 위치로 이동합니다. `자동 추적`을 누르면 다시 보스를 쫓습니다.
- `회피`는 원정대 전체를 짧게 이동시키고 0.5초 동안 피격을 막습니다. 재사용 대기시간은 5초입니다.
- 하단 영웅 카드를 터치해 영웅을 선택한 뒤 `스킬` 또는 `각성`을 누르면 준비된 기술을 직접 사용합니다. 자동 사용 설정과 함께 사용할 수 있습니다.
- 보스의 위험 구역은 예고 시 정해져 화면에 표시됩니다. 타격 때 영웅의 위치를 같은 범위와 비교하므로 걸어서 벗어나거나 회피할 수 있습니다. 기절로 시전 차단도 가능합니다.

## 세 보스

| 보스 | 움직임과 패턴 | 대처 |
| --- | --- | --- |
| 초원왕 그룬 | 접근·거목 기운, 원형 포효와 2연속 도넛형 지진 | 원 밖 또는 도넛 안쪽으로 이동, 두 번째 파동도 회피 |
| 광맥의 거인 모르굴 | 추적·수정 파편, 전열과 후열을 노리는 낙석 통로 | 예고된 세로 통로에서 좌우로 빠져나오기 |
| 월식의 여왕 셀레네 | 추적·월식 입자, 넓은 흡혈과 체력 낮은 두 영웅의 표식 | 흡혈 범위 밖 또는 고정된 표식 밖으로 이동 |

기존 4자세 보스 원화 위에 보스별 원소 파편·시전 고리·공격 궤적을 2D 레이어로 더했습니다. 진입 문이 열리는 짧은 화면 연출, 자동 추적, 선택 영웅 수동 스킬, 패턴 회피 횟수를 표시합니다.

## 검증

- Godot 4.7.2 편집기 스크립트 검사 통과.
- `V64RealtimeRaidSmokeTest.gd`: 이동·영웅 선택·수동 각성기·동일 위험 구역의 피격과 회피를 세 레이드에서 33/33 통과.
- 기존 `V59ThreeRaidVisualSmokeTest.gd` 31/31, `V27RaidIntegrationSmokeTest.gd` 19/19, `V31HeroFxSmokeTest.gd` 740/740 통과.

현재 전투는 클라이언트 안에서 실시간으로 계산됩니다. 여러 사람이 함께 접속하는 네트워크 협동 레이드는 포함되지 않습니다.
