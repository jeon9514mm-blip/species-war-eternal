# v47 UI · 맵 · 자동사냥 개선

v46.2 안정화 소스를 기준으로 수정했습니다. 영웅 30명의 능력치·스킬 데이터, 세로 화면 방향, 저장 형식은 유지했습니다.

## 화면과 조작

- 전투 영웅 슬롯을 5열 × 2행으로 정리했습니다. 이름, 레벨, 체력, 궁극기 게이지를 함께 보여 주고 영웅을 누르면 상세 화면을 엽니다.
- 빈 슬롯에는 추가 안내, 잠긴 슬롯에는 해금 스테이지를 표시합니다. 파티와 슬롯 수가 바뀌면 패널이 갱신됩니다.
- 자동사냥 버튼에 진행/재개 문구를 표시하고 사냥 정보·배속 버튼을 같은 줄에 모았습니다.
- 목표 표시를 한 줄로 정리하고 글자 외곽선을 줄였습니다. 카메라 중심을 하단 패널 위의 전투 영역에 맞췄습니다.
- 편성 화면의 선택된 역할 필터를 강조하고, 전체 버튼을 누르면 전체 목록으로 돌아갑니다. 영웅 초상화를 누르면 상세 화면이 열리고 편성 버튼의 높이를 늘렸습니다.

## 맵과 지형

- 실제 월드 좌표를 사용하는 미니맵을 추가했습니다. 파란 점은 생존 아군, 붉은 점은 적이며 현재 추적 대상에는 금색 테두리를 표시합니다.
- 미니맵에 카메라 영역과 장애물 우회 경로를 표시합니다. 미니맵을 누르면 사냥터 선택 화면으로 이동합니다.
- 초원의 기존 나무·연못 좌표를 유지하면서 바닥 색감을 완화하고 연못 잔물결과 이동 영역 바깥쪽 경계석을 추가했습니다.
- 초원의 충돌 영역을 미니맵과 공유합니다. 다른 사냥터의 배경과 기존 이동 방식도 유지합니다.

## 자동사냥

- 영웅과 파티가 대상을 고를 때 장애물을 돌아가는 경로 길이를 참고합니다. 가까워 보여도 연못 뒤에 있는 적과 곧바로 접근할 수 있는 적을 구분합니다.
- 파티가 적과 가까워져도 사이에 장애물이 있으면 계속 우회합니다.
- 모퉁이에서 남은 이동 거리를 안전할 때 활용하고, 대열 이동으로 경로에서 밀려나면 즉시 연결 경로를 다시 찾습니다. 한 프레임의 전체 이동선도 장애물과 교차하지 않는지 확인합니다.
- 정확히 겹친 영웅은 서로 다른 방향으로 흩어집니다. 이동 속도 상한과 기존 공격 준비 동작은 유지합니다.
- 일시정지 중에는 대상 고정 시간도 멈춥니다. 잘못된 이동 거리나 목적지 입력은 무시합니다.
- 지형 거리 계산은 최대 256개를 캐시합니다. 장시간 사냥에서 캐시가 무한히 늘어나지 않습니다.

## 검증

최종 검사 결과: **163/163 스크립트 컴파일, 86/86 테스트 통과**. 새 이동 검사 248개, UI 검사 442개 항목도 통과했습니다.

| 10인 파티 · 180초 시뮬레이션 | 아우렐리아 | 녹스페라 |
| --- | ---: | ---: |
| 몬스터 무리 격파 | 25 | 26 |
| 가장 긴 격파 간격 | 12.1초 | 11.3초 |
| 전멸 후 10명 복귀 | 4.4초 | 4.4초 |

이는 고정 시드·스테이지 8 테스트의 측정값입니다. 모든 영웅이 전투 행동을 완료했고 체력 범위와 보상 증가가 정상임을 확인했습니다.

- Godot 4.7.2 실제 엔진으로 전체 GDScript 구문 검사 및 게임 회귀 검사를 실행했습니다.
- 새 이동 검사: 연못 너머의 대상 선택, 겹침 해소, 정지 상태, 잘못된 수치, 서로 다른 프레임 간격의 24개 이동 경로, 움직이는 목적지를 검사합니다.
- 새 UI 검사: 720×1280, 720×1440, 720×1560, 810×1440에서 영웅 카드·게이지·버튼 영역, 미니맵 좌표, 카메라 위치, 영웅 상세 및 필터 동작을 검사합니다.
- 기존 저장/복구, 영웅 30명·애니메이션, 성장, 레이드, 전쟁, 양 진영 연속 사냥과 전멸 후 복귀 검사도 포함합니다.
- 초기 개선안의 조기 정지 조건은 연속 사냥 간격을 늘려 제거했습니다. 최종 사냥 수치는 모든 상황의 속도 향상을 보장하는 벤치마크가 아닙니다.

검증 범위는 헤드리스 엔진의 실행·상태·UI 좌표입니다. 이 환경에서는 그래픽 디스플레이를 사용할 수 없어 실제 화면 캡처와 육안 비교를 수행하지 못했습니다. Android 기기의 터치 감각·GPU 렌더링·FPS는 아직 검증하지 않았습니다.

## 소스 적용

`pixel-rpg-v47-ui-map-autohunt.patch`는 **원본 v46.1 typefix 프로젝트용 누적 패치**입니다. v46.2 안정화 수정도 포함합니다. v46.2 패치를 이미 적용한 폴더에 중복 적용하지 마세요.

1. 원본 `pixel-rpg-v46.1-typefix.zip`을 새 폴더에 풉니다.
2. 그 안의 `project.godot`가 있는 프로젝트 폴더에서 실행합니다. 패치 경로는 실제 다운로드 위치에 맞게 지정합니다.

```sh
git apply --check /path/to/pixel-rpg-v47-ui-map-autohunt.patch
git apply /path/to/pixel-rpg-v47-ui-map-autohunt.patch
```

3. Godot 4.7.2로 `project.godot`를 열고 실행합니다. 전체 프로젝트와 기존 아트 리소스가 필요한 소스 패치이며 APK 배포본은 아닙니다.

개발용 검사 명령:

```sh
python tools/run_tests.py --godot /path/to/Godot_v4.7.2 --jobs 4 --output test-results.json
```
