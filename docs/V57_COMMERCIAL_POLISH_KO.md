# v57 상용화 품질 개선 · 적용 및 확인

앞선 점검의 우선순위에 맞춰 영웅 능력치·편성·설정과 저장 안내를 먼저 수정하고, 성장/소환의 탐색량과 전투/던전 결과 피드백을 줄였습니다. 저장 형식 31과 보상 수치, 레이드 전투 공식 및 기존 장비/거래 규칙은 유지합니다.

## 변경된 화면과 사용법

| 화면 | 변경 사항 |
| --- | --- |
| 영웅 상세 | HP·공격·방어에 실제 전투와 같은 레벨·훈련·장비·돌파·편성 시너지를 반영합니다. |
| 편성 | 출전 영웅 초상을 한 번 누른 뒤 다른 슬롯 초상을 누르면 서로 교체됩니다. 슬롯에 실제 전열/중열/후열을 표시하고 바로 저장합니다. |
| 로비와 메뉴 | 첫 여정의 다음 목표와 이동 버튼, 별도 가이드 진입, 전투 연출/스킬 소리 독립 설정을 표시합니다. 효과를 꺼도 보스 위험 경고는 남습니다. |
| 저장 | 저장 실패와 최신 버전 저장 파일의 차단 이유를 안내하고, 저장이 복구되면 한 번 알립니다. |
| 훈련·소환 | 영웅 선택 메뉴와 한 영웅의 훈련/돌파 카드만 표시합니다. 선택한 영웅은 화면 재진입 시 유지합니다. |
| 던전 | 즉시 정산 방식을 명시하고 완료 후 보상·점수·다음 층 결과 카드를 보여줍니다. 기존의 즉시 완료 규칙과 횟수·보상은 그대로입니다. |
| 레이드 | 성공 시 생존 인원·패턴 차단 수, 실패 시 남은 보스 체력과 전열/공격 개선 안내를 표시합니다. |

## 적용

변경 전에 플레이 저장과 소스의 사본을 보관하세요. v56 소스에서 진행할 경우 `git apply --check pixel-rpg-v57-from-v56.patch` 후 `git apply pixel-rpg-v57-from-v56.patch`를 사용합니다. v46.1 원본에서 시작하는 경우에는 `pixel-rpg-v57-full.patch`만 적용합니다. 두 파일을 중복 적용하지 마세요. 이후 Godot 4.7.2로 프로젝트를 열어 자산 가져오기가 끝난 다음 실행하세요. 검증 결과는 함께 제공한 JSON에 있습니다.

## 남은 출시 준비 작업

1. Android SDK/내보내기 템플릿과 서명·앱 식별자·런처 아이콘을 준비하고 Android 내보내기 설정을 만듭니다. 현재 환경에는 SDK와 내보내기 템플릿이 없어 설치형 APK를 만들지 못했습니다.
2. 실제 Android 휴대폰의 좁은/긴 화면에서 한글 잘림, 탭 터치, 10인 편성, 레이드 240초, 저장 재실행과 발열/프레임을 확인합니다. 이번 자동 검사는 headless viewport 입력·레이아웃 수준입니다. 그래픽 프레임버퍼 캡처 환경도 제공되지 않아 실제 게임 스크린샷은 포함하지 않았습니다.
3. 던전은 아직 전투 시뮬레이션이 아닌 전투력 조건을 만족하는 즉시 정산 콘텐츠입니다. 이를 실제 전투로 바꾸려면 각 모드의 전투 규칙/난이도/보상/저장·재접속 복구를 함께 설계하고 밸런스 재검증이 필요합니다.
4. 게임 전반의 배경·캐릭터·아이콘 화풍 통일과 전체 기기별 시각 검수는 별도 아트·실기기 작업이 필요합니다. 거래소의 실시간 유저 간 거래는 서버 기능 범위이므로 이번 품질 작업에 포함하지 않았습니다.

Android 내보내기 준비 사항은 Godot 4.7 공식 문서 `https://docs.godotengine.org/en/4.7/tutorials/export/exporting_for_android.html`와 `https://docs.godotengine.org/en/4.7/tutorials/export/exporting_projects.html`를 참고하세요.
