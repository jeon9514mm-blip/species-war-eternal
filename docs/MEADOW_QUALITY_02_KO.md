# 밝은 초원 그래픽 개선 — 2026-10-04

이번 변경은 `scenes/art/ArtDirectionLab.tscn`의 검토용 초원을 개선합니다. Godot 4.7.2에서 F6로 실행합니다. 기본 F5 게임의 디자인을 교체하기 전 실제 사냥 화면으로 검토하는 단계입니다.

기존 바닥은 3:2 원화를 64×88 월드 영역에 늘려 풀과 돌의 비율이 어긋났습니다. 새 원화에는 희미한 흙길, 넓은 녹색 명암 덩어리, 가장자리 꽃·돌·클로버를 구성하고, 64×42⅔의 비율로 표시합니다. 바깥 지면에는 원화를 반사 반복하여 경계 행이 벽처럼 늘어나는 현상을 없애고, 원경의 대비를 약하게 낮춥니다. 사냥 영역의 UV·월드 좌표는 고정이며 무한 횡스크롤을 추가하지 않습니다. 이전 원화는 `pilot-01/meadow-ground.png`에 보존합니다.

먼 산의 표시 높이를 늘리고, 수목 그림자를 지면의 월드 좌표에 고정합니다. 그림자의 작은 흔들림과 입체 풀은 기존 분위기 시간만 사용하므로 사냥 일시정지·메뉴·앱 중지·원래 맵 비교 중에는 멈춥니다. 셰이더의 전역 TIME이나 전투 RNG를 사용하지 않습니다.

짧은 풀 176군락·880잎은 주변부에 배치한 메시 한 개입니다. 새 소품 아틀라스 한 장에는 참나무·자작나무·석조 아치·유적벽·이끼 바위·꽃 군락의 6변형이 있습니다. 실제 알파 경계를 측정하여 12개의 월드 소품으로 배치하고, 별도 메시 한 개에 부드러운 접지 그림자를 묶습니다. 소품은 카메라를 향하는 2.5D 그림이며 새 3D 모델을 만들었다는 뜻이 아닙니다.

새로운 물리 충돌·내비게이션·스폰 지점은 없습니다. 기존 18개 합성층에 입체 풀·월드 소품·접지 그림자를 추가하여 현재는 21층입니다. 신규 그림은 지면과 소품 아틀라스 두 장이며, 21장의 독립 원화를 만들었다는 뜻이 아닙니다.

실제 8방향 사냥·32×20 전투 좌표·진형·피해·보상·저장 격리·가로 고정·장비 200칸·레이드 강화값을 유지합니다. 미검수 영웅 그림의 자동 적용 조건도 유지합니다. 영웅 목 연결 문제는 별도 진행 중이며 이 맵 변경을 영웅 조립 완료로 간주하지 않습니다.
