# 현재 엔진 기준 — Godot 4.7.2

v83-6.4부터 사용자가 지정한 **Godot 4.7.2 일반 에디터**를 기준으로 개발·실행 검증합니다. `project.godot`의 `config/features`는 `4.7`입니다.

- PC 기본 렌더러: **Forward+**. 모바일 설정: **Mobile**.
- 현재 화면은 3D 전장과 Sprite3D 캐릭터, 2D Control UI를 함께 사용합니다.
- 프로젝트를 처음 열면 해당 엔진에 맞는 `.godot` 임포트 캐시가 생성됩니다.
- 검증 절차: [ENGINE_TESTING_KO.md](../ENGINE_TESTING_KO.md).
- 기존 v83-6.2/3의 Godot 4.6.3 결과는 과거 검증 기록으로 보존합니다.

예전 v14의 2D/Compatibility 전환 메모는 [과거 문서](history/pre_v83_6_4_GODOT_4_7_MIGRATION_KO.md)로 옮겼습니다. 그 메모의 렌더러 설명은 현재 3D 프로젝트에 적용하지 않습니다.
