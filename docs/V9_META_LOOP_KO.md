# v9 출시형 메타 루프 기반

v9은 전투 기능을 추가하는 대신, 플레이어가 반복해서 접속하고 성장할 이유를 만드는 메타게임 기반을 강화합니다.

## 추가 기능
- 로비에서 성장·콘텐츠 허브 및 영웅 소환·돌파로 바로 이동
- 영웅 조각 소환: 1회 100젬, 기본 12조각, 10회째 30조각 보장
- 영웅 최대 5돌파 및 돌파 전투력 보너스
- 일일 던전 3회와 집중 성장 보상
- 무한탑 진행/최고층 기록/층별 난이도 상승
- 스테이지/레이드/무한탑 기반 퀘스트·업적 보상
- 장비 등급 기준 자동 분해 설정
- 도감 발견 상태의 저장 기반
- v8 저장 데이터를 유지하면서 save_version 9로 확장
- 타이틀의 보상·상점 센터 버튼 활성화

## 의도
`사냥 → 보상 → 성장 → 소환/돌파 → 일일 콘텐츠/무한탑 → 더 높은 스테이지`가 하나의 루프로 이어지도록 했습니다.
과금 SDK나 광고 SDK는 연결하지 않고, 게임 경제와 UI 흐름만 프로토타입으로 유지합니다.

## 검증
`V9MetaLoopSmokeTest.gd`에서 소환 천장, 돌파, 퀘스트, 일일 던전, 무한탑, 자동분해를 검증합니다.
