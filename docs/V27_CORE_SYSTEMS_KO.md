# Pixel War of Species v27 · 핵심 8개 시스템 통합 기록

2026-09-22 · Godot 4.7.2.stable.official.ed1daf0bf · Linux headless

이번 작업은 기존 20명 영웅·2개 진영·3개 사냥터·최대 10인 편성 게임의 핵심 8개 영역을 구현하고 연결한 결과다. 자동화 검사의 최종 고유 결과는 **65개 스크립트 모두 통과**이며, 새 v27 검사 11개에는 **534개 판정**이 포함된다. 검증 수를 개발 완성률로 환산하지 않는다.

사용자가 요청한 95% 이상 목표에 맞춰 기능 구현·중복 처리 방어·저장 복원·실제 전투 연결을 마감 조건으로 삼았다. 이 조건에서 구현과 회귀 확인을 마쳤다. 실제 기기와 운영 서버, 장기간 경제 검증은 아래에 따로 기록한다. 이 문서가 게임 전체 또는 출시 준비도 95%를 확정하는 것은 아니다.

## 연결 과정에서 함께 고친 문제

- 장착·강화·스킬 투자 후 화면을 다시 만들면서 살아 있는 전투 상태가 비워지던 문제를 수정했다. HP 비율·사망·궁극기·수호·쿨다운·준비 중 공격을 유지한다.
- 기절을 주지 않는 루네아·닉스·모르가스 궁극기까지 보스 차단 예고를 기다리던 문제를 수정했다. 실제 효과가 기절인 궁극기에만 차단 대기를 적용한다.
- 필드 상태 효과를 몬스터별로 적용하고 이동·공격·약화 피해·취약 피해·만료에 연결했다. 귀환 중인 적을 공격해 보상받는 경로도 막았다.
- 단계 10,000에서 일반 처치 보상은 유지하면서 단계 상자가 반복 생성되지 않도록 했다.
- 회귀 검사에서 처치 후 희귀 반지 자동 장착에 따른 정상 체력 증가를 오류로 보던 가정을 고쳤다. 실제 피격 횟수·각 영웅 HP 비율·적 공격 타이머·정확히 1회 처치로 반격과 중복 보상을 직접 확인한다.

## 최종 실행 결과와 재현

전체 실행은 65개 중 64개가 통과했다. 유일한 실패는 마지막 항목의 낡은 HP 불변 가정이었다. 실제 결과는 HP 1,295→1,298, 최대 HP 1,554→1,557, 반격 없음, 적 HP 0, 처치 증가 1이었다. 테스트의 판정만 수정한 뒤 해당 18개 조건을 재실행하여 모두 통과했다. 전체 실행 이후 제품 코드는 바꾸지 않았다.

- 최신 고유 결과: `docs/v27-runtime-results.json` — **65/65 통과**.
- 최초 전체 원본: `docs/v27-runtime-initial-results.json` — 실패 1건을 그대로 보존.
- 대상 재검증: `docs/v27-runtime-targeted-retest.json` — **18/18 통과**.
- 정적 검증: GDScript 95개, SmokeTest 64개, 리소스·문서 링크 확인.
- Godot 4.7 호환성 검사 및 `git diff --check` 통과.
- 기존 `SkillSmokeTest` 종료 시 ObjectDB 4개 경고는 남아 있다. 해당 검사는 종료 코드 0이며 스크립트 오류는 없었다. 새 v27 검사와 지속 사냥 검사에는 이 경고가 없었다.

각 테스트는 독립적인 사용자 저장 경로에서 실행한다. 재현 명령의 `godot`은 설치한 Godot 4.7.2 실행 경로로 바꾼다.

```sh
python3 tools/run_tests.py --godot /path/to/godot --jobs 3 --output v27-results.json
python3 tools/static_validate.py
python3 tools/godot47_compat_scan.py
```

### 지속 자동사냥

각 진영 10명을 실제 전투·성장·보상·화면 갱신 경로로 180초씩 시뮬레이션했다. 아래 값은 게임 내부 경과 시간이며 실제 기기에서 수 시간 운용한 기록은 아니다.

| 진영 | 60초 / 120초 / 180초 누적 무리 격파 | 행동한 영웅 | 가장 긴 격파 간격 | 강제 전멸 후 회복 |
|---|---|---:|---:|---:|
| 아우렐리아 | 10 / 19 / 31 | 10명 전원 | 10.3초 | 4.4초 |
| 녹스페라 | 11 / 21 / 33 | 10명 전원 | 10.0초 | 4.4초 |

### 실제 밸런스 표본

기본 조건은 Lv.10·일반 장비 +3·스테이지 25·동일 시드, 각 60초다. 나머지 3개 조건은 Lv.1 초원 경계 입력을 서로 다른 시드로 측정했다. 저장 I/O와 HUD 재그리기만 제외한 실제 게임 함수를 사용했다.

| 조건 | 아우렐리아 무리/60초 | 녹스페라 무리/60초 |
|---|---:|---:|
| 초원 3인 | 15 | 17 |
| 광산 3인 | 10 | 11 |
| 숲 3인 | 7 | 8 |
| 초원 10인 | 15 | 15 |
| 광산 10인 | 10 | 10 |
| 숲 10인 | 8 | 8 |

이 표본에서 10인 처리량은 같고 3인 녹스페라 처리량은 10~14.3% 높았다. 10인 실제 HP·공격 합·전투력 차이는 각각 약 0.10%·0.45%·0.59%였다. 다른 조합이나 PvP 승률이 같다는 뜻은 아니다.

숲 10인은 방치 일반 골드 1,320, 온라인 1,149로 방치가 약 14.9% 높았다. 이 비교에는 별도 단계 상자·장비·동료 XP·군량이 포함되지 않는다. 방치 추정 13무리와 온라인 8무리는 단계 상자 경계도 다르게 지나므로 총수익 차이를 14.9%로 한정할 수 없다. **숲 방치 추정과 단계 상자를 포함한 장기 경제 비교는 다음 수치 조정의 우선 대상**이다. 한 분의 표본만으로 계수를 임의 변경하지 않았다.

자세한 표와 영웅 수치는 `docs/V27_BALANCE_RESULTS_KO.md`, 원시 데이터는 `docs/v27-balance-results.json`에 있다.

## 남은 마감 판단

1. Android 실제 기기에서 터치·가독성·장시간 프레임·발열·강제 종료·저장 공간 부족을 확인해야 한다. 이번 결과는 Linux headless 실행이다.
2. 영토전 권한 서비스와 레이드는 현재 로컬 게임 구현이다. 원격 계정·공유 DB·동시 접속·실시간 협동 레이드 운영 서버는 미구현이다. 로컬 SHA-256/HMAC는 운영 서버 보안 완성을 뜻하지 않는다.
3. 숲 방치 수익, 단계 상자, 장기간 재화 획득/소모, 다양한 영웅·장비 조합과 PvP 승률은 더 긴 플레이 데이터로 조정해야 한다.
4. 현재 대형·파티 중심 전투 모델에는 맵 장식의 물리 충돌과 개별 캐릭터 장애물 길찾기가 포함되지 않는다. 추가 콘텐츠·음성·전체 고유 애니메이션 역시 이 기능 검사만으로 완성됐다고 판단하지 않는다.

현재 결과는 기존 로컬 게임의 핵심 기능 마감 및 통합 검증 기록이다. 남은 항목을 확인하지 않은 상태에서 모든 영역의 출시 완성도가 95% 이상이라고 표시하지 않는다.

## 누적 소스 적용

`pixel-faction-rpg-v27-core-checkpoint.patch`는 원래 v25 소스에 v26과 이번 v27의 변경을 모두 합친 누적 패치다. 소스·검사·결과 문서를 포함하며 기존 이미지·음원 등 변경 없는 자산은 원본을 사용한다.

1. 원본 `pixel-faction-rpg-prototype-v25-godot47-combat-fx-runtime-verified.zip`을 새 폴더에 푼다.
2. 추출된 `pixel-faction-rpg-prototype-v25` 프로젝트 폴더에서 다음 명령을 실행한다. 별도로 v26 패치를 먼저 적용하지 않는다.

```sh
git apply --check /path/to/pixel-faction-rpg-v27-core-checkpoint.patch
git apply /path/to/pixel-faction-rpg-v27-core-checkpoint.patch
```

3. Godot 4.7.2로 `project.godot`을 열어 리소스를 import하고 `scenes/Main.tscn`을 실행한다.

각 영역의 세부 구현은 `docs/V27_COMBAT_FIELD_KO.md`, `V27_HERO_ROLES_KO.md`, `V27_GROWTH_KO.md`, `V27_BOSS_RAID_KO.md`, `V27_TERRITORY_KO.md`, `V27_SAVE_STABILITY_KO.md` 및 연결 검사 문서에 기록했다.
