# 가로 영웅 화면과 전체 메뉴

## 현재 작업 범위

Godot 4.7.2, 1280×720 가로 전용 기준으로 영웅 확인·성장 화면과 전체 메뉴를 개편했습니다. 현재 기준은 `main`입니다. 가로 전용·200칸 장비 가방 단계 `f4ec23b14d347b50d1501b7ec765428d29c7ae2d` 위에 적용한 후속 작업입니다.

이번 범위는 영웅 화면, 해당 화면으로 이어지는 편성 동선, 오른쪽 전체 메뉴입니다. 사냥 화면에는 우상단 메뉴 진입 버튼과 필요한 공간을 연결합니다. 사냥 맵·전투 HUD 전체를 다시 디자인하는 작업은 포함하지 않습니다. 장비 가방 200칸, 가로 고정과 기존 저장 버전 37을 유지합니다.

## 영웅 화면

사용자가 제공한 첫 번째 참조 이미지의 좌·중·우 구성을 게임의 기존 영웅 자료와 성장 기능에 맞춥니다.

- **왼쪽 영웅 목록:** 현재 진영의 영웅 초상화를 세로로 배치합니다. 레벨·잠금 해제 조건·출전 상태와 선택 영웅을 표시하며 목록을 스크롤할 수 있습니다.
- **세로 기능 탭:** 성장, 스킬, 장비, 승급·돌파를 전환합니다. 같은 탭에서 영웅을 바꾸어 상태를 살펴볼 수 있습니다.
- **중앙 캐릭터:** 기존 원본 영웅 그림을 크게 표시하고 `PortraitHeroSkeletalRig`의 대기 동작을 연결합니다. 새로운 캐릭터 그림이나 분리된 신체 원화를 생성한 작업은 아닙니다.
- **오른쪽 정보:** 영웅 이름·종족·직업·역할·레벨을 고정해서 표시하고, 선택 탭의 정보를 아래 영역에서 스크롤합니다. 성장 탭은 현재 장비·연구·진형과 적용되는 원정대 시너지를 반영한 공격력·방어력·체력을 보여 줍니다.
- **하단 동선:** 하단 `영웅` 버튼은 새 영웅 화면으로 진입합니다. `원정대 편성`은 별도 편성 화면으로 연결합니다. 선택 영웅 배치·해제와 편성 정원·해금 조건은 기존 규칙을 사용합니다.

아직 합류하지 않은 영웅은 해금 스테이지를 표시합니다. 성장·배치 버튼은 해금 조건과 보유 재화, 최대 단계, 저장 보호 상태를 확인합니다. 연습 상태에서는 진행 변경을 제한합니다.

## 실제 성장과 장비 연결

영웅 레벨은 **전투 경험치로 성장**합니다. 성장 화면은 현재 EXP와 다음 레벨까지 필요한 경험치를 표시합니다. 별도의 경험치 구매나 즉시 레벨업 규칙을 추가하지 않습니다.

| 화면 기능 | 기존 처리와 연결 |
| --- | --- |
| 공격·생존·기능 연구 | `_upgrade_skill_tree`로 사용 가능한 연구 포인트를 소비합니다. 연구 재배분 창도 연결합니다. |
| 등급 승급 | `_try_ascend_hero`로 필요한 레벨·골드·최대 등급을 확인합니다. |
| 조각 돌파 | `_try_breakthrough`로 영웅 조각과 최대 돌파 단계를 확인합니다. 소환 화면으로 이어지는 획득 동선도 제공합니다. |
| 장착 중인 장비 | 무기·방어구·장신구를 표시하고 기존 장비 상세·공방으로 연결합니다. |
| 장비 비교·교체 | 선택 영웅을 200칸 장비 가방에 전달하고 기존 장착 처리를 사용합니다. |
| 출전·배치 해제 | `_deploy_hero`와 기존 편성 규칙을 사용합니다. |

스킬 탭은 기존 영웅 데이터의 액티브·패시브·궁극기 설명과 재사용 시간, 전투 성향을 보여 줍니다. 이번 변경은 신규 성장 재화·DLC·온라인 계정 기능을 추가하지 않습니다.

## 오른쪽 전체 메뉴

우상단 `☰`를 누르면 현재 화면 위에 어두운 오른쪽 메뉴가 열립니다. 배경과 메뉴 밖 영역을 어둡게 처리하고, 메뉴 안의 콘텐츠를 그림 카드와 기능 아이콘으로 구분합니다. 닫기 버튼, 메뉴 바깥 영역, 취소 입력으로 닫을 수 있습니다.

**그림 카드 6개**는 종의 전쟁, 원정 캠프, 사냥터, 소환, 레이드, 성장·던전으로 연결합니다. 카드에는 프로젝트에 있는 배경 그림을 사용합니다.

**기능 아이콘 12개**는 가방, 영웅, 파티 편성, 전투 진형, 영웅 도감, 성장 연구, 보상 센터, 목표·업적, 거래소, 진영 선택, 가이드, 설정입니다. 각각 기존 화면과 기능을 호출합니다. 상단 빠른 버튼으로 목표·업적과 보상 센터에 접근할 수 있고, 하단에는 전투 연출·효과음 설정과 시작 화면 이동을 둡니다.

영웅 감상·성장과 파티 편성을 서로 다른 진입 항목으로 유지합니다. 편성 화면은 왼쪽 10인 슬롯·프리셋·확정 버튼과 오른쪽 필터·정렬·영웅 목록으로 나누었습니다. 진영 선택은 두 진영 카드를 좌우로 배치했습니다. 던전·레이드·사냥터 편성에서 영웅의 장비나 연구 재배분을 확인해도 원래 편성으로 돌아갑니다.

## 구현 위치

- `scripts/HeroShowcaseView.gd`: 영웅 목록·세로 탭·원본 아트와 골격 대기 동작·성장과 장비 연결
- `scripts/LandscapeMainMenu.gd`: 오른쪽 메뉴, 그림 카드·아이콘 배치, 실제 화면 이동과 닫기 입력
- `scripts/portrait/PortraitMain.gd`: 하단 영웅 진입·선택 영웅 복원·새 메뉴 연결
- `scripts/portrait/LandscapeHuntHud.gd`: 우상단 전체 메뉴 버튼
- `scripts/portrait/PortraitMenus.gd`: 가로 편성·진영 선택 배치
- `scripts/ResearchAllocationScreens.gd`, `scripts/Main.gd`: 연구 재배분 후 영웅·원래 편성 복귀

최종 실제 렌더 15장을 `checks/hero-menu/captures/`에 보관했습니다. [영웅 성장 화면](../checks/hero-menu/captures/hero-growth.png), [장비 탭](../checks/hero-menu/captures/hero-equipment.png), [사냥 화면 위 메뉴](../checks/hero-menu/captures/menu-hunt.png), [가로 편성](../checks/hero-menu/captures/party-roster.png), [진영 선택](../checks/hero-menu/captures/faction-selection.png)을 확인할 수 있습니다. 기존 영웅 그림과 게임 UI를 Godot의 Vulkan 소프트웨어 렌더러로 실행한 캡처입니다.

Godot **4.7.2.stable.official.ed1daf0bf**에서 스크립트 **398/398**, 선택 회귀 **15/15종·18,975개 검사**를 통과했습니다. 에디터 임포트와 실제 렌더도 오류 없이 완료했습니다. [전체 검증 결과](../checks/hero-menu/regression.json)에 각 테스트의 출력과 화면 크기를 기록했습니다. 연구 저장 실패를 의도적으로 주입하는 테스트의 경고는 원문에 보존했습니다. 이전 장비 단계의 393개·17종·10장 검증은 [별도 기록](LANDSCAPE_EQUIPMENT_KO.md)에 남아 있습니다.

실제 포인터 입력으로 영웅·탭 전환, 성장 비용과 저장 보호, 장비·연구 재배분 왕복, 양 진영 선택과 편성, 메뉴 이동·닫기·입력 차단을 확인했습니다. 창 크기 변경 후에도 메뉴 뒤의 전투 버튼이 눌리지 않고 영웅 선택·탭·전투 상태가 유지됩니다. 1280×720·1600×720·960×540 렌더와 여러 창 비율의 가로 논리 화면을 검사했습니다. Android 실기기의 터치·성능 검증과 모든 과거 테스트 전체 실행은 포함하지 않습니다.
