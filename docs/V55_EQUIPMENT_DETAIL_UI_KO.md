# Pixel RPG v55 · 장비를 눌러 관리하는 UI

가방의 긴 장비 카드와 반복 버튼을 줄이고, **장비 타일 선택 → 해당 장비 상세에서 작업**하는 방식으로 바꿨습니다. 장비 목록과 옵션 공방을 계속 아래로 스크롤해야 하던 흐름을 정리했습니다.

## 가방

- 장비를 **3열, 한 페이지 12개** 타일로 표시합니다. 30개를 보유하면 12개·12개·6개로 나뉩니다.
- 타일에는 아이콘·이름·등급·강화 단계·옵션 개수·잠금/귀속 상태만 표시합니다. 긴 이름은 줄이고 상세에서 확인할 수 있습니다.
- 타일 전체를 누르면 그 장비의 상세가 열립니다. 목록에 장착·강화·분해 버튼을 반복 배치하지 않습니다.
- 종류·부위·정렬 필터는 상단에 둡니다. 출처 필터, 자동 획득 설정, 추천 장착과 일괄 강화는 **정리 · 설정**에 모았습니다.
- 거래소와 보호 보관함은 상단에서 바로 엽니다.
- 상세를 보고 돌아오면 기존 필터와 페이지를 유지합니다. 필터 결과가 줄면 유효한 페이지로 보정합니다. 강화로 정렬 순위가 달라지면 장비가 다른 페이지로 이동할 수 있습니다.

## 장비 상세

선택 장비의 아이콘·이름·등급과 작업 탭을 위에 고정하고, 선택한 작업 내용만 표시합니다.

| 탭 | 할 수 있는 작업 |
| --- | --- |
| 정보 | 출처·세트·현재 옵션 확인, 영웅 선택 후 장착, 잠금, 판매 진입, 분해 |
| 강화 | 현재 → 다음 강화 단계와 기본 전투력 비교, 비용 확인, 같은 장비 연속 강화 |
| 옵션 | 현재 옵션 확인, 선택 옵션 삭제·추출, 계열 선택 후 후보 조율·선택 |
| 이식 | 보유 결정 선택, 이식 전후 옵션 비교, 결정 이식 |

강화 후에는 같은 장비의 강화 탭이 유지되며 다음 비용을 갱신합니다. 장착 후에는 같은 장비의 장착 위치로 상세 문맥을 이어서, 다시 찾지 않고 강화·옵션 작업을 할 수 있습니다.

영웅 상세에서도 장착된 무기·갑옷·장신구를 각각 타일로 표시합니다. 타일을 눌러 같은 상세에서 관리하고, 뒤로 돌아가면 해당 영웅과 읽던 스크롤 위치를 복원합니다. 가방에서 장착한 경우에는 가방으로 돌아갑니다. ESC도 상세에서 이전 목록으로 돌아갑니다.

옵션 결정은 **정보 / 이식**만 표시합니다. 결정에 장비 강화 기능이 표시되지 않습니다. 삭제·추출·이식·분해의 확인 절차와 원래 옵션 일치 검사는 유지합니다.

## 유지한 게임 규칙

장비 수치·강화 비용·옵션 확률·세트 효과·드롭 규칙은 v54와 같습니다. 강화는 기존과 같이 확정 성공이며 최대 +10입니다. 추출 18정수, 이식 8정수, 삭제 6정수 및 거래 규칙도 유지합니다.

새 상세는 장비 ID를 기준으로 작업합니다. 장착한 장비와 가방 장비의 강화가 같은 처리 경로를 사용하고, 장비의 옵션·출처·귀속·거래 이력을 보존합니다. 이미 이동하거나 분해된 장비에는 작업하지 않습니다.

거래소는 v54와 같은 로컬 구현입니다. 이번 변경은 온라인 거래 서버를 추가하지 않습니다.

## 검증

| 주요 UI 검사 | 통과 조건 |

| 기존 장비·공방·거래 입력 회귀 | 862 |
| 결정 추출·판매·이식 입력 회귀 | 786 |
| 전체 세로 UI | 22,480 · 159개 화면 상태 |

기본 가방에서 장비 12개와 페이지 이동이 추가 스크롤 없이 보이는지 확인했습니다. 30개 보유 시 12/12/6 페이지, 빈 필터 결과와 페이지 보정, 긴 이름·한글 줄바꿈·버튼 글자·가로 넘침·글자 겹침을 검사했습니다. 물리 창 크기는 320×568, 360×640, 720×1280, 810×1440, 720×1560을 포함하며 기존 720폭 캔버스 설정을 사용합니다.

실제 viewport 입력으로 강화 탭 유지, 갱신된 다음 강화 비용, 장착 후 같은 장비 강화, 옵션 메타 보존, 재화 부족·최대 강화 비활성, 장비 헤더·탭 고정, 영웅 상세 스크롤 복원을 확인했습니다. 기존 장비·전투 성장·옵션 거래·저장 테스트 5종도 별도 통과했습니다.

초기 신규 검사에는 강화로 정렬 순위가 바뀌어도 이전 페이지에 같은 타일이 남아야 한다는 잘못된 기대가 있었습니다. 변경 없는 상세 왕복은 페이지와 타일 복원, 강화 후에는 페이지와 소유 장비 ID 보존으로 구분해 수정했습니다. 초기 결과와 최종 재실행 기록을 테스트 JSON에 함께 보관합니다.

Godot headless에서 실제 한글 글꼴·Control 배치와 viewport 입력을 검사합니다. 실제 GPU 화면 캡처와 휴대폰의 터치감·프레임 성능은 별도 확인이 필요합니다.

## 적용

현재 작업 소스에는 v55가 반영되어 있습니다. 자신의 원본에 맞는 패치 하나만 사용하세요.

- `pixel-rpg-v55-from-v54.patch`: v54 장비·옵션 결정 업데이트가 적용된 소스 기준.
- `pixel-rpg-v55-equipment-ui.patch`: 최초 v46.1 원본 소스 기준 누적 패치. v54를 포함한 이전 개선도 들어 있습니다.

```bash
git apply --check /path/to/pixel-rpg-v55-from-v54.patch
git apply /path/to/pixel-rpg-v55-from-v54.patch
```

기존 소스와 플레이 저장을 별도로 보관한 뒤 적용하세요. 저장 형식은 v54의 31을 유지하며, 이번 UI 변경에 별도 데이터 변환은 없습니다. 개인 저장 파일과 엔진 실행 파일은 전달물에 포함하지 않습니다.

```bash
python3 tools/run_tests.py --godot /path/to/Godot --jobs 4
```
