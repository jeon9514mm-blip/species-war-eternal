# Pixel RPG v49 · 세로 UI와 텍스트 배치 개선

v48 작업본의 주요 화면을 점검하고 소스를 수정했습니다. 영웅·스킬·전투 수치와 재화 계산은 기존 게임 로직을 사용합니다.

## 수정 내용

| 화면 / 요소 | 확인한 문제 | 수정 |
| --- | --- | --- |
| 캠프·훈련·장비·소환·도감 등 | 가로 배치를 통째로 축소해 작은 글자와 버튼이 생김 | 세로 컨테이너와 한 개의 콘텐츠 스크롤로 교체. 본문 16~20, 카드 제목 24, 일반 동작 버튼 높이 52 기준 |
| 상단 헤더 | 긴 화면 제목과 재화 표시가 같은 가로 공간을 경쟁 | 뒤로 가기·제목·재화를 컨테이너로 분리. 긴 제목 두 줄, 설명 별도 행 |
| 모험 메뉴 | 제목 영역이 닫기 버튼과 겹침, 중복 메뉴 생성 가능 | 제목과 닫기 버튼을 별도 열로 배치. 한 개의 메뉴만 표시하고 창 크기에 반응 |
| 성장 콘텐츠 | 여정 제목과 설명 영역이 겹침 | 자연 높이의 개별 텍스트 행으로 분리 |
| 캠프 / 레이드 원정대 | 10인 가로 배치로 초상화와 글자가 지나치게 작아짐 | 캠프와 레이드를 5열·2행으로 표시. 레이드 이름과 HP 바를 분리 |
| 레이드 상태 | 긴 전투 결과가 시작 버튼 영역까지 커질 수 있음 | 고정 영역 안의 세로 스크롤로 긴 내용을 읽도록 변경 |
| 보스 경고 / 궁극기 | 가로 화면 좌표 때문에 경고와 레이드 연출이 화면 밖으로 나감 | 실제 화면 폭에 맞추고 중복 경고를 정리 |
| 필드 전투 결과 | 결과 알림이 스테이지·진행 표시 위에 놓임 | HUD 아래의 전장 영역으로 이동 |
| 버튼 / 팝업 | 남아 있던 밝은 테마와 어두운 테마가 혼재하고 버튼 상태별 글자 대비가 달라짐 | 네이비 표면·파란 버튼·금색 강조로 통일. hover / pressed / focus 글자 대비 보정 |
| 영웅 편성 | 작은 해제 버튼, 상세 화면 전환 후 이전 UI 참조가 남을 가능성 | 해제 버튼 확대, 화면 전환 시 편성 UI 참조 정리 |
| 화면 크기 변경 | 레이드 배치를 다시 만들면 보스·FX 객체를 잃을 위험, 시작 화면에 내비게이션이 생길 수 있음 | 살아 있는 보스·FX를 먼저 옮겨 전투 HP와 시간을 유지. 시작/진영 화면의 내비게이션 분리 |
| 오프라인 보상 | 세로 전투 HUD 설치 중 보상 팝업을 숨길 수 있음 | 보상 팝업과 배경을 유지 |

전체 축소 배치를 교체한 화면: 로그인, 캠프, 첫 만남, 출전 준비, 영웅 상세, 영웅 훈련, 가방, 성장 콘텐츠, 소환, 보상 센터, 사냥터, 지역 보스, 도감.

## 검증 결과

- Godot 4.7.2: 스크립트 168 / 168개 구문 검사 통과.
- 전체 회귀 테스트 89 / 89개 통과.
- 마지막 메뉴 크기 대응 수정 후 관련 테스트 3 / 3개 재검사 통과.
- 신규 UI 검사: 158개 화면 상태, 21,519 / 21,519개 조건 통과.
- 두 진영, 720×1280 / 720×1560 / 810×1440 화면, 빈 가방·빈 편성·잠긴 영웅, 긴 장비 이름, 큰 재화, 10인 편성, 결과·보상 팝업 포함.
- 별도 크기 변경 검사: 열린 메뉴 900×1600 ↔ 720×1280, 실시간 레이드 720×1560 ↔ 720×1280. 레이드 HP·경과 시간·진행 상태 유지 확인.
- 실제 콜백 검사: 영웅 배치/해제, 훈련 포인트 사용, 소환 비용 1회 차감, 선택한 장비 장착, 누적 보상 1회 수령.
- 기본 720×1280 캡처 데이터의 주요 메뉴 10종에서, 화면에 보이는 14 디자인 픽셀 미만 텍스트: 수정 전 111개 → 수정 후 0개.

검사는 Godot의 실제 Control 좌표와 폰트 줄 수·폭, 버튼 영역을 측정한 headless 검사입니다. GPU 화면 캡처나 Android/iOS 실기기 육안 검수는 이 환경에서 수행하지 못했습니다. 장식 이미지의 미관이나 모든 기기의 렌더링까지 보증하는 결과는 아닙니다.

## 소스 패치

`pixel-rpg-v49-ui-readability.patch`는 제공된 **v46.1 원본 ZIP**을 기준으로 v46.2 안정화, v47 UI·맵·자동사냥, v48 진영전, 이번 v49 변경을 모두 포함하는 누적 패치입니다. 이전 패치를 적용한 폴더에 중복 적용하지 말고 원본을 새 폴더에 풀어 사용하세요. 현재 작업 중인 소스 폴더에는 v49 수정이 이미 반영되어 있습니다.

원본 프로젝트 폴더에서:

```bash
git apply --check /path/to/pixel-rpg-v49-ui-readability.patch
git apply /path/to/pixel-rpg-v49-ui-readability.patch
```

Godot 4.7.2에서 `project.godot`을 열어 가져오기를 완료한 뒤 실행합니다. 그림·음원 등 원본 에셋은 원본 ZIP이 필요합니다. 플레이어 저장 파일은 패치에 포함하지 않습니다.

재검사:

```bash
python3 tools/run_tests.py --godot /path/to/Godot --jobs 4
```

UI만 검사하려면 `--tests V49PortraitLayoutSmokeTest.gd`를 추가합니다. `tools/ui/PortraitLayoutAudit.gd`는 화면별 Control 측정 JSON을 남깁니다. 그래픽 디스플레이가 연결된 환경에서는 PNG도 저장하며, headless에서는 이미지를 만들지 않습니다.
