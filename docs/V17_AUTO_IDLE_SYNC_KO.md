# v17 자동사냥·방치사냥·전선 재동기화

v17은 두 가지 목표를 함께 다룹니다.

1. 개인 RPG의 자동/방치사냥을 장기 운영형 게임에 맞게 안정화
2. v16 서버 권한 전쟁을 재접속·서버시간 기반으로 강화

## 1. 자동사냥 AI 개선

### 타깃 선택 공정성
기존에는 거리 + 누적 방문 횟수를 단순 합산했습니다. 장시간 사냥 시 방문 점수가 계속 커지는 구조를 개선해 **최소 방문 횟수 대비 상대 방문량**을 사용합니다.

추가로 최근 방문한 사냥 포인트와 길찾기 실패 포인트에는 임시 패널티를 줍니다. 가까운 두 지점만 반복하거나 막힌 지점을 계속 선택하는 현상을 줄입니다.

### 이동 정체 감지
한 목표로 12초 이상 이동 상태가 계속되면 해당 목표를 포기하고 자동 재탐색합니다.

### 회복과 길찾기 실패 분리
체력이 낮아서 안전 재정비를 하는 것은 길찾기 실패가 아닙니다. v17에서는 `retreat_target()`을 별도로 두어 회복 때문에 특정 사냥 포인트의 실패 점수가 올라가지 않습니다.

### 전투 진입 소프트락 방지
영웅 스프라이트가 프레임 드롭/애니메이션 오차 때문에 목표 배치점에 완전히 도착하지 못하면 전투가 영구 대기할 가능성이 있었습니다.

1.25초 이상 전투 진입 대기가 지속되면 남은 영웅 위치를 안전하게 정렬해 전투를 계속합니다.

### 위험도 기반 재정비
고정 HP 18%가 아니라 다음 요소를 함께 봅니다.

- 생존 영웅 비율
- 살아 있는 서포터 존재 여부
- 이동 중인지 여부
- 현재 적에 암살자 타입이 있는지

힐러가 없거나 많은 영웅이 쓰러졌을수록 더 일찍 재정비합니다. 반대로 살아 있는 서포터가 있으면 더 빠르게 전선으로 복귀합니다.

## 2. 방치사냥 계산 개선

`IdleHuntEstimator.gd`를 추가해 오프라인 보상 계산을 Main/UI에서 분리했습니다.

오프라인 처치 속도는 이제 다음을 반영합니다.

- 현재 원정대 전투력
- 지역 권장 전투력
- 편성 영웅 수
- 지역 난이도

따라서 약한 1인 파티와 성장한 5~10인 파티가 동일하게 5초당 1회 처치하는 문제가 사라집니다.

오프라인 보상에는 다음이 포함됩니다.

- 골드
- 경험치
- 동료 XP
- 종의전쟁 군량
- 제한된 장비 탐색
- 사냥 스테이지 자동 진행

오프라인 자동 스테이지 클리어는 한 접속당 최대 5단계, 장비 탐색 재현은 최대 32회로 제한합니다. 8시간치 수천 번의 장비 RNG를 한 번에 재생해 모바일 프레임이 멈추거나 인벤토리가 폭주하는 문제를 방지합니다.

## 3. 원정대 성장 1 → 10인

신규 플레이어 편성 한도:

- 스테이지 1: 1인
- 스테이지 3: 3인
- 스테이지 8: 5인
- 스테이지 15: 7인
- 스테이지 25: 10인

기존 v16 이하 저장 파일은 현재 편성 인원을 `party_slot_legacy_cap`으로 보존합니다. 업데이트 때문에 기존 3인/10인 원정대가 강제로 해제되지 않습니다.

## 4. 전쟁 서버시간 행군

`WorldMarchState`에 권한 서버 기준 시작/도착 시각을 추가했습니다.

- `authority_started_unix`
- `authority_end_unix`
- `last_authority_unix`

클라이언트가 큰 delta를 보내 행군을 즉시 완료시키는 대신 `WorldAuthorityService`의 서버 시간으로 진행률과 도착을 판단합니다.

중립 영토도 행군 레이어가 직접 소유권을 변경하지 않습니다. 행군은 도착 사실만 반환하고, 최종 점령은 Authority가 커밋합니다.

## 5. 재접속 / 스냅샷 동기화

`WorldAuthorityService.build_snapshot()`은 다음 authoritative 상태를 반환합니다.

- world
- march
- conflict
- revision
- server_time

`WorldWarClientSession`은 스냅샷을 적용하면서 로컬 상태를 서버 상태로 복원하고 서버시간 오프셋을 계산합니다.

추가된 동작:

- 전쟁 화면 진입 시 스냅샷 동기화
- 앱 전쟁 화면 복귀 시 재연결/재동기화
- stale revision 명령 거절 후 자동 재동기화
- 수동 `재동기화` 버튼
- 동기화 횟수 표시

로컬 권한 시뮬레이션에서는 연결이 끊기기 전 마지막 authoritative snapshot을 캐시해 재접속 테스트에 사용합니다. 실제 온라인 서버 연결 시 이 부분은 원격 서버의 최신 snapshot 응답으로 교체합니다.

## 6. 남은 온라인 과제

v17도 실제 인터넷 서버는 아닙니다. 다음 단계에서 실제 온라인화를 진행한다면 다음 순서가 안전합니다.

1. HTTPS/WebSocket DTO
2. 계정 인증 토큰
3. 서버 DB의 월드/행군/수비대 저장
4. 서버 push 또는 polling 기반 전쟁 갱신
5. reconnect snapshot 다운로드
6. 시즌 ID와 시즌 reset
7. 길드/진영 채팅 및 랭킹
