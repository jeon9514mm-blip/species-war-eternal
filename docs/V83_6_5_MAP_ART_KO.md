# v83-6.5 — 프롬프트 기반 맵 재질·조명 개선

사용자가 공유한 [맵 퀄리티 프롬프트](https://www.meta.ai/share/c/xyr4jPvlab)를 기준으로 Godot 4.7.2의 기존 3D 씬을 다듬었습니다. [추출한 프롬프트 원문](references/META_MAP_QUALITY_2026_10_02.txt)을 보관했습니다. 프롬프트의 Unreal Engine 5 / 8K 표현은 미술 방향으로 참고하며 엔진이나 텍스처 해상도를 바꾸지 않았습니다.

- 얼음 동굴: 기존 2K 노멀·거칠기 텍스처 연결, 면 방향에 맞는 표면 반사와 미세 균열, 암벽 윗면 서리, 외곽 빙정 파편, 문 주변 청색광.
- 붉은 협곡: 높이에 따른 지층 색과 돌출 선반, 따뜻한 낮은 태양광·차가운 주변광, 주변 자갈과 부유 먼지.
- 숲과 마법 유적: 녹색 수관, 위를 향한 암석의 이끼, 외곽 뿌리와 이끼 둔덕, 따뜻한 햇빛·청록색 반사광, 유적 주변 발광 입자.
- 공통: 바위 표면의 미세 요철, 지면 노멀 UV 정렬, 제한된 발광·안개·접촉 그림자. 새 정적 디테일과 입자는 MultiMesh로 묶습니다.

중앙 바닥 메시·문양 원본·충돌·스폰·내비게이션·전투 좌표는 유지합니다. 얼음의 깊이감은 불투명 재질의 색·반사·발광으로 표현하며 실제 굴절이나 투명 얼음은 이번 범위에 포함하지 않았습니다. 사냥/레이드 8개 원본 씬에 `ArtPolish` 노드를 저장해 게임과 갤러리에서 함께 사용합니다.

## 재현·편집

추가 장식은 `tools/MapArtPolish.gd`, 재질은 `assets/maps3d/materials/`에서 관리합니다. 원본 생성 도구에도 같은 미술 패스를 연결했습니다. 기존 수동 지형 편집을 유지하고 장식 패스만 다시 적용하려면 다음 명령을 사용합니다. 다시 적용할 때 기존 `ArtPolish`를 교체하므로 같은 장식이 누적되지 않습니다.

```sh
godot --audio-driver Dummy --path . --script tools/polish_3d_maps.gd
MAP_CAPTURE_DIR=/tmp/map-art godot --audio-driver Dummy --path . --script tools/capture_map_art.gd
```

## 검증 범위

Godot 4.7.2 파서 검사370/370개, 선택한 실행 검사5/5종의 총1,301개 조건을 통과했습니다. 실행 결과는 `checks/v83-6-5/validation.json`과 로그에 기록합니다. 정적 리소스·링크 검사와 아키텍처 단위 검사12개를 통과했습니다. 새 화면 캡처4개에는 셰이더 오류가 없습니다. Linux 소프트웨어 렌더링 결과이며 Android 실기기의 FPS·발열·메모리·Mobile 렌더러의 시각적 일치는 아직 확인하지 않았습니다. 고급 안개·SSAO는 렌더러별 지원에 따라 달라집니다.

클라우드 샌드박스에서 에디터의 TCP 소켓 생성이 차단되어, 에디터 전체 임포트 검사를 다시 완료하지는 못했습니다. 이미 임포트된 리소스를 사용한 스크립트 파서와 headless 실행 검사는 별도로 기록합니다. v83-6.4의 과거 검사 수치를 이번 변경의 결과로 재사용하지 않습니다.
