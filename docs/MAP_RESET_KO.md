# 맵 디자인 전체 초기화

2026-10-06 사용자 요청에 따라 현재 게임 작업본에서 기존 맵 디자인을 전부 제거했다. 사냥터 3곳과 레이드는 단색 빈 전장이다. 돌바닥과 룬 시안도 폐기했다. 새로운 초원 바닥 시안은 아직 게임에 적용하지 않았다. GitHub 반영도 하지 않았다.

삭제한 것은 PBR 바닥·룬·장식 메시·패럴랙스 이미지·기존 맵 배경·맵 그림자/조형물 셰이더·메뉴의 맵 썸네일·기존 디자인 빌더와 오래된 맵 제작 예시다. 삭제 목록과 해시는 `checks/map-reset/deleted-map-design-files.json`에 있다. 다른 작업 폴더의 과거 백업은 현재 게임의 실행 경로가 아니다.

기능 유지용으로 남긴 것은 카메라와 32×20m 좌표 변환, 영웅·몬스터 렌더링, 영웅의 접지 그림자와 팀 표시, UI, 전투/사냥 로직, 레이드 위험 구역과 입력, 기존 저장 키다. 지역 ID와 사냥 몬스터/보상도 유지한다. 삭제된 조형물의 숨은 장애물이 남지 않도록 시각적 장애물 카탈로그도 비웠다.

`GeneratedMapScene`과 `Battlefield3DView`는 이제 카메라·조명·좌표/스폰 메타데이터만 생성한다. 바닥 메시나 배경 그림을 만들지 않는다. `FieldArtCatalog`, `PortraitSky`, `PortraitScenery`, `PortraitMeadowProps`의 호환 API는 비어 있으며 기존 맵 이미지나 절차식 대체 지형을 불러오지 않는다. 재료/전경/고리의 이전 기본틀은 새 맵에 재사용하지 않는다.

## 새 디자인의 직접 기준

[컴투스 공식 소울스트라이크 플레이 화면](https://on.com2us.com/content/soul_strike/)의 초원과 [GameWith 실제 플레이 화면](https://gamewith.jp/gamedb/10700)을 직접 확인했다. 공식 공개 화면은 2024년 자료이며 2026년 최신 게임을 직접 실행해 조사한 것은 아니다.

소울스트라이크 초원은 화면 전체를 채우는 조용한 녹색 바닥, 드문 풀/꽃, 불규칙한 흙 패치, 캐릭터보다 낮은 바닥 명암, 짧은 접지 그림자가 특징이다. 하늘·원형 벽·중앙 마법진을 기본 구도로 잡지 않는다. 새 바닥 시안은 이 실제 화면들을 이미지 생성의 직접 참고로 사용했다. 원본 게임의 UI나 캐릭터는 시안에 넣지 않았다. 이 시안은 생성된 검토 이미지이며 실행 중인 우리 게임의 캡처가 아니다. 일치율 100%를 측정하거나 보장한 결과도 아니다.

## 검증

Godot 4.7.2에서 7개 검증 묶음, 총 2,045개 항목이 통과했다. 기본 사냥터 3곳의 맵 메시 부재, 영웅/몬스터 유지, 좌표 왕복, 경제/RNG 보존, 전투 카메라, HUD, 맵 교체, 갤러리, 레이드 입력/저장을 검사했다. 고정 경로로 불러오는 누락 리소스는 0개다.

실제 Mobile 렌더러로 `tools/capture_map_reset.gd`를 실행해 맵 제거 상태를 촬영한다. 캡처의 `map_meshes`는 바닥·조형물만 세며 영웅 몸체·접지 그림자·팀 표시 메시를 제외한다. 이미지/메타데이터와 로그는 `checks/map-reset/`에 있다.
