# v63 · 스킬 효과, 자동 전투 설정, 사냥 보상

## 화면과 전투

- 전투 스킬 아틀라스가 잘못된 좌표에서 잘려 보이던 이중 오프셋을 제거했습니다. 실제 적·아군 대상에만 효과를 놓고 전투 영역에서 클리핑합니다. 역할별 연출은 기존 30명 고유 스킬 이펙트와 같은 영역에 그립니다.
- 사냥과 레이드 화면에 `스킬 AUTO`와 `각성기 AUTO`를 각각 배치했습니다. 스킬을 끄면 액티브 A1/A2의 자동 시전이 멈추고, 각성기를 끄면 궁극기의 자동 시전이 멈춥니다. 켜고 끄는 선택은 저장됩니다. 기본 공격과 패시브 효과는 계속 작동합니다.
- 전투 속도는 ×1 ↔ ×2만 전환합니다. 이전 저장의 ×3 선택은 ×2로 낮춰서 불러옵니다.

## 보상

- **온라인 사냥**: 영웅 경험치는 기존처럼 전투 시 반영되고, 골드·계정 경험치·스테이지 상자 보상도 처치 후 자동 지급됩니다. 이전 버전의 미수령 온라인 보상과 레이드·퀘스트에서 발생한 일반 미수령 금액은 저장할 때 지갑으로 정산됩니다.
- **오프라인 사냥**: 이전과 같이 접속 시 추정 전투와 영웅 성장·장비 탐색이 계산됩니다. 골드·계정 경험치·오프라인 스테이지 상자 금액은 별도 장부에 보존하고 `오프라인 사냥 받기`에서 수령합니다. 중복 탭, 앱 재시작, 새 오프라인 정산은 각각 한 번만 지급합니다.
- 구 버전의 `보상 받기` 버튼은 사냥 HUD와 로비에서 제거했습니다. 기존 저장의 미수령 온라인 보상은 다음 정산 때 자동 지급됩니다.

## 적용과 확인

이 변경 묶음은 v62 프로젝트 루트에 적용합니다. Godot 4.7.2에서 `V63AutoFxOfflineSmokeTest.gd`와 `V53HuntFeedbackSmokeTest.gd`, `V59ThreeRaidVisualSmokeTest.gd`, `V31HeroFxSmokeTest.gd`를 확인하며 30명 효과·3종 레이드·버튼 배치·보상 중복 방지를 검사합니다.
