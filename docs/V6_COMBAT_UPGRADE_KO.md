# v6 다중 전투 시스템 업그레이드

v6는 v5의 자동사냥·10인 편성·저장·성장 시스템을 유지하면서 일반 사냥 전투를 **공용 HP 1개 + 몬스터 1마리** 구조에서 **영웅별 개별 HP + 2~5마리 동시 조우** 구조로 확장한 버전입니다.

## 핵심 변경

- 배치된 영웅마다 `hp / max_hp / attack / defense / role_group / slot` 전투 상태를 따로 가집니다.
- 10인 원정대는 일반 사냥에서 최대 5마리 몬스터 무리와 동시에 싸웁니다.
- 몬스터도 개별 HP와 공격 주기를 가지며 각각 독립적으로 공격합니다.
- 탱커는 기본적으로 적의 우선 공격 대상이며 방어 스킬 사용 시 도발과 개인 피해 감소를 얻습니다.
- 전열에 탱커가 없을 때는 3-4-3 편성의 전열 영웅을 우선 공격하고, 전열이 무너지면 생존 영웅에게 자동 재타깃합니다.
- 힐러는 공용 HP가 아니라 현재 HP 비율이 가장 낮은 살아있는 아군을 자동 선택합니다.
- 아스텔은 원정대 광역 회복, 엘리시아·이졸데는 위기 아군 집중 회복 역할로 분리했습니다.
- 일부 공격/제어 스킬은 여러 몬스터에 동시에 적용되는 광역기로 변환했습니다.
- 흡혈 스킬은 피해량에 따라 해당 영웅 자신의 HP를 회복합니다.
- 영웅과 몬스터 각각에 작은 HP 바를 표시해 전열 붕괴, 힐 대상, 적 처치 순서를 눈으로 확인할 수 있습니다.
- 전멸 또는 원정대 HP가 매우 낮아지면 재정비 상태로 전환하고, 쓰러진 영웅을 일으킨 뒤 85%까지 회복해 자동사냥을 재개합니다.

## 호환성 방향

지역 이동, 스테이지, 오프라인 보상, 장비, 저장 데이터와 레이드는 v5 구조를 유지합니다. 레이드의 공용 HP 전투는 기존 스모크 테스트 및 보상 흐름과의 호환성을 위해 이번 버전에서는 유지했습니다. 다음 단계에서 일반 사냥에서 검증된 개별 전투 모델을 레이드에도 확장할 수 있습니다.

## 추가 검증

`V6CombatSmokeTest.gd`는 다음 항목을 확인합니다.

1. 10인 개별 전투 상태 생성
2. 10인 파티 기준 5마리 적 웨이브 생성
3. 영웅·몬스터 개별 HP 바 생성
4. 탱커 도발에 따른 적 타깃 변경
5. 최저 HP 아군 자동 힐
6. 광역 스킬의 다중 적 피해

실행 명령:

```bash
godot --headless --path . --script res://tests/regression/V6CombatSmokeTest.gd
```
