# v20 실시간 배회형 자동사냥

v20은 기존의 `고정 조우 지점 도착 → 정지 전투` 구조를 제거하고, 필드 안에서 원정대와 몬스터가 동시에 움직이는 실시간 배회형 자동사냥으로 전환한 버전입니다.

## 핵심 변화

### 1. 고정 몬스터 지점 제거
기존 자동사냥은 `AutoHuntController`가 정해진 몬스터 스폰 좌표를 선택하고 그 위치에 정확히 도착해야 전투가 시작됐습니다.
v20에서는 전투 진입이 특정 고정 좌표에 묶이지 않습니다.

### 2. RoamingHuntDirector
새 `RoamingHuntDirector.gd`가 필드 이동을 담당합니다.

- 원정대 자유 순찰
- 몬스터 그룹 랜덤 위치 생성
- 몬스터 개별 배회
- 감지 반경 기반 어그로
- 자동 추격
- 거리 기반 교전
- 전멸 후 어그로 해제
- 다음 몬스터 그룹 탐색

### 3. 몬스터 역할별 이동
- brute: 느리지만 가까이 붙는 전열
- skirmisher: 조금 빠르게 접근
- assassin: 가장 빠르게 근접
- ranged: 일정 거리를 유지
- support: 후방 거리를 유지하며 회복

몬스터의 역할이 전투 수치뿐 아니라 실제 필드 이동에도 반영됩니다.

### 4. 실시간 거리 판정
영웅의 공격 사거리와 몬스터의 공격 사거리가 실제 필드 거리와 연결됩니다.

- 근접 영웅은 적 가까이 접근해야 공격
- 중거리 영웅은 조금 더 일찍 공격
- 후열/지원/제어 영웅은 먼 거리에서 공격 가능
- 원거리 몬스터도 거리를 유지한 채 공격
- 근접 몬스터는 파티 쪽으로 직접 추격

### 5. 10인 원정대 동적 대형
전투가 시작되면 전열 영웅은 적 방향으로 조금 전진하고, 중열은 소폭 전진하며, 후열은 뒤에 남습니다.
기존처럼 10명이 완전히 고정된 대형에서 동시에 타격하는 느낌을 줄였습니다.

### 6. 몬스터 이동 애니메이션
`MonsterSpriteController.gd`에 walk 상태와 월드 기준 좌표 API를 추가했습니다.
배회/추격 중에는 걷기 모션을 사용하고, 공격/피격/죽음 애니메이션은 이동 기준 좌표 위에 합성됩니다.

### 7. 자동사냥 흐름
현재 흐름:

`필드 자유 순찰 → 몬스터 배회 발견 → 감지 → 추격 → 거리별 실시간 교전 → 전리품 회수 → 다시 순찰`

기존 스킬 AI, 궁극기 AI, 영웅별 AI 성향, 정예 광폭화, 회복 AI는 그대로 유지됩니다.

## 아직 남아 있는 개선 방향
v20은 그룹 단위 실시간 필드 이동의 첫 버전입니다.

향후 발전 가능:
- 영웅 개별 NavAgent 이동
- 적별 개별 어그로 테이블
- 몬스터 다중 그룹 동시 존재
- 원거리 투사체 실제 이동
- 광역 스킬의 실제 원형/부채꼴 범위
- 장애물 회피
- 필드 크기 확대와 카메라 추적
- 몬스터가 화면 밖에서도 생성/소멸하는 스트리밍 방식

이 기능들은 현재 10인 파티 성능과 모바일 최적화를 확인한 후 단계적으로 추가하는 것이 안전합니다.
