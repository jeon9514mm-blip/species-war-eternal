# 휴대폰 터치와 드래그 스크롤

목록 안의 버튼을 누른 채 손가락을 움직여도 스크롤됩니다. 모든 ScrollContainer에 공통 입력 처리를 적용하므로 영웅 목록·장비 가방·상세 정보·설정 팝업과 가로 부대 목록에 같은 동작이 적용됩니다.

- 짧은 터치는 버튼을 한 번 실행합니다. 10 논리 픽셀 미만의 흔들림은 터치로 유지합니다.
- 드래그가 시작되면 버튼 누름을 취소합니다. 손을 뗄 때 선택·장착·구매가 실행되지 않습니다.
- 실제 손가락 좌표로 한 번만 이동합니다. Android가 함께 보내는 마우스 이벤트는 중복 스크롤에 사용하지 않습니다.
- 종료 이벤트를 엔진에 전달해 다음 버튼의 입력이 막히지 않게 합니다. 취소된 레이드 영웅 슬롯 입력도 실행하지 않습니다.
- 두 번째 손가락, 터치 취소, 포커스 이탈, 화면 숨김·삭제·크기 변경에는 진행 중인 동작을 취소합니다.
- 팝업과 중첩 목록은 실제 GUI 입력 대상에서 소유권을 결정합니다. 슬라이더·텍스트 입력·선택 상자·스크롤바는 고유 입력을 유지합니다.
- 마우스 드래그와 기존 휠 입력도 지원합니다. 손을 뗀 뒤 관성 이동은 추가하지 않았습니다.

Godot 4.6.3 headless에서 실제 InputEventScreenTouch/ScreenDrag를 Input.parse_input_event로 전달하고 엔진의 마우스 변환까지 검사했습니다. 새 터치 검사 51개, 영웅 메뉴 1,065개, 장비 팝업·저장 복구 163개, 지도·팝업 입력 99개와 전투 조작 검사를 통과했습니다. 지도 검사에는 이미 변경된 영웅 화면 이름을 반영했습니다. 변경한 스크립트 6개도 파싱을 확인했습니다.

프로젝트 기준 엔진은 4.7.2입니다. Android 실기기에서의 스크롤 감도와 OS 입력 동작은 아직 확인하지 않았으며 APK를 새로 빌드하지 않았습니다. 검사 기록은 [validation.json](../checks/touch-scroll/validation.json)에 있습니다.
