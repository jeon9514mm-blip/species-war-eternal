# Pixel RPG v50 · 대형 SLG 진영전

진영전을 큰 대륙 지도에서 정찰하고, 전술을 고른 뒤 출정하는 SLG 흐름으로 개편했습니다. 종의전쟁의 기존 진영·영웅과 세로 화면을 사용합니다.

## 변경 내용

| 요소 | 변경 |
| --- | --- |
| 대륙 규모 | 20×20, 400칸 → 40×40, 1,600칸. 서부 왕국·동부 변경·남부 연맹지·황혼 고원의 4개 권역 |
| 지형과 성곽 | 평면 사각형 지도를 마름모 형태의 입체 시점으로 변경. 숲·산맥·광산·유적·요새·대성·수도에 구분되는 지형과 건물 그림 |
| 지도 조작 | 1~8배 확대, 드래그, 두 손가락 확대, 미니맵 시점 이동, 내부대·추천 목표 이동, 자원·성곽 필터 |
| 영토 표시 | 진영별 색과 경계선, 수도 보호 지역, 보급 단절 표시, 행군 경로·화살표·이동 중 부대 깃발 |
| 화면 구성 | 지도를 크게 보여 주는 기본 화면과 펼치는 부대 지휘 패널. 720×1280 기준 지도 패널 높이 610, 지휘 패널을 펼치면 386 |
| 출정 절차 | 영토 선택 → 정찰·출정 준비 → 전술 선택 → 출정 확정. 첫 버튼으로 군량을 소모하지 않으며 확정 직전에 경로와 군량을 다시 검사 |
| 정찰 | 실제 수비대와 남은 HP를 반영한 전력 추정, 지형 방어, 군량, 이동 거리, 도착 시간, 편성 영웅과 부상 표시. 정찰 자체는 수비대를 생성하거나 회복시키지 않음 |
| 전술 | 균형: 기본 능력. 강습: 공격 +15% / 방어 -15%. 신중: 공격 -10% / 방어 +20%. 행군 중 변경 불가, 전투 종료 후 영웅 기본 능력 복원 |
| 중립 토벌 | 자원지·요새·대성에 Lv.1~4 영토 수비대. 도착 시 실제 전투를 거쳐 점령. 실패하면 원 주둔지로 복귀하고 양쪽의 부상 유지 |
| 전투 보고 | 일반 공격·중립 토벌·집결의 실제 턴별 잔여 HP와 피해량, 생존자·피로·격파 기록을 스크롤로 확인 |
| 가독성 | 정찰창의 10인 편성은 스크롤 안에 배치하고 출정·닫기 버튼은 고정. 긴 내용이 정렬되는 도중 팝업이 화면 밖으로 커지던 현상 수정. 어두운 패널과 밝은 글자 대비 통일 |

새 전술은 진영전 전투에만 적용합니다. 일반 자동사냥과 영웅의 기본 능력·스킬에는 적용하지 않습니다. 기존 지원 주둔·집결·수도 귀환·행군 취소·시즌 보상은 부대 지휘/시즌 메뉴에서 사용할 수 있습니다.

## 저장 데이터

- 기존 수도, 영토, 부대와 행군 좌표를 옮기지 않고 동쪽·남쪽으로 대륙을 추가합니다.
- 이전 400칸 저장 데이터의 영토 소유권·지형·군량·명예·부상은 유지합니다. 기존 영토에 새 수비대를 강제로 추가하지 않고 새 권역에는 수비대를 배치합니다.
- 새 게임은 기존 권역의 자원지·성곽에도 수비대가 있습니다.
- 전술과 중립 수비대의 부상은 저장/복원됩니다. 월드 버전 5, 저장 버전 30으로 올려 구버전 프로그램이 새 저장 파일을 덮어쓰지 않게 합니다.

## 검증

- Godot 4.7.2: 스크립트 **172/172개** 구문 검사 통과.
- 전체 회귀 검사 **91/91개** 통과. 최종 정찰/추천 수정 후 관련 검사 **3/3개** 재검사 통과.
- 신규 진영전 로직 검사: **852개 조건** 통과. 400칸 저장의 영토 유지와 1,600칸 복원, 수비대 승패, 부상 저장, 전술 검증, 단독/집결 전술 적용, 시즌·소유권·보급 변경, 보상 중복 방지 포함.
- 신규 진영전 UI 검사: **21개 화면 상태, 3,049개 조건** 통과. 양쪽 진영과 720×1280 / 720×1560 / 810×1440 화면, 10인 편성 정찰창, 확대/축소, 미니맵, 출정 확정과 비용 재검증 포함.
- 기존 전체 세로 UI 검사: **158개 화면 상태, 21,501개 조건** 통과. 일반 메뉴·자동사냥·레이드·성장 화면도 함께 검사.
- 화면 밖으로 커진 정찰창을 발견한 초기 검사는 실패했으며, 레이아웃 재계산 수정 후 최종 검사에서 해결을 확인했습니다.

Godot headless에서 실제 UI Control 영역·한글 폰트 줄 수와 폭·버튼 콜백을 검사했습니다. GPU 화면 캡처, Android/iOS 실기기 터치감·성능·육안 검수는 이 환경에서 수행하지 못했습니다. 기존의 기기 내 전선 모드를 개선한 것으로, 새 온라인 멀티플레이 서버를 구현한 것은 아닙니다.

## 적용

`pixel-rpg-v50-slg-war.patch`는 제공된 **v46.1 원본 ZIP** 기준의 누적 패치입니다. v46.2 안정화, v47 UI·맵·자동사냥, v48 진영전, v49 가독성, 이번 v50 변경을 포함합니다. 이전 패치를 적용한 폴더에 중복 적용하지 말고 원본을 새 폴더에 풀어 사용하세요. 현재 작업 소스 폴더에는 수정이 이미 반영되어 있습니다.

원본 프로젝트 폴더에서:

```bash
git apply --check /path/to/pixel-rpg-v50-slg-war.patch
git apply /path/to/pixel-rpg-v50-slg-war.patch
```

Godot 4.7.2에서 `project.godot`을 열고 가져오기를 마친 뒤 실행합니다. 원본 이미지·음원은 원본 ZIP을 사용합니다. 개인 플레이어 저장 파일은 패치에 포함하지 않습니다.

전체 검사:

```bash
python3 tools/run_tests.py --godot /path/to/Godot --jobs 4
```

이번 진영전 검사만 실행하려면 `--tests V50CampaignSmokeTest.gd V50CampaignUiSmokeTest.gd V48WarUiSmokeTest.gd`를 추가합니다.
