# v13 행군 · 안전지대 · 열세 진영 보호

v13은 v12의 20×20 종의전쟁 월드맵 위에 실제 행군 흐름과 진영 복구 장치를 추가한 버전입니다.

## 행군
- 영웅 10명은 월드맵에서 1개 부대로 취급합니다.
- 선택한 전선까지 아군 영토만 따라 BFS 경로를 계산합니다.
- 이동 거리만큼 군량과 시간이 필요합니다.
- 열세 진영은 행군 속도와 군량 효율 보정을 받습니다.
- 도착하면 아군 타일에서는 주둔, 중립 타일에서는 점령합니다.
- 행군 상태는 저장되며 전쟁 화면에 다시 들어올 때 경과 시간을 따라잡습니다.
- 진행 중 행군 취소 시 소비 군량의 50%를 반환합니다.
- 수도 귀환도 동일한 행군 규칙을 사용합니다.

## 안전지대
아우렐리아와 녹스페라 수도 주변 반경 2칸은 영구 안전지대입니다.
해당 타일은 상대 진영이 점령할 수 없도록 전쟁 상태 규칙에서 차단합니다.
이는 한쪽 진영이 완전히 소멸하여 시즌이 사실상 끝나는 상황을 막는 최후의 재건 거점입니다.

## 열세 진영 보정
영토 비율에 따라 저항 단계가 자동 계산됩니다.

- 균형: 보정 없음
- 저항 I: 행군 +10%, 군량 -10%, 방어 +10%, 자원 +5%
- 저항 II: 행군 +20%, 군량 -20%, 방어 +18%, 자원 +10%, 수도 주변 보호 반경 4칸
- 최후의 저항: 행군 +30%, 군량 -30%, 방어 +28%, 자원 +18%, 수도 주변 보호 반경 5칸

공격 피해량은 올리지 않습니다. 열세 진영의 회복 기회를 제공하되 직접 전투 결과를 강제로 뒤집지 않는 방향입니다.

## 개인 RPG와 연결
일반 자동사냥에서 군량을 소량 얻고, 사냥 스테이지를 클리어하면 추가 군량을 얻습니다.
즉 개인 성장과 월드전이 별도 게임이 되지 않도록 `자동사냥 → 군량 확보 → 월드 행군` 루프를 연결했습니다.

## 코드 분리
- `WorldWarState.gd`: 영토, 안전지대, 열세 보정, 보급선 경로, 군량 규칙
- `WorldMarchState.gd`: 행군 계획, 시간, 비용, 취소, 저장/복원
- `WorldWarMapView.gd`: 안전지대/최후 방어선/행군 경로 표시
- `WorldWarScreen.gd`: 출정/취소/귀환 UI
- `Main.gd`: 저장 및 개인 RPG와의 군량 연결만 담당

PvP 10vs10 해결은 v14에서 별도 `WorldBattleResolver`로 추가하는 것을 전제로 합니다.
