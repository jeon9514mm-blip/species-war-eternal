# 아우렐리아 영웅 원화·부위 조립 작업

## 사용자 피드백과 현재 기준

아우렐리아는 레온하르트를 포함해 15명입니다. 나머지 신규 대상은 14명이며, 다른 진영 15명은 이번 원화 교체 범위에 포함하지 않습니다.

처음 제작한 약 4등신 원화와 25파트 조립 초안에 대해 사용자가 다리가 짧고 조립이 부자연스럽다고 지적했습니다. 이후 **다리가 더 길고 날렵한 4.5~5등신**을 선택했습니다. 이전 짧은 비율은 더 이상 제작 목표가 아닙니다.

현재는 레온하르트를 먼저 수정합니다. 얼굴과 앞머리를 하나의 완성된 그림으로 유지하고, 가슴부터 허리까지 연결된 몸통과 움직임에 필요한 팔다리를 분리합니다. 파트 개수를 채우기 위해 얼굴·몸통을 과도하게 나누지 않습니다. 새 기준 원화와 실제 조립 자세를 비교한 뒤 나머지 영웅을 확장합니다.

## 실제 구조

- `HeroPartsCatalog.gd`: 기존 영웅 ID·무기·역할을 유지하며, 투명 원화 영역과 부위별 관절·앵커를 검증합니다. 영웅별 `joint_rest`로 허리·무릎·발목 위치를 조정합니다.
- `HeroPartsRig3D.gd`: 독립된 부위 그림을 21개 계층 관절에 연결합니다. 전체 몸 이미지 하나를 흔드는 방식과 구분됩니다. 입체 모델의 뒷면이나 임의 카메라 회전을 제공하는 구조는 아닙니다.
- `HeroPartsStudy.tscn`: 영웅 15명, 기존 동작 16종, 별도의 기준 자세를 검토하는 독립 F6 장면입니다. 기준 자세는 17번째 전투 동작이 아닙니다.
- 실제 사냥은 기존 컨트롤러의 동작·프레임 진행과 이동 거리를 읽습니다. 조립 렌더러가 타격 시점, 피해량, 이동 좌표나 저장 데이터를 변경하지 않습니다.

## 품질 검수

기준 자세에서는 움직임·관절 보정 없이 실제 연결 위치를 확인합니다. 이후 대기, 걷기, 공격의 준비·타격·회복을 크게 캡처하고 16동작의 실루엣을 확인합니다. 원화만 예쁘게 보이거나 기능 검사가 통과한 것은 조립 품질 통과를 의미하지 않습니다.

`parts.json`의 `reviewed`와 `component_integrity_verified`가 모두 참인 영웅만 독립 사냥 시범에 연결합니다. 미검수 초안은 영웅 검토 장면에서만 열리며, 사냥 화면은 기존 표현을 유지합니다. 기본 F5 실행 장면은 이 작업으로 바꾸지 않습니다.

기존 16개 동작을 읽는 구조와 새 동작의 시각적 완성도는 별도로 기록합니다. 15명×16종의 새 수작업 프레임 애니메이션 240개를 완성했다는 의미가 아닙니다.

## 검토 파일

레온하르트의 첫 원화·25파트 초안은 `assets/art-direction/aurelia-4head/leonhardt/draft-01/`에 보존합니다. 생성 원본과 수정 프롬프트는 영웅별 출처 JSON에 기록합니다. `aurelia-4head` 디렉터리명은 기존 경로 호환을 위한 이름이며, 현재 목표 비율은 4.5~5등신입니다.

대형 비교 캡처는 `tools/capture_leonhardt_quality_review.gd`, 전체 동작 시트는 `tools/capture_aurelia_pose_sheets.gd`로 실제 Godot 렌더를 기록합니다. 화면 왼쪽의 정적 원화와 오른쪽의 실제 조립 렌더를 명확히 구분합니다. 영상 기록 프레임 수는 모바일 실기기 FPS 측정값이 아닙니다.

## 검·손 연결 수정 결과

레온하르트는 새 원화에 맞춘 **18개 독립 그림과 21개 관절**로 조립합니다. 얼굴의 중복 목깃, 무릎 장식 중복, 과도한 발목 연결부와 희미한 배경 알파가 만드는 사각형을 수정했습니다. 발·무릎·목 위치는 실제 확대 렌더를 기준으로 맞췄습니다.

검의 그립 오프셋을 장비 관절의 고정 위치로 옮겨 회전할 때 손에서 벗어나지 않게 했습니다. 기본 공격 두 동작에서는 검과 공격 팔을 몸통·방패 앞에 함께 배치하고, 복귀 때 원래 깊이를 복원합니다. 검의 독립 방향 곡선 대신 팔의 관절 회전으로 검 궤적을 만들며, 공격 손목은 약 6.88도 이내로 움직입니다. 방패·검을 든 나머지 동작에도 손목 회전 상한을 적용했습니다.

변경 관련 스크립트 12개, 부위·그립·동작 검사 803개, 실제 사냥·화면 복귀·저장 격리 검사 413개를 통과했습니다. 기본 공격은 각 241개 진행 위치에서 손목·팔꿈치·연속성을 확인했고 16종 전체의 양손 손목 상한도 검사했습니다. 이는 원화·동작의 최종 시각 승인을 대신하지 않습니다.

레온하르트의 16동작은 검토 가능한 절차적 시안입니다. 나머지 14명은 길어진 비율의 원화가 준비됐으며 새 파트 조립·개별 동작은 후속 작업입니다. 이전 짧은 파트 초안은 `draft-01`에 보존하고 활성 파트로 사용하지 않습니다. `reviewed=false`를 유지하므로 기본 게임과 실제 사냥 영웅이 새 그림으로 자동 교체되지는 않습니다.
