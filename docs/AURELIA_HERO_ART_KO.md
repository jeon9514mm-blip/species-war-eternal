# 아우렐리아 영웅 원화·부위 조립 작업

## 사용자 피드백과 현재 기준

아우렐리아는 레온하르트를 포함해 15명입니다. 나머지 신규 대상은 14명이며, 다른 진영 15명은 이번 원화 교체 범위에 포함하지 않습니다.

처음 제작한 약 4등신 원화와 25파트 조립 초안에 대해 사용자가 다리가 짧고 조립이 부자연스럽다고 지적했습니다. 이후 **다리가 더 길고 날렵한 4.5~5등신**을 선택했습니다. 이전 짧은 비율은 더 이상 제작 목표가 아닙니다.

레온하르트의 검·손 연결 수정 후 나머지 14명의 부위 원화와 무기별 동작 시안을 확장했습니다. 얼굴과 앞머리를 하나의 완성된 그림으로 유지하고, 가슴부터 허리까지 연결된 몸통과 움직임에 필요한 팔다리를 분리합니다. 파트 개수를 채우기 위해 얼굴·몸통을 과도하게 나누지 않습니다. 새 기준 원화와 실제 조립 자세를 비교한 뒤 나머지 영웅을 확장합니다.

## 실제 구조

- `HeroPartsCatalog.gd`: 기존 영웅 ID·무기·역할을 유지하며, 투명 원화 영역과 부위별 관절·앵커를 검증합니다. 영웅별 `joint_rest`로 허리·무릎·발목 위치를 조정합니다.
- `HeroPartsRig3D.gd`: 독립된 부위 그림을 21개 계층 관절에 연결합니다. 전체 몸 이미지 하나를 흔드는 방식과 구분됩니다. 입체 모델의 뒷면이나 임의 카메라 회전을 제공하는 구조는 아닙니다.
- `HeroPartsStudy.tscn`: 영웅 15명, 영웅별 절차적 동작 16종, 별도의 기준 자세를 검토하는 독립 F6 장면입니다. 기준 자세는 17번째 전투 동작이 아닙니다.
- 실제 사냥은 기존 컨트롤러의 동작·프레임 진행과 이동 거리를 읽습니다. 조립 렌더러가 타격 시점, 피해량, 이동 좌표나 저장 데이터를 변경하지 않습니다.

## 품질 검수

기준 자세에서는 움직임·관절 보정 없이 실제 연결 위치를 확인합니다. 이후 대기, 걷기, 공격의 준비·타격·회복을 크게 캡처하고 16동작의 실루엣을 확인합니다. 원화만 예쁘게 보이거나 기능 검사가 통과한 것은 조립 품질 통과를 의미하지 않습니다.

`parts.json`의 `reviewed`와 `component_integrity_verified`가 모두 참인 영웅만 독립 사냥 시범에 연결합니다. 미검수 초안은 영웅 검토 장면에서만 열리며, 사냥 화면은 기존 표현을 유지합니다. 기본 F5 실행 장면은 이 작업으로 바꾸지 않습니다.

기존 16개 동작을 읽는 구조와 새 동작의 시각적 완성도는 별도로 기록합니다. 15명×16종의 새 수작업 프레임 애니메이션 240개를 완성했다는 의미가 아닙니다.

## 검토 파일

레온하르트의 첫 원화·25파트 초안은 `assets/art-direction/aurelia-4head/leonhardt/draft-01/`에 보존합니다. 생성 원본과 수정 프롬프트는 영웅별 출처 JSON에 기록합니다. `aurelia-4head` 디렉터리명은 기존 경로 호환을 위한 이름이며, 현재 목표 비율은 4.5~5등신입니다.

대형 비교 캡처는 `tools/capture_leonhardt_quality_review.gd`, 전체 동작 시트는 `tools/capture_aurelia_pose_sheets.gd`로 실제 Godot 렌더를 기록합니다. 화면 왼쪽의 정적 원화와 오른쪽의 실제 조립 렌더를 명확히 구분합니다. 영상 기록 프레임 수는 모바일 실기기 FPS 측정값이 아닙니다.

## 검·손 연결 수정 결과

레온하르트는 새 원화에 맞춘 **18개 독립 그림과 21개 관절**로 조립합니다. 얼굴의 중복 목깃, 무릎 장식 중복, 과도한 발목 연결부와 희미한 배경 알파가 만드는 사각형을 수정했습니다. 발·무릎·목 위치는 실제 확대 렌더를 기준으로 맞췄습니다.

검의 그립 오프셋을 장비 관절의 고정 위치로 옮겨 회전할 때 손에서 벗어나지 않게 했습니다. 기본 공격 두 동작에서는 검과 공격 팔을 몸통·방패 앞에 함께 배치하고, 복귀 때 원래 깊이를 복원합니다. 검의 독립 방향 곡선 대신 팔의 관절 회전으로 검 궤적을 만들며, 공격 손목은 약 6.88도 이내로 움직입니다. 방패·검을 든 나머지 동작에도 손목 회전 상한을 적용했습니다.

## 14명 부위 원화 확장 · 2026-10-03

각 영웅의 기존 얼굴·의상·색·무기를 기준으로 독립 원화를 생성했습니다. 얼굴/앞머리, 뒤 머리, 연속 몸통, 망토, 주무기, 보조 장비, 양팔의 상완·전완·손, 양다리의 허벅지·정강이·발을 분리했습니다. 원화 전체를 잘라 단일 그림을 흔드는 구조가 아닙니다.

초기 그림 중 부위 영역이 겹친 12명은 생성 도구로 간격을 수정했습니다. Odelia는 책과 망토 사이를 추가로 수정했습니다. 최초 원본은 `spacing-draft-01`에 보관합니다. 분석 도구는 PNG 픽셀을 변경하지 않고 알파 영역과 관절 메타데이터만 기록합니다.

`AureliaPartsMotion.gd`는 영웅별 힘·민첩성·옷 움직임과 무기 방식에 맞춘 16개 절차적 시안입니다. 활 시위 당김, 창/결투검 찌르기, 쌍검 교차, 대검 베기, 대포 반동, 치유/지팡이/책 시전을 구분합니다. 활·대포의 보조 손은 `AureliaGripConstraint.gd`에서 실제 팔다리 길이에 맞춰 계산합니다. 손목은 15도 이내이며, 81개 진행 위치씩 검사한 양손 연결 오차는 키의 1.5% 미만입니다.

검증: 변경 관련 GDScript 9개 문법 검사, 전체 부위·동작·전투 검사 **10,706개**, 실제 기존 사냥 8방향을 통과했습니다. 14명×16개 검토 장면 구성도 통과했으나 `prepared-pose-sheets` 결과는 **헤드리스 구성 검사**이며 화면 캡처가 아닙니다.

실제 렌더 기록 도구: `python tools/render_aurelia_roster_review.py`. Godot 화면 서버 접근이 허용된 환경에서 확대 비교 PNG, 16동작 시트와 실제 동작 MP4를 생성합니다. `--prepare`는 구성만 검사하며 실제 렌더를 주장하지 않습니다. 현재 상태는 확대 렌더를 확인하고 최종 디자인 승인을 기다리는 조립 시안입니다. 검토 전에 `reviewed`를 켜지 않습니다.

실제 확대 렌더에서 지팡이 크기와 얼굴 가림, 손 그림의 원래 방향, 손바닥의 손잡이 접점을 수정했습니다. 무기 피벗은 지팡이 축의 실제 알파 위치를 읽어 맞추고, 손목 관절과 손가락의 그립 위치를 구분합니다. 활은 준비 때 화살을 보이고 발사 뒤 숨기며 복귀 때 다음 화살을 표시합니다. 이는 화면 표현만 바꾸며 투사체·타격·전투 수치에 추가 쓰기를 하지 않습니다.

## 관절 재작업 — 2026-10-04 (한국 시간)

사용자가 15명 전체의 관절·무기 비율과 목 연결을 지적했습니다. 앞선 렌더와 자동 검사 통과를 디자인 완성으로 보지 않습니다. 이전 부위/메타데이터는 `anatomy-draft-02/`에 보존하고, 14명의 팔·손·다리 중복 그림을 생성 도구로 수정했습니다.

`tools/hero-anatomy/<hero>.json`은 영웅마다 다른 원화상의 관절과 옷깃 좌표, 부위 그림의 연결점을 기록합니다. `fit_aurelia_anatomy.py`는 이 좌표를 실제 메시/관절에 맞추며 PNG를 수정하지 않습니다. 알파 외곽으로 부위 메시를 만들어 인접 그림의 중복 추출을 막습니다. 목 밑점은 몸통 옷깃에 연결되고 옷깃이 절단선을 덮습니다. 얼굴 아래의 작은 피부 끝만 부드럽게 처리하고 머리 회전 범위를 약 6도로 제한합니다.

기능 검사 **11,456개**가 통과했습니다. 각 동작의 33개 진행 위치에서 실제 메시 UV가 변환된 목·옷깃과 관절 끝점의 연결을 확인합니다. 무기의 가로/세로 비율을 보존하고 영웅별 신체 대비 길이로 맞춥니다. 활 두 영웅은 시위 당김이 가능한 팔의 준비 자세를 따로 지정했습니다. 결과는 실제 확대 렌더 검수와 사용자 승인 전이며, 기존 게임 기본 표현을 자동 교체하지 않습니다.

### 현재 남은 시각 문제 · 2026-10-04

15명 원화와 부위·동작 코드를 저장소에 공개하지만 최종 승인된 디자인은 아닙니다. 실제 15명 정면 조립 화면을 다시 확인했습니다. 이미지가 누락되거나 대체 텍스처로 표시되는 현상은 없었지만, 일부 팔꿈치·무릎 절단선과 무기 비율은 여전히 어색합니다.

미라·엘리시아는 몸통 원화의 목 끝이 머리 쪽 목과 겹치는 원인을 확인했습니다. 원화 PNG는 보존하고 몸통의 특정 목 패치만 셰이더에서 가립니다. 미라는 옷깃의 검은 테두리를 보존하도록 피부색 영역을 구분하고 목 접점도 다시 맞췄습니다. 확대 기준·대기·걷기·공격·스킬 화면을 다시 기록했습니다. 작은 경계와 다른 영웅의 관절 조립 개선은 남아 있습니다. 자동 검사 통과가 자연스러운 동작이나 시각적 완성도를 보장하지 않습니다. 모든 영웅은 `reviewed=false`를 유지합니다.
