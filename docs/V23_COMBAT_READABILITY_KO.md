# v23 전투 가독성 / 전술 HUD 업그레이드

## 목표
실시간 배회 자동사냥에서 플레이어가 전투 상황을 한눈에 읽도록 전투 HUD를 강화했습니다.

## 변경
- 1~10명 배치 영웅별 전술 카드: HP%와 궁극기 게이지 표시
- 궁극기 100 도달 시 `ULT!` 강조
- HP 30% 이하 위험 색상 강조
- 현재 어그로/추격 대상 위에 `◎ TARGET` 역할 마커
- 정예 몬스터 조우 경고
- 정예 체력 40% 이하 광폭화 시 상단 위험 배너
- 기존 실시간 배회/추격/거리별 공격 AI와 결합
- 전투 이펙트와 정보 UI가 서로 겹치지 않도록 하단 HUD 재배치
