# v19 서버 안정성 · 영웅 AI 정체성 · 진영 밸런스 · UI

v19는 보상 확장보다 기반 완성도를 우선합니다.

## 1. 서버 안정성
- `WorldSyncGuard.gd` 추가
- heartbeat 5초 주기 기반 연결 상태 확인
- 서버 revision이 클라이언트보다 앞서면 자동 재동기화
- 오래된 snapshot revision은 적용 거부
- 서버 시간 offset은 한 번에 급격히 변경하지 않고 단계적으로 보정
- 큰 시간 오차는 UI에 `서버 시간 보정 중`으로 표시
- 재연결 시 오래된 gateway cache를 authoritative 상태로 복원하지 않고 최신 snapshot을 다시 요청
- 재접속 실패 backoff 상한 15초
- Authority 처리 명령/idempotency cache 최대 256개로 제한해 장시간 서버 메모리 증가 방지
- 전쟁 UI에서 `서버 상태 안정 / 상태 불일치 / 연결 끊김 / 시간 보정`을 표시

## 2. 영웅별 전투 정체성
`HeroIdentityCatalog.gd`에 20명 전부 개별 프로필을 분리했습니다.

프로필 요소:
- AI 성향
- 고유 전투 정체성
- HP/공격/방어 보정
- 기본 공격 간격
- 궁극기 충전 속도
- 스킬 재사용 시간
- 스킬 수치
- 제어 지속시간
- 흡혈/생존 성향

AI 성향:
- 수호 우선
- 지원 우선
- 제어 우선
- 공격 우선
- 처형 우선
- 생존 공격
- 균형 전술

이 성향은 단순 UI 텍스트가 아니라 `AutoCombatTactics`의 스킬/궁극기 우선순위에도 반영됩니다.

## 3. 진영 방향과 밸런스
아우렐리아:
- 수호/정밀/회복 중심
- 전열 안정과 장기전
- Human 탱커 + Elf 지원/제어 조합 강점

녹스페라:
- 흡혈/광폭/약화 중심
- 빠른 공격 템포와 위험-보상
- Vampire 지속전 + Werewolf 공격 템포 강점

두 진영을 같은 캐릭터의 색상만 바꾼 미러 구조로 만들지 않되, `balance_budget()`으로 전체 수치 예산을 비교합니다.
현재 10명 평균 전투 예산 차이는 약 1% 미만으로 맞춰 두었습니다.
개별 영웅은 역할에 따라 강점/약점이 있지만 과도한 단독 상위호환을 피하도록 범위를 제한합니다.

## 4. UI 개선
영웅 카드:
- AI 성향
- 고유 특성명
- 실제 전투 행동 설명

편성 패널:
- 탱커/딜러/지원/제어 숫자 즉시 표시
- 탱커 없음, 회복 없음, 제어 없음 등 편성 약점을 자동 안내
- 역할 균형이 맞으면 현재 시너지 표시

영웅 상세:
- AI 전술
- 고유 정체성
- 행동 특성 설명

자동사냥 HUD:
- 현재 편성의 역할 구성을 표시

종의전쟁 HUD:
- heartbeat 기반 연결 건강도
- revision / sync 횟수
- 서버 시간 보정/재동기화 상태

## 5. 월드전 영웅 정체성
개인 사냥에서만 영웅 개성이 적용되고 종의전쟁에서는 사라지는 문제를 막기 위해,
`_world_party_snapshot()`에도 영웅별 HP/공격/방어 정체성 보정과 identity 정보를 포함합니다.
