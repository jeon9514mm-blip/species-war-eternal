# Unity CP18 · 고유 스킬 문양과 딥 표현 기반
2026-10-09. 기존 30명, 120개 스킬, 10인 사냥, 성장 기록, 직접 이동 조이스틱, 세 레이드와 원화 기반 2.5D 방향을 유지한다.

## 이번 변경
- 30명 고유 문양: 두 개의 5×3 RGBA 아틀라스. 원본 생성 이미지를 그대로 복사하고 실제 알파를 보존했다. 영웅별 한 문양을 원래 네 슬롯 프로필의 차징/비행/명중/잔상에 연결한다. 120개 별도 원화 제작이라는 뜻은 아니다.
- 스킬 상세: 원화, 실제 이름과 설명, 발동 조건/쿨타임, 영웅 문양을 함께 표시한다. 원래 스킬 종류와 피해 수치는 변경하지 않았다.
- 명중 피드백: 확정된 피해 이벤트만 관찰한다. 투사체 비행 시간 뒤 숫자·피격 반짝임·타격음·스파크·흔들림을 표시한다. HP/상태/쿨타임/보상/전투 시계는 원래 순간에 계산된다. 최대 128개 지연 표시; 초과분의 시각 피드백만 생략한다. 전투 전환/결과 시 오래된 표시를 취소한다.
- 레이드 성공: 실제 interrupt/counter/shield_break/mechanic_success 이벤트에만 반응한다. 성공 안내가 좌측 레인의 궁극기 컷인보다 먼저 보이고, 전조/모달/결과에는 가리지 않는다. 모의 성공 이벤트를 실제 보상이나 판정으로 바꾸지 않는다.
- 영웅별 카드·망토: 30명에 카드 수/바람/클러스터/흩날림/망토 3·5점 프로필을 작성했다. 레온하르트 300, 미라 600, 오르윈 200, 다리우스 100, 라그나 400 등 실제 렌더 삼각형 수가 바뀐다. 공유 600 카드 원본에서 고르게 골라 별도 메시로 사용하고 원본 캐시는 보존한다. 기존 카이렌·오르윈·카엘룸 의상 원화도 유지한다.
- 몸통: 발 고정 1초/2.5px 호흡, 기존 3px 외곽선, 화면 필터를 거친 직물 미세 결, 림 0.25와 얇은 표면 역광 색 보완. 머리카락 뿌리는 고정하고 끝의 최대 변위를 제한한다.
- 털: 라그나·펜리스·가름·울리크·보라, 타락한 늑대인간, 멧돼지/개 계열에 여섯 겹의 희박한 실루엣 셸을 덧댄다. 동일 원화를 여섯 번 불투명하게 겹치지 않고 알파 경계의 가는 부분만 표시한다.
- 기존 몬스터 분리/정렬 15%/응집 8%, 1–8초 성격 전환, 종별 이동/호흡, 높은 스테이지의 원래 스킬·디버프 로직은 유지했다. 사망 이벤트는 12개 붉은 스파크와 50% 확률 타격음을 표시한다. 경험치로 실제 레벨이 올라간 영웅에만 20개 파티클과 보상음을 표시한다.
- 카메라: 고정 중심 배율 ×1/×1.5/×2/×3을 유지하고, 10초/3px 화면 기준 미세 이동, 일반 5px/크리티컬 10px Perlin 흔들림 0.25초, 크리티컬 ×1.15 줌 0.20초, 최대 3도 순간 롤을 더했다. 전조 중 강한 카메라·렌즈 연출을 억제한다.
- 분위기: 20개 먼지에 세 깊이층을 두었다. 실행 시 소유하는 Volume 복사본에서 Bloom 0.60, Vignette 0.35/부드러움 0.75, 크리티컬 색수차 0.05/렌즈 왜곡 -0.05/필름 그레인 최대 0.15를 사용한다. 저장된 공용 Volume 에셋을 수정하지 않는다.
- 빌드용 DeepLensVariants 프로필은 이번 세 렌즈 기능의 활성 변형을 보존한다. URP의 전체 스트리핑을 끄거나 기존 DOF/Panini 제거 문제를 변경하지 않는다.

## 참고 자료 확인
[Meta 사양 문서](https://www.meta.ai/share/a/7504c581-279c-4675-8dca-c21b4862b2d5)는 브라우저의 공개 HTML 본문을 읽었다. 두 번째 [v48 ZIP 링크](https://www.meta.ai/share/a/956c38f2-41d8-4307-8c4f-19a7af95c936)는 ZIP 이름과 다운로드 링크까지만 확인했으며 다운로드가 시간 초과/401 권한 오류로 실패했다. ZIP 내부 코드를 검토하거나 적용했다고 주장하지 않는다. 사용자가 메시지에 적은 사양과 첫 문서를 바탕으로 기존 구현에 통합했다. 외부 문서의 98점·6시간·200MB·발열/배터리 수치는 측정 결과가 아니다.

[Unity Cloth 공식 문서](https://docs.unity3d.com/6000.0/Documentation/Manual/class-Cloth.html), [URP 카메라 문서](https://docs.unity.com/en-us/engine/6000.5/manual/cameras/urp/camera-components-reference/camera-component-reference), [URP DOF 문서](https://docs.unity.com/en-us/engine/6000.0/manual/post-processing-and-full-screen-effects/urp/effect-list/depth-of-field-urp/volume-override)를 비교하고 로컬 Unity 6000.6.4f1/URP 17.6 소스를 확인했다.

## 구현 경계와 남은 마감
현재 영웅은 원화 UV를 사용하는 정적 릴리프 메시와 헤어 카드다. 3·5점 망토는 고정점·몸통 회피·점 분리 제약을 둔 분석적 보조 움직임이며 Unity Cloth/스키닝 기반 천 전체의 self collision이 아니다. 털은 여섯 셸 근사이며 물리적 600 가닥 groom이 아니다. 림/역광도 원화와 조화를 위한 셰이더 근사이며 native SSS/SSR/SDFGI나 Unity Hair System 설치를 의미하지 않는다.

4K 미세 노멀 원본, 부위별 전용 PBR 맵/마스크, 정밀 머리카락·의상 충돌, 스킨 상처 데칼, 사망 전신 애니메이션, 물웅덩이/발자국, DOF/Bokeh/SSR/체적 안개/렌즈 플레어/모션 블러는 새로 완성한 항목이 아니다. 기존 Windows 빌드의 DOF/Panini 스트리핑을 해결했다고 주장하지 않는다. Vignette 0.75 상시 적용 대신 전장 가독성을 확인한 0.35를 사용한다. 전체 게임을 반복 멈추게 하는 Engine.time_scale 0.08은 적용하지 않았다. 보스 전조와 직접 회피·사냥의 읽기 쉬운 움직임을 유지한다.

실제 3D 헤어/천·120개 독립 스킬 원화·고유 모션 전부의 시각 검수는 후속 마감 범위다. FPS 최적화, 모바일 발열/메모리/배터리 검수는 사용자 요청대로 마지막 단계이며 이번에 60fps를 입증하지 않았다.
