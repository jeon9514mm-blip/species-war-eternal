# v65 · 수호신 소환과 전투·사냥 옵션

## 이용 방법

- 원정대 캠프의 `수호신 소환` 또는 영웅 훈련의 `수호신 도감과 소환`을 엽니다. 기존 영웅 조각 소환은 같은 화면의 별도 탭에 유지됩니다.
- 첫 수호신 소환은 무료이며 이후 1회 80젬입니다. 고급 55%, 희귀 27%, 에픽 12%, 전설 5%, 신화 1%입니다. 전설 이상은 최대 30회, 신화는 최대 80회 안에 나옵니다. 보장은 각 기준 이상의 수호신을 획득하면 초기화됩니다.
- 10종 수호신 가운데 도감에서 장착한 **한 마리**의 옵션만 적용됩니다. 같은 수호신을 4·7장 보유하면 공명 2·3단계가 되어 원래 옵션 수치에 각각 10·20%를 더합니다. 공명은 3단계가 최고입니다.
- 진영의 기존 동료는 고급 수호신으로 자동 등록됩니다. 이전 저장의 진영별 레벨·경험치·진화 상태와 기존 자동 지원 전투는 이어집니다. 다른 수호신으로 바꿔도 진영별 성장치는 사라지지 않습니다.

## 옵션 적용 범위

| 옵션 | 적용 위치 |
| --- | --- |
| 온라인 골드·경험치 | 온라인 사냥 처치 보상, 스테이지 상자, 레이드 클리어 보상 |
| 오프라인 골드·경험치 | 오프라인 사냥 추정 보상과 스테이지 상자. 영웅 경험치에도 반영 |
| 장비 획득률 | 온·오프라인 사냥 장비 드롭 판정. 전설·희귀가 뽑힐 확률 자체는 늘리지 않음 |
| 공격력 | 영웅의 실전 공격 수치와 표시 전투력, 이를 사용하는 오프라인 사냥 효율 |
| 치명타 확률 | 필드와 레이드의 공격 피해에 1.5배 치명타 판정. 장착 수호신의 추가 확률만 적용 |

수호신마다 옵션 구성과 수치가 다릅니다. 도감의 장착 카드에 실제 적용 수치가 표시됩니다. 수호신 등급은 고정이며 소환 확률과 보장 횟수는 소환 화면에서 항상 확인할 수 있습니다.

## 내부 검증

- `V65GuardianSmokeTest.gd`: 10종·5등급, 가중 확률, 첫 무료 소환, 젬 차감, 보장, 장착/저장, 구 저장 마이그레이션, 중복 공명, 실제 사냥·치명타·오프라인 보상, 소환 화면과 결과 팝업 확인.
- 기존 세로 화면·영웅 성장·영웅 소환·레이드·저장 검증도 통과.
