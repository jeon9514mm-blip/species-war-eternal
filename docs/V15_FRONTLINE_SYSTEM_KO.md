# v15 전선 다중부대 · 지원 · 집결 · 보급선

v15는 v14의 단일 수비대 비동기 PvP를 실제 SLG 전선 구조에 가까워지도록 확장합니다.

## 핵심 변경

### 타일별 다중 수비대
한 타일에 여러 플레이어 부대 스냅샷이 주둔할 수 있습니다.

주둔 한도:
- 일반 평원/숲/구릉: 2부대
- 광산/마력숲/유적: 3부대
- 전선 요새: 5부대
- 중앙 대성: 6부대
- 수도: 8부대

무한 수비 적층을 막기 위한 하드 캡입니다.

### 공격 대기열
적 타일에 도착한 공격 부대는 FIFO 공격 큐에 들어갑니다.
현재 로컬 프로토타입은 곧바로 다음 공격을 처리하지만, 큐 데이터 자체는 저장되므로 서버 연결 시 여러 유저의 동시 도착 순서를 처리하는 기반으로 사용할 수 있습니다.
한 타일의 공격 대기열은 최대 8부대입니다.

### 연속 10vs10
공격 부대 한 개가 타일의 첫 수비대를 이기면 남은 HP를 유지한 채 다음 수비대와 이어서 싸웁니다.
모든 수비대를 격파해야 점령됩니다.
중간에 패배하면 살아남은 수비대의 HP가 저장되어 다음 공격이 이어받습니다.

### 아군 지원
아군 영토로 지원 행군 후 주둔 슬롯에 등록할 수 있습니다.
같은 플레이어의 `player_local` 부대는 동시에 여러 타일에 중복 등록되지 않습니다.

### 집결
집결은 최대 5부대로 제한합니다.
현재 실제 서버가 없으므로 로컬 검증에서는 `프로토타입 동맹 A/B`를 사용합니다.
실제 서비스에서는 이 두 스냅샷 자리를 실제 다른 유저의 참여 부대로 교체하면 됩니다.

### 보급선
수도에서 아군 타일만 따라 BFS로 연결된 영토를 보급 연결 상태로 판단합니다.
보급이 끊긴 고립 영토:
- 방어 배율 ×0.82
- 자원 효율 25%
- 새 지원 부대 주둔 불가

요새 자체는 방어 +18%, 중앙 대성 +12%, 자원지는 +5%의 지형 방어 보정을 갖고 인접 아군 요새가 있으면 추가 +6%를 받습니다.

### 긴급 후퇴
보급선이 끊겨 일반 경로로 수도에 돌아갈 수 없는 부대는 `긴급 후퇴`가 가능합니다.
군량을 소비하지 않는 대신 일반 이동보다 오래 걸리며, 수도 도착 후 기존 피로 회복 규칙이 적용됩니다.
고립 때문에 계정 부대가 영구적으로 갇히는 소프트락을 막기 위한 안전장치입니다.

### 피로도 공격 제한
부대 피로가 85 이상이면 공격/집결 출정을 할 수 없습니다.
이동과 수도 귀환은 계속 가능합니다.
반복 박치기 공격보다 교대·복귀·지원의 의미를 높이는 장치입니다.

### 공헌도 공정성
집결에 포함된 프로토타입 동맹이 적을 격파해도 내 개인 공헌도는 증가하지 않습니다.
내 `player_local` 부대가 직접 격파한 수비대만 개인 공헌도에 반영합니다.

## 코드 구조
- `WorldWarState.gd`: 영토, 안전지대, 군량, 피로
- `WorldMarchState.gd`: 이동/지원/공격/집결 문맥, 긴급 후퇴
- `WorldSupplyNetwork.gd`: 수도 연결망, 고립 판정, 보급 패널티
- `WorldConflictState.gd`: 다중 수비대, 공격 큐, 집결, 공헌도
- `WorldBattleResolver.gd`: 결정론적 10vs10
- `WorldWarMapView.gd`: 영토/보급단절/행군 표시
- `WorldWarScreen.gd`: 유저 명령과 전투 리포트
- `Main.gd`: 개인 RPG 스냅샷과 저장 연결만 담당

## 아직 서버가 필요한 부분
현재 v15는 로컬 프로토타입입니다.
실제 멀티플레이에서는 다음 항목을 서버 권한으로 옮겨야 합니다.
- 타일 소유권
- 공격 큐 순서
- 부대 스냅샷 서명/검증
- 집결 참여
- 전투 시드/결과
- 시즌 공헌도와 보상

클라이언트 계산 결과를 그대로 신뢰하는 구조로 출시하면 치팅에 취약하므로 실제 온라인 단계에서는 서버 권한 모델이 필수입니다.
