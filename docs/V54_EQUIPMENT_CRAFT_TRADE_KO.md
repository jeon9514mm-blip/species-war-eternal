# Pixel RPG v54 · 장비 파밍·옵션 추출·거래

사냥 장비, 레이드 세트, 레이드 정수 공방을 연결했습니다. 좋은 옵션은 원래 수치를 유지한 **옵션 결정**으로 추출하고, 거래하거나 다른 장비에 이식할 수 있습니다. 원래 장비에는 선택한 옵션만 빠집니다.

## 장비 획득

| 지역 | 사냥 장비 세트 | 레이드 전용 세트 | 2세트 효과 | 3세트 추가 효과 | 클리어 정수 |
| --- | --- | --- | --- | --- | ---: |
| 회색 초원 | 개척자 | 새벽의 맹약 | 체력 +10% | 궁극기 충전 +8% | 12 |
| 잊힌 광산 | 강철 | 철벽의 맹세 | 체력 +12% | 방어력 +8 | 18 |
| 달잠 숲 | 월광 | 월식의 추격 | 공격력 +10% | 공격 속도 +6% | 24 |

- 사냥 장비에는 지역별 이름·출처를 기록합니다. 기존 사냥 드롭 확률과 강화 기본 수치는 유지합니다.
- 레이드 승리 시 전용 세트 장비 1개와 정수를 확정 지급하고, 기존 사냥 장비 추첨 1회도 진행합니다. 패배·취소·시간 초과에는 지급하지 않습니다.
- 지역별 5회째 클리어마다 전설을 확정하고, 해당 레이드 세트의 미보유 부위를 우선합니다. 가방·장착·보관함·거래 배송·판매 중인 장비까지 보유 판정에 포함합니다. 추출 결정은 장비 부위로 세지 않습니다.
- 레이드 세트·옵션 장비·옵션 결정·잠금 장비·선택 대기 후보가 있는 장비는 자동 분해에서 보호합니다.
- 가방에 보호 장비만 남아 있으면 새 보호 보상은 보관함으로 전달합니다. 가방과 보호 보관함이 모두 가득 차면 레이드 시작 또는 추출을 거절합니다.

## 옵션 공방과 결정

| 작업 | 레이드 정수 비용 | 결과 |
| --- | ---: | --- |
| 첫 번째 / 두 번째 / 세 번째 옵션 조율 | 12 / 20 / 28 | 선택한 계열의 후보를 제시하고 하나 선택 |
| 옵션 삭제 | 6 | 선택한 옵션만 삭제, 공명 집중 +1 |
| 옵션 추출 | 18 | 선택한 옵션을 장비에서 제거하고 같은 수치의 결정 1개 생성 |
| 결정 이식 | 8 | 결정 1개 소모, 장비의 빈 옵션 칸에 원래 수치로 추가 |

일반·희귀·전설 장비는 각각 옵션 1·2·3칸을 갖습니다. 같은 종류의 옵션은 한 장비에 중복 추가할 수 없습니다. 공격 계열은 공격력·궁극기 충전, 수호 계열은 체력·방어력, 흐름 계열은 공격 속도·궁극기 충전을 제공합니다. 이미 가진 종류는 후보에서 제외합니다.

조율 후보는 비용 지불 즉시 저장하므로 재실행해도 그대로 이어서 고릅니다. 후보를 포기하면 비용은 돌려주지 않습니다. 삭제로 집중을 3회 쌓으면 다음 조율 후보는 최대 수치로 나옵니다. 추출은 집중도를 올리지 않습니다.

| 옵션 | 개별 수치 범위 | 장착 3부위 합산 상한 |
| --- | --- | --- |
| 공격력 | +2~6% | +24% |
| 체력 | +3~8% | +30% |
| 방어력 | +1~4 | +18 |
| 공격 속도 | +1~3% | +12% |
| 궁극기 충전 | +2~5% | +18% |

상한은 장비 옵션 합산 기준이며 세트 효과는 별도로 반영합니다. 공격 속도·궁극기 충전은 사냥·레이드 전투에 적용합니다. 진영전의 기존 라운드 전투에는 공격력·체력·방어력이 적용됩니다. 장착 옵션을 변경하면 현재 체력 비율과 전투 진행 상태를 유지하며 능력치를 갱신합니다.

## 좋은 옵션을 추출해서 판매하는 흐름

1. 가방의 **상세 · 옵션 공방** 또는 영웅 상세의 **장착 장비 옵션 공방**을 엽니다.
2. 원하는 옵션의 **추출**을 선택하고 수치·비용을 확인합니다.
3. 결정은 가방으로, 가방이 꽉 차면 보호 보관함으로 전달됩니다. 추출 때문에 다른 장비를 자동 분해하지 않습니다.
4. 가방에서 **옵션 결정만** 필터를 선택하고 **거래 등록**으로 가격을 정합니다.
5. 구매자는 배송함에서 결정을 받은 뒤 **이식할 장비**에서 대상·현재 옵션·이식 후 옵션을 확인하고 이식합니다.

직접 만든 옵션은 장착으로 귀속된 장비에서도 추출해 판매할 수 있습니다. 구매한 장비 또는 구매한 결정에서 나온 옵션은 거래 이력을 유지하므로 이식·재추출을 반복해도 재판매할 수 없습니다. 구매 옵션이 들어 있는 미귀속 장비도 그 옵션을 가진 동안은 판매할 수 없습니다.

결정은 강화하거나 영웅 장비로 착용할 수 없습니다. 잠긴 결정은 잠금을 해제한 뒤 이식합니다. 이식 실패 시 결정·장비·재화는 그대로 유지합니다. 이미 소비된 결정, 이동한 장비, 오래된 추출 확인창은 현재 상태를 재검사해 중복 소비나 엉뚱한 옵션 제거를 막습니다.

## 장비 UI

- 가방 카드에서 출처·세트·옵션 품질·귀속/거래 상태를 확인합니다.
- 장비/결정, 부위, 출처 필터와 등급·옵션 품질·최근 획득 정렬을 제공합니다.
- 자동 장착·분해 설정을 접어 장비 목록을 더 빨리 볼 수 있게 했습니다. 장비 자체를 판매하려면 자동 장착을 끄고 미귀속 상태로 보관하세요.
- 공방은 현재 옵션을 위에 배치하고 삭제·추출·이식 비용을 함께 표시합니다.
- 옵션 품질은 최대 수치 대비 비율로 표시합니다. 강화 기본 전투력과 옵션의 가치는 따로 보여 줍니다.
- 결정 상세에서 가방 장비와 현재 원정대 장착 장비를 선택합니다. 다른 영웅은 영웅 상세 공방에서 이식할 수 있습니다.
- 삭제·추출·이식·판매 등록·구매에는 각각 확인창이 있습니다. 보호 장비 수동 분해도 확인하며, 잠금 또는 후보 선택 중에는 분해를 차단합니다.

## 거래소 구현 범위

등록·구매·취소·만료·배송·판매대금 정산을 처리하는 **로컬 거래 엔진과 게임 UI**를 구현했습니다. 현재 프로젝트에는 실제 온라인 계정/거래 서버가 연결되어 있지 않습니다. 서로 다른 기기의 실제 플레이어 간 거래는 아직 사용할 수 없습니다. UI에도 이 상태를 표시하며 가짜 플레이어 매물은 만들지 않습니다.

| 규칙 | 구현 |
| --- | --- |
| 거래 대상 | 미귀속·미거래 장비 및 직접 추출한 옵션 결정 |
| 가격 | 10~1,000,000,000 골드 |
| 등록 제한 | 계정당 판매 중 5개, 48시간 유지 |
| 비용 | 등록·취소 무료, 판매 완료 시 5% 올림 수수료 |
| 구매 | 골드 차감과 판매 정산을 함께 처리, 구매 물품 귀속 |
| 수령 | 가방이 꽉 차면 배송함에 남김. 취소·만료도 배송함 반환 |
| 반복 요청 | 거래 요청 번호를 저장하고 이전 요청을 중복 실행하지 않음 |

복수 계정을 같은 거래 엔진에서 사용해 실제 소유권·골드 이동과 중복 구매 거절을 검증했습니다. 온라인 연결 시에는 인증된 계정, 서버 저장소와 서버 기준 거래 처리로 교체해야 합니다. 로컬 인벤토리 동기화 함수는 신뢰된 게임 내부용이며 원격 클라이언트 API가 아닙니다. 로컬 저장 검증만으로 외부 파일 조작을 방지하는 온라인 보안을 제공하지는 않습니다.

전체 검사 중 기존 V31 효과 테스트는 740개 조건을 모두 통과했지만 종료 시 ObjectDB 객체 2개 정리 경고를 남겼습니다. 수정 전 단독 1회·동시 3회 재실행에서는 재현되지 않았습니다. 해당 테스트의 종료 순서를 음향 정지·참조 해제 → 대기 → 장면 해제로 보완했고, 구문 검사와 효과 검사 740개를 오류·경고 없이 재통과했습니다. 실제 효과 검사는 그대로 유지합니다. 모든 간헐적 엔진 종료 경고가 해결됐다고 단정하지 않으며, 원래 로그와 재검증 결과를 JSON에 함께 남깁니다.

기존 30명 영웅의 장비 상태 3종, 총 90개 기준 프로필을 v53 원본에서 별도로 기록해 기존 HP·ATK·DEF·행동 간격·궁극기 충전·전투력 유지도 검사했습니다. 옵션 추출과 이식에는 실제 장착 전투 상태, 만석, 재화 부족, 선택 대기 후보, 중복 옵션, 오래된 확인창을 포함합니다.

검증 환경은 Godot 4.7.2 headless입니다. 실제 Control 크기·한글 글꼴 줄바꿈·viewport 입력을 검사했으며 GPU 화면 캡처나 실제 휴대폰 터치·성능 검증은 포함하지 않습니다.

현재 작업 소스에는 v54가 반영되어 있습니다. 전달 패치는 다음 중 자신의 원본에 맞는 **하나만** 사용하세요.

- `pixel-rpg-v54-from-v53.patch`: 전달받은 v53 전체 프로젝트 기준 증분 패치.
- `pixel-rpg-v54-equipment.patch`: 최초 v46.1 원본 소스 기준 누적 패치. 이전 개선도 포함합니다.

```bash
git apply --check /path/to/pixel-rpg-v54-from-v53.patch
git apply /path/to/pixel-rpg-v54-from-v53.patch
```

두 패치를 함께 적용하거나 다른 버전에 강제로 적용하지 마세요. Godot 4.7.2에서 `project.godot`을 열고 리소스 가져오기 후 실행합니다. 저장 형식은 31로 갱신하며 기존 저장은 로드 시 변환합니다. 테스트 전 기존 저장을 별도로 보관하세요. 변경물에는 개인 플레이 저장 파일을 포함하지 않습니다.

```bash
python3 tools/run_tests.py --godot /path/to/Godot --jobs 4
```
