# v26 자동사냥·전투 AI 재개 기록

기준: 2026-09-22, Godot 4.7.2.stable.official.ed1daf0bf.
기반 소스: pixel-faction-rpg-prototype-v25-godot47-combat-fx-runtime-verified.zip.

## 이번 작업

1. `CombatDecisionEngine.gd`로 사거리, 전열, 역할·개성·즉시 위협도, 도발 판단을 분리했습니다. 공격 시작 때 선택한 대상을 유지하고, 사망·사거리 이탈 때 다시 고릅니다.
2. 근접 영웅의 사거리 실패가 뒤 순서 영웅과 몬스터의 행동까지 중단시키던 오류를 수정했습니다. 살아있는 적이 있으면 이동과 재탐색을 계속합니다.
3. 사거리 안의 적을 기준으로 전열을 판단합니다. 멀리 있는 전열 적 때문에 바로 옆 적을 공격하지 못하던 정체를 해소했습니다.
4. 추격 중에도 응급 치유와 보호 스킬을 사용할 수 있습니다. 지원 스킬은 적 타겟을 요구하지 않고, 시전 완료 때 아군 상태를 다시 확인합니다.
5. 공격형 스킬과 궁극기는 발동 직전에 유효 대상을 검사합니다. 범위 밖 대상에게 자원을 낭비하거나 필드 반대편 적에게 광역 피해를 주지 않습니다.
6. 파티 전원이 1초 이상 보호 효과를 받고 있으면 다음 탱커가 같은 궁극기를 중복 사용하지 않습니다.
7. 배회 타겟의 작은 거리 차이를 무시하고, 추격 정지 거리를 근접 사거리 안쪽으로 둡니다. 회복 상태 보존, 사망 타겟 해제, 교전 경계 떨림, 큰 시간 간격에서 위치 겹침도 수정했습니다.
8. 펫이 마지막 적을 처치해도 해당 전투의 보상을 즉시 한 번만 처리합니다. 화면상 영웅 위치나 연출 준비 시간은 전투 판정을 막지 않습니다.

## 검증 기록

- 기존 테스트와 추가 테스트를 합쳐 서로 다른 **54개 스크립트가 최종 통과**했습니다. 전체 52개 실행 뒤 회복 검사 1개를 실제 상태 전이에 맞춰 수정·재실행했고, 나중에 추가한 행동 안전성/연속 전투 2개를 별도로 실행했습니다.
- 신규 전투 행동 검사: 원본 v25 14개 중 9개 실패 → 수정 후 14개 전부 통과.
- 타겟 판단 엔진: 368개 검사 통과(고정 시드 유효 타겟 조합 포함).
- 자원/시전/보상 안전성: 24개 검사 통과.
- 배회 및 기존 호환 검사 통과. 정적 리소스 검사와 Godot 4.7 호환성 검사 통과.
- 테스트는 플레이어 저장 데이터와 분리한 환경에서 실행했습니다.

## 해석 범위와 다음 순서

이번 체크포인트는 1번 자동사냥·전투 AI의 확인된 진행 차단 결함을 수정한 것입니다. 8개 영역 전체의 완료율을 임의 숫자로 올리지 않았습니다.

현재 전투 판정은 기존 파티 중심 좌표와 대형을 사용합니다. 영웅 한 명씩의 물리 충돌·장애물 경로, 글로벌 상태이상을 개별 몬스터에 나누는 작업, 모바일 장시간 발열·실기기 조작성은 이번 검증 범위에 포함하지 않습니다.

다음 개발 순서는 기존 합의를 유지합니다: 자동사냥 AI 마감 기준 확인 → 영웅 스킬·개성·역할 → 성장·장비·방치 → 보스·레이드 → 필드 몬스터 생태 → 종의전쟁·영토전 → 밸런스 → 저장·안정성·회귀 검증. 서버·DB 확대는 이 순서를 앞당기지 않습니다.

ZIP 패키징은 요청할 때만 수행합니다.
