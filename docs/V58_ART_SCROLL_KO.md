# v58 세로형 사냥터 그래픽·UI와 스크롤 개선

## 적용 범위

- 초원·광산·숲의 세로형 사냥 지도와 상단 풍경을 영웅 SD 일러스트와 어울리는 그림으로 교체했습니다. 기존 길, 초원 연못, 월드 좌표와 장애물 판정은 유지합니다.
- 일반 몬스터 13종과 보스 3종의 세로형 전투용 4포즈 그림을 추가했습니다. 이동·공격·피격·사망 상태와 기존 전투 크기, 보상과 AI는 유지합니다.
- 전투 HUD와 메뉴의 남색 고대비 패널을 차분한 숲색·금색 계열로 정리하고, 영웅과 몬스터 그림은 부드러운 선형 필터를 사용합니다.
- 긴 화면에 고정 폭 스크롤 손잡이를 표시합니다. 버튼 위에서 시작한 터치 드래그가 목록에 전달되고, 같은 화면을 다시 만들 때 이전 위치로 돌아갑니다. 포커스 이동 때문에 스크롤이 갑자기 바뀌지 않도록 했습니다.
- 애니메이션이 없는 광산·숲 배경은 카메라 변경 시에만 다시 그립니다.

## 실행

Godot 4.7.2에서 `project.godot`을 열고 첫 이미지 가져오기가 끝나면 F5로 실행합니다. 시작 장면은 `scenes/PortraitMain.tscn`입니다. 기존 저장 파일은 이전처럼 그대로 사용합니다.

## 검사

`python tools/run_tests.py --godot <Godot 4.7.2 실행 파일> --jobs 4`로 전체 116개 테스트와 202개 스크립트 컴파일을 통과했습니다. 새 `V58ArtScrollSmokeTest.gd`는 16종 몬스터 그림과 동작, 실제 세로형 사냥 장면, 버튼 위 터치 드래그, 버튼 오작동 방지, 스크롤 복원과 휠 입력을 검사합니다.

검사는 Godot headless 가상 화면에서 수행했습니다. 실제 Android/iOS 기기에서의 화질·프레임 속도와 터치 감각은 기기별 확인이 필요합니다. 이전 가로형 장면과 일부 오래된 스킬 아이콘은 기존 픽셀 리소스를 계속 사용합니다.
