# Pixel RPG v51 · 시스템·소스·UI 통합 점검

기존 v50 프로젝트를 기준으로 저장, 성장·경제, 자동사냥, 전투, 진영전, 화면 입력과 효과를 점검하고 재현한 오류를 수정했습니다. 실행 소스 13개를 수정하고, 기존 검사 5개를 보완했으며, 새 회귀 검사 6개를 추가했습니다.

## 이번에 수정한 내용

| 영역 | 확인한 문제 | 수정 후 동작 |
| --- | --- | --- |
| 복귀 보상 | 재접속 후 전투에 들어가기 전에 메뉴에서 저장하면 방치 보상 시간이 사라짐 | 저장된 편성과 지역으로 먼저 정산한 뒤 메뉴를 표시. 메뉴에서 앱을 중단·복귀해도 정산하며 중복 지급 방지 |
| 일일·주간 보상 | 기기 날짜를 이전으로 돌리면 사용 횟수가 초기화되거나 보상을 다시 받음 | 저장된 마지막 날짜·주보다 앞으로 진행할 때만 초기화. UI도 같은 기준 사용 |
| 저장 검증 | 잘못된 날짜 문자열이 보상 날짜 비교를 영구적으로 막을 수 있음 | 실제 달력 날짜·윤년과 정수 주 키를 검사하고 손상된 값 정규화 |
| 진영·시즌 | 다른 진영의 저장된 영토·행군이 새 시즌으로 넘어온 뒤 되살아남 | 진영별 상태에 시즌 번호 저장. 이전 시즌 영토·부상·전술·행군·주둔 상태 초기화, 군량 800, 누적 명예 보존 |
| 진영전 도착 | 출발 후 보급·피로·부상이 바뀌어도 전투나 중립 점령이 진행됨 | 도착 시 최신 부대 상태·출발지 보급·전투 가능 여부를 재검사 |
| 지원 | 수도 지원이 거절되어도 먼저 수도 이동·회복이 적용됨 | 수용 인원·보급·부대 상태를 승인한 뒤 이동과 회복 반영 |
| 집결 | 준비 시점의 오래된 체력·전술로 전투할 수 있음 | 해결 시점의 신뢰된 부대 상태로 해당 참여자 갱신. 만료·거절된 집결 정리 |
| 전투 보고 | 남은 HP보다 큰 공격값이 피해량에 기록됨 | 실제 제거된 HP만 기록하고 저장된 전투 로그 16줄 모두 표시 |
| 보스 전투 | 반격으로 죽은 보스가 광역 공격을 계속하거나 저주 흡혈로 되살아남 | 보스 사망 즉시 후속 타격·흡혈 중단, 해당 전투 루프에서 승리 정산 |
| 복합 지원기 | 회복으로 체력 순위가 바뀌면서 보호막이 다른 아군에게 적용됨 | 한 번의 시전에서 선택한 지원 대상을 회복·보호막에 공통 사용 |
| 팝업 입력 | 진영전 팝업 뒤의 하단 메뉴가 눌려 화면이 바뀜 | 별도 CanvasLayer에서 팝업과 배경을 처리해 뒤쪽 입력 차단. 닫은 뒤 정상 복구 |
| 지도 터치 | 취소된 터치가 영토 선택으로 처리되거나, 세 손가락 확대 중 손가락을 빼면 확대율이 튐 | 취소·포커스 상실 때 제스처 정리, 남은 두 손가락으로 확대 기준 갱신 |
| 창 닫기 | 진영전 팝업과 모험 메뉴가 ESC로 닫히지 않음 | ESC 닫기 및 입력 처리 연결 |
| 피격 효과 | 연속 타격 후 화면 위치·확대율과 붉은 색상이 원래대로 돌아오지 않음 | 최초 기준 상태로 복구. 화면 교체·대상 삭제 시 효과 정리, 사망 효과의 투명도 보존 |

구형 저장에는 진영별 시즌 번호가 없으므로 그 저장의 전역 시즌 번호를 부여해 기존 진행을 보존합니다. 새 버전부터 기록되는 시즌 번호로 이후 시즌 전환을 구분합니다. 같은 시즌의 진영 전환은 기존 영토·군량·행군을 유지합니다.

## 시스템 설계와 검사 범위

| 시스템 | 확인한 연결 |
| --- | --- |
| 저장 | 체크섬, 백업 복구, 원자적 저장, 미래 버전 덮어쓰기 방지, 구형 저장 이행, 편성별 복귀 보상 |
| 성장·경제 | 경험치 분배, 강화 비용·상한, 장비 교체·판매·분해·자동장착, 승급·돌파, 소환 천장, 중복 보상 방지 |
| 자동사냥·전투 | 지형 경로 탐색, 이동·대상 결정, 전투 상태·스킬·회복, 영웅 30인, 레이드 생명주기, 반복 전투 |
| 진영전 | 출정→행군→도착→전투→주둔, 보급망, 중립 수비대, 집결, 전술, 시즌 정산, 진영별 저장 |
| UI·디자인 | 세로 화면 배치, 실제 한글 폰트 크기·줄바꿈, 스크롤·팝업 경계, 실제 입력 전달, 확대·이동, 전투 효과 수명 |
| 에셋 | 리소스 참조 누락, 영웅 동작·스프라이트, 몬스터·지형 그림의 기존 무결성 검사 |

v50에서 확대한 40×40 / 1,600칸 지도, 입체 지형, 정찰→전술 선택→출정, 미니맵과 전투 보고 구성을 유지합니다. 이번 수정은 그 흐름에서 발견한 입력·상태 동기화·전투 판정 문제를 보완합니다.

Main에 화면·경제·전투 연결이 많이 모여 있어 변경의 영향 범위가 넓습니다. 이번에는 문제가 재현된 처리 순서와 전담 모듈을 수정하고 관련 경계 검사를 추가했습니다. 기존·신형 스킬 경로의 특성 보정 차이와 장애물 너머 공격 정책은 밸런스 의도가 확정되지 않아 변경하지 않았습니다.

- 기존 대형 진영전 UI: **21개 화면 상태, 3,049개 조건** 통과.

- 정적 리소스 참조 205개 / 154개 파일 검사에서 누락 0.
- 반격·복합 지원기 오류는 수정 전 검사 44개 중 12개 실패, 시즌 은행 오류는 15개 중 7개 실패로 재현한 뒤 해결했습니다.

검사는 headless Godot에서 실제 객체·폰트·Control 배치·입력 전달·게임 상태로 수행했습니다. GPU 화면 캡처와 Android/iOS 실기기 터치감·성능·육안 검수는 수행하지 못했습니다. 대화에 보낸 이미지는 생성한 디자인 미리보기이며 실행 화면 캡처가 아닙니다.

전체 검사에서 기존 테스트 4개에 종료 시 ObjectDB 경고가 발생했습니다. 상세 로그로 WAV·PlaybackWAV 오디오 객체 정리 대기 누락임을 각각 확인했습니다. 테스트 종료부에 0.3초 정리 시간을 준 뒤 해당 **4/4개 재검사에서 오류·경고·누수 출력 0**을 확인했습니다. 게임 실행 코드를 추가로 변경하지 않았으며, 전후 로그를 결과 JSON에 포함합니다.

진영전의 원격 서버 어댑터는 아직 구현되지 않았습니다. 이번 검증과 개선 범위는 현재 기기 내 권한 처리·전선 시뮬레이션이며 실제 온라인 다중 사용자 동시전은 포함하지 않습니다.

## 수정 소스 적용

`pixel-rpg-v51-system-audit.patch`는 최초 **v46.1 원본 소스 기준의 누적 패치**입니다. v46.2~v50 개선과 이번 v51 변경을 포함합니다. 기존 패치를 적용한 폴더에 중복 적용하지 말고 원본을 별도 폴더에 풀어 사용하세요. 현재 작업 프로젝트에는 수정이 반영되어 있습니다.

```bash
git apply --check /path/to/pixel-rpg-v51-system-audit.patch
git apply /path/to/pixel-rpg-v51-system-audit.patch
```

Godot 4.7.2에서 `project.godot`을 열고 가져오기를 마친 뒤 실행합니다. 패치는 소스·검사·문서를 담고 있으며 이미지·음원은 원본 프로젝트를 사용합니다. 개인 플레이 저장 파일은 포함하지 않습니다.

원본 소스 기준점에서 패치 적용 여부와 모든 변경 파일의 바이트 일치를 별도로 확인했습니다. 그 결과와 파일 해시는 `pixel-rpg-v51-test-results.json`에 기록합니다.

전체 검사 재실행:

```bash
python3 tools/run_tests.py --godot /path/to/Godot --jobs 4
```
