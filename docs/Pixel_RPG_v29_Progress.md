# Pixel RPG v29 진행 보고

## 이번 요청 반영

기존 20명의 이름과 ID를 보존하고 10명을 추가했습니다. 두 진영 모두 15명이며, 각각 딜러 8명 / 방어·보조 4명 / 디버프 3명입니다. 전투 출전 상한은 10명입니다.

- 아우렐리아 신규: 아드리엔 로웰, 테사 코그웰, 나이아 스타위버, 사엘 리프댄서, 오델리아 실브룩.
- 녹스페라 신규: 루시엔 레드메르, 코르빈 애쉬웰, 로칸 스톤하울, 보라 스노우팽, 셀레네 베르밀.
- 모르가스는 실제 저주 기능에 맞춰 디버프로 분류했습니다.
- 휴먼 8·엘프 7 / 뱀파이어 8·늑대인간 7. 신규 해금은 양쪽 모두 스테이지 9~13입니다.

영웅마다 액티브 2개, 패시브 1개, 궁극기 1개를 갖습니다. 120개의 스킬 이름과 ID가 중복되지 않습니다. 액티브 2에는 별도 쿨타임과 시전 상태가 있고, 패시브는 조건과 내부 쿨타임을 검사합니다. 궁극기는 영웅별 데이터로 실행합니다. 같은 전투 행동에서 스킬 두 개가 동시에 실행되지 않습니다.

## 연결된 기능

- 실시간 이동 사냥과 레이드에 A2, 조건부 패시브, 고유 궁극기를 연결했습니다.
- HP를 자원으로 쓰는 공격, 보호막, 조건부 강화, 연격·광역·처형·흡혈·회복·도발·약화·취약·기절을 기존 HP/제어 규칙으로 처리합니다.
- 보호막은 최대 HP 20% 상한이며 합산 누적하지 않습니다. 사거리 밖/복귀 중 몬스터와 전투불능 영웅은 유효 대상이 아닙니다.
- 영웅 상세에서 네 스킬을 스크롤로 확인할 수 있습니다. 영웅 목록은 15명과 해금 상태를 표시합니다.
- 저장 버전은 29입니다. 기존 성장·장비·조각·편성을 읽으며 새 영웅 ID도 저장합니다. v27부터 적용된 무결성 검사 기준은 그대로 유지합니다.
- 종의전쟁·영토전의 기존 역할 기반 자동 해결 구조와 출전 상한은 유지합니다. 해당 모드는 필드의 네 스킬을 타이밍 단위로 재현하는 시뮬레이터가 아닙니다.

### 진영 비교

동일한 Lv20·장비 +3·SSR·펫 없음. 각 진영에서 딜러 5/방어·보조 3/디버프 2의 10인 편성을 네 번 회전하여 30명 전원을 포함했습니다. 각 측정은 60초이며 필드는 초원·숲, 레이드는 처치되지 않는 훈련 보스와 실제 레이드 AI·공격 패턴으로 측정했습니다.

| 지표 | 아우렐리아 | 녹스페라 | 양 진영 평균 대비 차이 |
|---|---:|---:|---:|
| 필드 무리 격파 합계 | 39 | 39 | 0.00% |
| 레이드 피해 합계 | 738,559 | 778,533 | 5.27% |

16개 측정 편성 모두 종료 시 10명 생존. 이 수치는 위 조건의 비교이며 모든 레벨·장비·PvP 조합에서 완전한 동률을 뜻하지 않습니다. 장기 밸런스·경제 조정은 플레이 기록을 더 모아야 합니다.

장시간 추가 확인에서 오른쪽 경계 나무 옆의 좁은 구역에 몬스터가 남아 원정대가 접근하지 못하는 경우를 재현했습니다. 이동 가능 판정에 연결된 경로 격자까지의 접근 가능성 검사를 추가하고 해당 좌표의 회귀 테스트를 만들었습니다. 이동·경로·장시간 사냥·진영 비교 6개가 다시 통과했습니다. 경계 수정 후 진영 비교를 다시 측정한 값이 위 표입니다.

초기 회귀에서 발견한 레이드 배열 형식 오류를 수정했습니다. 기존 10인 명단 가정은 15인 후보/10인 출전으로 구분했고, 저장 왕복 테스트는 6인 편성이 합법인 진행도로 수정했습니다. 초기 실패 기록은 v29-initial-regression-results.json에 남아 있으며 최종 통과 기록은 v29-regression-results.json입니다.

## 남은 아트 작업
