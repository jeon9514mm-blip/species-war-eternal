# 초반 10분 안내와 1·7·30일 성장 검증

사용자 요청의 상용화 준비 항목 3(첫 플레이 동선·실패 피드백), 4(성장·경제 검증)를 반영했다. 기준 소스는 `fa71acdfbb83d3b50ae8b5edc9134a1613ce3939`, 검증 엔진은 Godot 4.6.3이다.

## 첫 플레이에서 달라지는 점

사냥 홈에서 현재 목표와 다음 화면으로 이동하는 버튼을 제공한다. 가로 화면은 기존 목표 줄을 사용하고, 세로 화면은 사냥 설정을 열지 않아도 버튼을 볼 수 있다. 사냥 보상 알림과 버튼이 겹치지 않도록 배치했다.

안내 순서는 진영 → 첫 영웅 → 첫 무리 처치 → 스테이지 2 → 직접 장비 강화/연구 → 3인 편성·첫 레이드 준비다. 강화 비용이 부족하면 필요한 골드를 알려주고 사냥으로 돌아간다. 연구 포인트가 있으면 해당 영웅의 연구 화면을 열고, 무기 강화를 선택하면 장비 상세의 강화 탭을 연다. 버튼이 재화를 자동으로 쓰지는 않는다.

장비를 얻거나 영웅이 레벨업하는 것만으로 강화 안내를 완료하던 문제를 수정했다. 성공한 강화 또는 연구 명령을 저장하고, 실패한 명령·연습·저장 대기는 안내 기록을 만들지 않는다. 새 저장에는 실제 행동 기록을 남긴다. 기존 저장에 기록이 없으면 이미 투자한 연구와 장비 강화를 인정한다. 기존 안내 완료 상태, 영웅 레벨, 강화 단계, 보유 재화는 유지된다.

첫 레이드는 입장 비용과 권장 전투력을 알려준 뒤 준비 화면으로 이동한다. 안내 완료 조건은 실제 첫 도전이며, 승리 보상은 승리할 때만 지급한다. 기존 레이드 강도 10배와 보상 구조는 유지한다. 녹스페라는 회복 영웅이 스테이지 5에서 열리므로, 스테이지 3 안내에서 아직 잠긴 서포터를 요구하지 않는다.

레이드 실패 시 부족한 역할, 현재/권장 전투력, 제한시간 초과, 차단하지 못한 패턴의 회피 기록을 바탕으로 다음 행동을 안내한다. 추천 버튼은 편성·성장·역할 해금 사냥으로 이동한다. 결과 화면에서도 실제 휴대폰 터치 이벤트로 이동을 검사했다.

## 경제 조정

- 스테이지 1~25 상자 보상은 유지한다. 이후 보상 단계는 `25 + sqrt(스테이지-25)`로 계산하며 골드·경험치·군량에 동일하게 적용한다. 온라인과 오프라인은 같은 함수를 사용한다. 스테이지 10,000에서도 한 상자는 6,500G·3,300XP 미만이며, 최대 스테이지에서 상자를 반복 지급하지 않는다.
- 초원 스테이지 1~2의 1인 사냥만 완화한다. 적 체력은 탱커·서포터 시작 시 16%, 다른 역할 시작 시 32%, 공격력은 40%를 적용한다. 15~20마리 군단과 각 적의 개별 행동은 유지하며, 스테이지 3부터 기존 전투 수치를 사용한다.
- 사냥 기록이 없는 편성의 오프라인 보상은 초원에서 `60 / sqrt(편성 인원)`초당 무리 처치를 기본값으로 사용한다. 해당 빌드의 유효한 사냥 기록이 있으면 기존 실제 측정 속도를 사용한다. 지급률 88%, 8시간 상한, 수령당 최대 5스테이지·32장비 표본, 중복 수령 방지는 유지한다.
- 레벨 1~20 경험치 비용은 유지한다. 이후 필요 경험치는 `100 + (레벨-1)*75 + max(0,레벨-20)^2*8`이다. 기존 영웅을 강등하지 않는다.
- 장비 +1→+5 비용은 유지한다. 이후 비용은 기존 비용에 `1 + max(0,현재 강화 단계-4)^2*1.5`를 곱한다. 무기·방어구·장신구의 비용 비율 1:2:3은 유지한다.

## 시뮬레이션 조건과 범위

신규 계정, 첫 영웅 1명, 기본 수호신, 초원 사냥으로 시작한다. 하루 실제 전투 600초와 오프라인 보상 8시간을 계산한다. 매일 무료 출석 보상을 받고, 해금된 영웅을 목록 순서대로 편성하며, 1분마다 연구·승급·추천 장착·보유 골드 일부를 이용한 강화를 수행한다. UI 렌더링과 디스크 저장만 생략한 테스트 호스트에서 실제 사냥 AI·전투·보상·강화 명령을 실행한다.

이 모델은 모든 던전·레이드 보상, 광고·결제·소환·퀘스트 보너스와 최적 편성을 포함하지 않는다. 실제 이용자 유지율이나 휴대폰 FPS 측정이 아니다. 장기 전투는 두 진영에 동일한 정책과 seed 3401을 적용했다. 첫날은 추가 seed 3402~3404에서도 확인했다. 별도 드롭 감사는 두 진영·세 지역·세 seed에서 총 18,000회 실제 드롭 함수를 실행했다. 기존 영웅 정체성·진영 균형 검사와 지역별 10배 레이드 검사도 실행했다.

영웅 역할별 공격 성향과 시작 영웅이 달라 첫 전투 속도는 완전히 같지 않다. 이 변경은 두 진영 모두 첫 10분에 성장과 편성을 경험하도록 만드는 데 초점을 둔다.

## 이후 실사용 검증

게임 수치가 개선되더라도 이용자 데이터와 실제 폰 검증은 필요하다. 첫 처치·첫 강화·첫 편성·첫 레이드 도달률, 전멸·시간초과 이유, 일별 골드 유입·소비·잔고를 비공개 테스트에서 수집해야 한다. 30일 이후 남는 골드와 보호 장비 보관량도 후반 콘텐츠 설계에 반영해야 한다. 이번 시뮬레이션만으로 장기 경제나 유저 유지율이 완성됐다고 판단하지 않는다.
