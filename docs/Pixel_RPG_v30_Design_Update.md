세이지 초록·크림색 패널·짙은 초록 글자로 통일했고, 금색은 보상과 주요 진행 정보에 사용했습니다. 기존보다 밝기가 과하지 않도록 신규 배경을 구성했습니다. 사냥 맵 밝기 90%, 채도 88%, 큰 필드와 작은 이동 캐릭터는 유지했습니다.

자동사냥의 스테이지 완료는 잠깐 나타나는 비차단 알림입니다. 보상 결과 창은 이미 반영된 보상을 표시하며 다시 지급하지 않습니다. 설정 메뉴를 열어도 전투 상태가 초기화되지 않으며, 전투 효과 설정은 다음 실행에도 유지됩니다.

## 검증

- 최신 결과 기준 **76개 고유 회귀 테스트 모두 통과**. 전체 1차 실행에서 도움말 배치 검사 1개가 실패해 고쳤고, 새 UI 흐름 및 영향받은 기존 8개 테스트를 재실행했습니다.
- 새 UI 흐름 **976개 검증, 실패 0**. 실제 버튼으로 시작·기기 로그인·진영·편성·메뉴·가이드·효과 설정·저장 복원·토스트 동작을 확인했습니다.
- **17개 화면**의 실제 Godot Control 배치: 화면 이탈 0, 글자 가로 넘침 0, 40px 미만 터치 영역 0.
- 영웅 상세의 120개 스킬 표시, 최대 10인 편성, 1280/1600 폭, 기존 저장 호환을 확인했습니다.
- Godot 4.7 호환 검사와 정적 리소스 검사가 통과했습니다.

실제 PNG 캡처는 로컬 디스플레이 소켓 제한과 자동 실행 승인 거절로 완료하지 못했습니다. 위 배치 검증은 실제 렌더 이미지 검수를 대신하지 않습니다. 실기기에서 폰트·아트·터치·애니메이션 최종 확인이 남아 있습니다.

## 현재 기능의 경계

로그인 화면은 **이 기기 저장을 사용하는 실제 진입 화면**입니다. Google/Apple 등 계정 인증과 클라우드 저장 서버는 연결되지 않았습니다. 결제도 준비 중이며, 무료 지원 보상은 기존 제한과 지급량을 유지합니다. 영토전의 현재 저장 범위는 기기 내 전선입니다.

기존 승인 영웅 아트를 재사용했습니다. 아직 전용 이미지가 없는 영웅은 역할 문장으로 표시하며, 이번 작업이 30명 전체 캐릭터 아트 제작을 포함하지는 않습니다. 전투·성장·30명 구성과 저장 스키마 29는 유지됩니다.

## 실행과 소스

적용된 프로젝트: `game-v29/pixel-faction-rpg-v28/project.godot` (폴더 이름은 기존 이름, 내용은 v30).
Godot 4.7.2에서 프로젝트를 열고 실행하면 새 초기 화면으로 시작합니다.

`pixel-faction-rpg-v30-ui-checkpoint.patch`는 **원본 v25 ZIP을 기준으로 v30 전체 변경을 담은 누적 바이너리 패치**입니다. 이미 수정된 v28/v29 폴더에 덧붙이는 패치가 아닙니다. 원본 v25를 새 폴더에 풀고 프로젝트 루트에서 다음처럼 확인 후 적용할 수 있습니다.

```bash
git apply --check --binary /path/to/pixel-faction-rpg-v30-ui-checkpoint.patch
git apply --binary /path/to/pixel-faction-rpg-v30-ui-checkpoint.patch
```

새 압축파일은 만들지 않았습니다. 누적 패치는 빌드 도구가 원본을 새로 풀어 적용한 뒤 모든 파일의 내용·경로·실행 권한을 비교하도록 구성했습니다. 결과는 동봉 manifest에 기록됩니다.

프로젝트의 `docs/ui-v30/DESIGN.md`에 디자인 규칙·구현 파일·아트 출처를, `docs/v30-validation-summary.json`에 최신 검증 결과를 기록했습니다. 그래픽 실행이 가능한 환경에서는 `tools/ui/CaptureScreens.gd`로 실제 화면 캡처를 다시 실행할 수 있습니다.
