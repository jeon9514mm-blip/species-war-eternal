# v21 UI 업그레이드

## 목표
- 전반적인 화면 완성도 향상
- 핵심 화면의 정보 구조를 더 빠르게 이해할 수 있게 개선
- 자동사냥/성장/전쟁 루프를 한눈에 연결하는 대시보드형 UX 강화

## 이번 변경

### 1. 공통 UI 스타일 정리
- 배경에 은은한 격자 라인과 좌우 글로우를 추가해 픽셀 전쟁 세계관 분위기 강화
- 공통 헤더 함수 `_add_screen_header()` 추가
- 핵심 지표 카드 함수 `_create_metric_card()` 추가
- 대시보드형 카드 배치 함수 `_add_status_dashboard()` 추가

### 2. 로비 화면 업그레이드
- 상단에 공통 헤더/진영·재화 표시 통합
- 편성 인원, 전투력, 추천 사냥터, 미수령 보상을 한 번에 보는 4칸 대시보드 추가
- 오른쪽 액션 패널을 `빠른 출격 허브`로 정리하여 사냥/성장/소환/월드맵/종의전쟁 진입성 향상

### 3. 영웅 편성 화면 업그레이드
- 편성 현황/예상 전투력/장비 창고/영웅 풀 현황을 상단 요약 카드로 표시
- 장비 인벤토리와 성장 연구 버튼을 상단 퀵 액션으로 분리
- 원정대 편성 정보를 더 읽기 쉽게 재배치

### 4. 소환 화면 업그레이드
- 보유 젬, 천장 진행, 돌파 준비, 파티 연계 상태를 상단 카드로 요약
- 소환/도감 액션 위치를 위로 끌어올려 접근성 개선

### 5. 하단 내비게이션 업그레이드
- 아이콘형 텍스트(⌂, ⚔, ✦, ♜, ⬆, ✧) 적용
- 활성 탭 강조 색상 개선
- 보상/성장/소환 알림을 더 눈에 띄게 정리

## 기대 효과
- 첫 진입 시 로비에서 해야 할 행동을 더 빠르게 이해할 수 있음
- 영웅 편성과 성장 허브 진입 흐름이 더 자연스러워짐
- 방치형 RPG 특유의 `수치 확인 → 빠른 결정 → 즉시 출격` 템포 강화
