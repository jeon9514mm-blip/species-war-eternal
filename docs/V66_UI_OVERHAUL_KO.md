# v66 세로형 UI 개편

Godot 4.7.2용 **전체 프로젝트 ZIP**입니다. 기존 프로젝트 위에 압축을 덮어쓰기보다 새 폴더에 풀어 `project.godot`을 여세요. APK와 개인 저장 데이터는 포함하지 않습니다.

## 달라진 화면

- 상단 헤더의 제목 공간과 자원 표시를 정리하고, 카드의 색상·테두리·그림자·간격을 화면 전체에 일관되게 적용했습니다.
- 하단 주요 메뉴에서 현재 위치를 금색으로 표시하며, 사냥 HUD의 정보 패널과 메뉴 색상을 통일했습니다.
- 목록을 버튼 위에서 손가락으로 움직일 때 중복으로 스크롤 위치를 바꾸던 예약 입력을 제거했습니다. Godot 기본 터치 스크롤과 관성을 사용합니다.
- 캠프에서 현재 사냥터와 권장 전투력을 나눠 표시하고, 장비 가방에 조작 안내를 추가했습니다.
- 수호신 소환 화면에서 장착 수호신 설명·효과를 분리하고, 도감에 전체·보유·미보유·등급별 필터를 추가했습니다.
- 실시간 레이드 전장과 상태 카드의 경계·대비를 정리하고, 모험 메뉴의 제목과 설정 영역을 읽기 쉽게 배치했습니다.

게임 규칙, 장비·거래소 데이터, 영웅 편성, 레이드 진행과 기존 저장 형식은 이번 UI 변경에서 수정하지 않았습니다.

## 검증과 제한

Godot 4.7.2에서 프로젝트 가져오기 및 스크립트 파싱을 확인했습니다. 720×1280, 720×1560, 810×1440 등의 세로 화면 상태를 순회하는 `V49PortraitLayoutSmokeTest.gd` 22,025/22,025, 메뉴 동작의 `V30UiFlowSmokeTest.gd` 966/966, 장비 상세의 `V55EquipmentDetailUiSmokeTest.gd` 4,017/4,017, 레이드의 `V64RealtimeRaidSmokeTest.gd` 33/33, 수호신의 `V65GuardianSmokeTest.gd` 25/25, 품질 검사의 `V57QualityPassSmokeTest.gd` 36/36, 도감 필터의 `V66UiFilterSmokeTest.gd` 6/6 검사를 통과했습니다. 기기별 실제 손가락 스와이프와 저사양 휴대폰 프레임 성능은 기기에서 추가 확인이 필요합니다.
