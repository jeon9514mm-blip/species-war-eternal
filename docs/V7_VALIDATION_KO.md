   - 이제 일반 전투와 레이드 모두 최저 HP 생존 영웅을 기준으로 힐 여부를 결정합니다.

4. 다른 진영의 편성 프리셋을 적용할 때 현재 편성이 빈 상태로 덮일 수 있는 상황 방지
5. 저장된 전투 배속 값을 x1/x2/x3 중 하나로 정규화
6. README의 v6 표기와 잘못된/누락된 v7 문서 안내 정리

## 실제 Godot 실행 검증

프로젝트는 Godot 4.5.1 기준입니다. 현재 작업 환경에는 Godot 실행 파일이 기본 설치되어 있지 않고 외부 바이너리 다운로드도 허용되지 않아, 이번 세션에서는 엔진 import와 headless 전체 테스트를 직접 실행하지 못했습니다.

Godot 4.5.1이 설치된 PC에서는 아래 명령으로 전체 테스트를 실행할 수 있습니다.

```bash
python tools/run_tests.py --godot /path/to/Godot_v4.5.1-stable_linux.x86_64 --output docs/v7-test-results.json
```

특히 `V7SystemsSmokeTest.gd`는 10인 대형, 궁극기, 편성 프리셋, 전투 배속, 전열 사거리, 암살형 타깃 AI, 도발 우선순위, 진영 동료, 레이드 위기 힐 판단, 녹스페라 동료의 레이드 흡혈 지원, 기절/피격 함수 분리를 확인합니다.
