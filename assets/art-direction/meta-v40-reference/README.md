# Meta v40 품질 자료 반영

2026-10-07 사용자가 제공한 [화면 품질 분석](https://www.meta.ai/share/a/4b623bd9-a889-4edf-8ab2-fd76a2dcde5c)과 [Godot v40 ZIP 설명](https://www.meta.ai/share/a/ad4912aa-13aa-495c-953b-9f2716e23580)을 읽고 현재 3D 사냥·레이드에 적용했습니다. 내려받은 ZIP은 [source.zip](source.zip), URL·SHA-256·내용 목록은 [SOURCE.json](SOURCE.json)에 보존합니다.

ZIP의 실제 내용은 `Quality_Fix_Godot_v40.gd`와 `Circle_Moss_Bronze.gdshader` 두 파일입니다. 설명에 나온 돌 PBR 셰이더, Trail/HitParticles 장면, Outfit 폰트, 룬 이미지, Breathing 스크립트는 들어 있지 않습니다. 샘플은 Camera2D·Heroes·Monsters·TileMap을 전제로 하므로 현재 Camera3D·SubViewport·전신 원화 구조에 맞춰 필요한 동작을 구현했습니다.

검수 이미지에서 변화가 작다는 사용자 피드백 후 돌바닥 밝기를 더 낮추고 원화 테두리를 0.8 화면 픽셀 기준으로 강화했습니다. 룬은 발광만으로 표시하지 않고 이끼·청동색 표면 색도 함께 넣어 흰색 번짐을 줄였습니다. 영웅 그림의 관절·크기·동작은 유지합니다. 그림 자산과 제작 흐름 자체를 개선하는 [Godot 그래픽 조사](../../../docs/GODOT_GRAPHICS_WORKFLOW_2026_10_07_KO.md)와 현재 코드 수정은 구분합니다.

추가 YouTube 자막 조사에서 확인한 알파 잘라내기·방향광 그림자 방식을 실제 사냥 원화 메시에도 연결했습니다. 몸 전체의 현재 실루엣이 돌바닥에 방향광 그림자를 드리우며 기존 발밑 접지 그림자를 보완합니다. 절전·이펙트 끄기에서는 이 추가 그림자를 끕니다. 2D 그림 배경인 레이드는 기존 접지 그림자를 유지합니다.

숫자는 등장 0.09초, 유지 0.30초(치명타 0.34초), 이동·소멸 0.30초를 사용합니다. 제안의 1.45배 확대·48px 상승 대신 현재 10인 전투에서 읽기 쉽고 서로 겹치지 않는 범위를 적용했습니다. 무기·투사체·타격점 높이는 혼잡 배율을 반영한 실제 원화 높이에 맞춥니다.

원본 그림 해상도를 8K·32K로 복원하거나 NeRF 모델을 추가한 작업은 아닙니다. ZIP의 '100% 작동', '60fps', 'AAA' 표현을 검증 결과로 사용하지 않습니다. 1.5배 슈퍼샘플링은 3D 픽셀 수가 2.25배이므로 Android 실기기 성능은 별도 검증이 필요합니다. [실행 검사와 화면](../../../checks/meta-v40-2026-10-07/README.md)을 확인하세요.
