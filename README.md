## 비주얼 개편 시범 실행

Godot에서 아래 장면을 열고 **F6**로 실행합니다. 프로젝트의 기본 실행 장면과 기존 운영 코드는 유지합니다.

- `scenes/art/ArtDirectionLab.tscn`: 실제 기존 8방향 자동사냥을 새 초원에서 실행합니다. `원래 맵과 비교`로 같은 전투의 원래 맵을 보고, `영웅 원화 보기`로 새 레온하르트 시안을 엽니다. 몬스터 4종은 새 8자세 원화로 표시하며 `몬스터 시안 보기`에서 크게 비교합니다. 영웅은 기존 그림·골격을 사용하고 레온하르트의 보폭·접지·윤곽을 보강했습니다.
- `scenes/art/MonsterConceptStudy.tscn`: 초원 몬스터 4종의 대기·이동·공격·피격·사망을 선택하고 재생·정지합니다.
- `scenes/art/HeroConceptStudy.tscn`: 기존·신규 레온하르트 원화를 확대·축소 크기로 비교합니다. 새 그림은 **4등신 안팎 SD 원화 시안**이며 분리 파트나 완성된 신규 애니메이션이 아닙니다.

시범의 진행·설정은 메모리에만 남고 기본 저장본을 읽거나 쓰지 않습니다. 레이드 메뉴까지 둘러본 경우 보고서만 `user://art-direction-lab/raid-reports.json`에 분리 저장합니다. 일반 F6 실행에 별도 환경 변수 설정은 필요하지 않습니다. 자동 검증 스크립트는 별도의 폐기 가능한 `XDG_DATA_HOME`이 필요합니다.

원화와 초원 바닥 이미지는 이번에 AI로 생성한 시범 자산이며 [출처·상태](assets/art-direction/pilot-01/ART_SOURCE.json)를 기록했습니다. 원화·맵 검토 → 31개 부위 분리 → 핵심 6동작 → 16종 동작 → 대표 4인 → 전체 30명 순으로 이어갑니다. [시범 범위·제한·검증 기록](docs/ART_DIRECTION_PILOT_KO.md)을 확인하세요.

## 현재 구현

- 15–20마리 부대가 접근하고, 잔여 적 5마리 이하·최소 4게임초 뒤 다음 부대 진입
- 동시에 최대 2부대·생존 적 25마리, 진형 4종과 실제 능력치 버프
- 가로 전용 화면과 창 크기 변경 시 전투 상태 보존
- 저장·획득·보관함·거래까지 같은 기준을 사용하는 장비 가방 200칸
- 현재 장비·후보 비교 카드, 중앙 작업 버튼, 오른쪽 4열 장비 목록
- 좌측 영웅 목록·세로 탭, 중앙 원본 캐릭터와 골격 대기 동작, 우측 실제 성장 정보
- 하단 영웅 화면과 별도 파티 편성, `☰`의 그림 카드 6개·기능 아이콘 12개
- 얼음 동굴·엘프 유적·협곡·숲의 실제 3D 맵
- 기본 사냥터: 빙하 심연 전장
- 살아 있는 부대를 따라가는 전투 중심 카메라와 `전장 보기` 전환
- 캐릭터 크기·피아 발밑 표시·피격색 연결, 필요한 체력 막대만 표시
- 가로 레이드 전투 영역 확대와 공격 경고·터치 위치 정렬 유지
- 레이드 3종 HP·공격력·권장 전투력 10배, 3열 선택 카드와 실제 회피·스킬 준비 표시
- 이미 획득한 보호 보관 장비의 개수 초과 저장복원 손실 방지

`scenes/MapGallery.tscn`을 열어 **F6**를 누르면 네 맵을 확인할 수 있습니다. 1–4로 전환하고 드래그로 회전, 휠로 확대합니다. 전장은 입체 지형이며 문양 이미지는 개별 표면 재질입니다. 영웅은 21관절 골격과 GPU 스키닝으로, 몬스터는 Sprite3D 프레임 애니메이션으로 표시합니다.

## 작업 보존과 검사

Git 태그 `v83-6.2`는 3D 맵 적용 전 기준, `v83-6.3`은 이전 3D 맵 통합 보관본입니다. v83-6.4는 그 위에 전투 화면 개선을 적용합니다. 기존 파일의 이력은 Git으로 보존합니다. 원본 v83-6.1 분석·복원 뒤 진행한 변경 내용은 저장소의 문서와 과거 기록에 남아 있습니다.

이번 영웅·몬스터 시범은 변경 관련 스크립트 **9/9개**, 새 표시 검사 1,218개와 기존 시범 회귀 412개를 합해 **1,630/1,630항목**을 통과했습니다. 실제 화면 8장과 12.58초 실행 영상은 [이번 검증 파일](checks/hero-monster-pilot/regression.json)에 기록했습니다. 아래 숫자는 이전 레이드 단계의 기록이며 이번 시범에서 전체 검사를 다시 실행한 합계가 아닙니다.

이전 레이드 품질 작업은 스크립트 **405/405개**, 현재 선택 회귀 **22/22종**, 숫자로 집계한 **17,405개 검사**를 통과했고 실제 렌더 **13장**을 확인했습니다. 이 합계에는 레이드 강화 비교 442항목이 포함됩니다. 숫자 카운터가 없는 전투 조작 검사도 별도로 통과했습니다. [현재 검증 결과와 구형 검사 제외 사유](docs/RAID_STRENGTH_QUALITY_KO.md)를 확인하세요.

이전 영웅·전체 메뉴 작업은 스크립트 **398개**, 선택 회귀 **15종·18,975개 검사**를 통과했습니다. 영웅 성장·장비·연구·편성 복귀, 메뉴 입력 차단과 창 크기 변경을 확인하고 실제 렌더 **15장**을 남겼습니다. [이전 영웅·메뉴 기록](docs/HERO_MENU_UX_KO.md)을 확인하세요.

이전 가로 장비 작업은 스크립트 **393개**, 선택 회귀 **17종**을 통과했습니다. 200칸 경계·저장복원·실제 버튼 입력과 창 크기 변경을 검사했고 실제 렌더 **10장**을 확인했습니다. [이전 장비 검증 범위](docs/LANDSCAPE_EQUIPMENT_KO.md)를 확인하세요.

이전 [전투 품질 검증](checks/combat-quality/regression.json)은 스크립트388개와 선택 회귀18종을 포함합니다. [v83-6.4 검증](checks/v83-6-4/validation.json)과 [화면 비교](docs/V83_6_4_COMBAT_VIEW_KO.md)는 이전 단계 기록입니다.

이전 검증 기록은 [v83-6.2](checks/v83-6-2/validation-summary.json)와 [v83-6.3](checks/v83-6-3/validation.json)에 있습니다. v83-6.3의 선택된 전투·맵 검사 538개는 통과했습니다. 이는 모든 과거 테스트를 실행했다는 뜻은 아닙니다. v67 지형 진단의 기존 실패 8개는 이전 버전에서도 동일하게 재현되어 별도 기록했습니다.

Android 실기기 성능·발열과 장기 밸런스 검증은 남아 있습니다. 이번 변경에서 온라인 기능은 개발하지 않았습니다. 현재 상태는 개발 작업본이며 APK 배포본이 아닙니다.
