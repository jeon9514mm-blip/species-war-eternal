# 사냥 AI·몸체 간격·성장 UX 개선 (2026-10-05)

영웅과 몬스터가 좁은 접촉 자리에 쌓이던 사냥을 개선했다. 영웅은 동료가 예약한 공격 자리를 피하고, 양 진영의 실제 몸체 간격을 이동 단계에서 보정한다. 사거리, 장애물, 추적 범위와 준비 중인 공격을 함께 고려한다.

## 적용한 동작

- `HuntPositionPlanner`: 실제 사거리 안의 공격 자리 후보를 동료의 현재 위치와 예약한 목적지에 맞춰 평가한다. 원거리는 위협에서 벗어날 위치를 우선한다. 준비 중인 영웅은 고정하고 이동하는 동료가 비켜선다.
- `HuntBodyCollision`: 영웅끼리 1.14, 몬스터끼리 1.12, 근접 교전 상대끼리 0.76 월드 단위 간격을 사용한다. 교전 간격은 암살자의 실제 0.82 사거리 안에 들어간다. 위치 보정은 이동 가능한 지형과 영웅의 역할별 추적 범위를 지킨다. 경계에서 정면으로 밀려 되돌아오는 경우 작은 측면 빈자리를 찾는다. 몸체가 겹친 상태에서는 새 공격 준비를 시작하지 않는다. 이미 준비 중이거나 기절한 캐릭터는 밀지 않는다. 빈 측면 자리도 없으면 이전의 겹치지 않는 프레임 위치를 유지한다. 이때 막힌 이동은 이동 거리나 패시브 보상에 더하지 않는다.
- 사냥 시작 시 영웅을 펼쳐 배치한다. 화면의 사냥 영웅 높이는 2.25→1.55, 몬스터는 1.75→1.20으로 조정해 큰 이미지가 인접 배우를 가리는 정도를 줄였다. 레이드의 기존 배우 크기는 별도 분기대로 유지된다.
- `HuntDamageReservations`: 가까운 시점에 이미 준비된 공격의 보수적인 예상 피해를 합산해, 처치가 예상되는 일반 적 대신 공격 가능한 다른 적을 선택한다. 정예 집중, 마무리형 AI와 같은 적 콤보는 유지한다. RNG·실제 HP·재화는 예측에서 변경하지 않는다. 준비된 공격의 타깃이 사망하거나 사거리에서 벗어나면 기존 규칙대로 취소하며 다른 적에게 순간 이동시키지 않는다.
- 몬스터의 원거리·지원 접근 거리와 후퇴 문턱, 공격 후 짧은 정지 시간을 구분했다. 근접 영웅만 남은 경우 실제 영웅 사거리로 접근 거리를 제한해 대치 상태를 방지한다.
- 사냥터 정보에 최근 약 120 게임초의 실제 처치/분·지급 골드/분·재정비 시간 비율을 표시한다. 편성 또는 지역 변경 시 측정 창을 초기화한다. 화면 밖에서 계속되는 사냥도 같은 계산을 쓴다. 배속에 따라 숫자가 부풀려지지 않으며 이 기록은 저장 보상 계산에 사용하지 않는다.
- 일괄 강화는 골드 25%·50%·현재 골드 예산, 장비 수·정확한 총비용·남은 골드를 먼저 보여준다. 확인 시 장비와 재화를 재검증하고 장착 아이템의 전체 데이터와 레거시 레벨을 함께 업데이트한다. 취소·중복 확인·바뀐 장비/재화·저장 복구 대기는 추가 지출을 만들지 않는다.
- 절전은 전장 3D 해상도를 반으로 줄이고 MSAA·그림자·일부 후처리를 줄인다. 가방 등에서 보관된 사냥 전장은 렌더링을 중단하며 사냥 계산은 유지한다. 복귀 시 렌더링을 재개하고 일반 모드에서 원래 조명/환경 설정을 복구한다. 환경 리소스 자체만 복제해 다른 전장의 옵션을 변경하지 않는다. 축소된 렌더 좌표와 실제 터치 좌표의 변환을 함께 보정했다.

## Main.gd 작업 범위

사용자 요청에 따라 기존 Main.gd의 전체 분리/재설계는 보류했다. 이번 신규 기능은 별도 모듈에 두었고 Main에는 타깃 예측, 몸체 확인, 효율 기록 및 강화 확인창을 연결하는 부분만 추가했다. 기존 저장·보상·전투 코드의 대규모 이동은 하지 않았다.

## 검사와 실제 화면

선택한 24개 회귀 검사 중 22개(9,026개 검증 항목)가 통과했다. 충돌 마지막 보정 후 관련 8개 검사를 다시 실행했다. 신규 검사에서는 양 진영/교전 상대 분리, 준비 중 배우 고정, 중복 피해 예측, 실제 강화 터치 확인, 예산/전체 아이템 업데이트/취소/중복 확인, 지역 변경 시 효율 초기화, 절전의 조명 복구/좌표 변환/재화·HP·RNG 보존을 확인했다.

아래 두 기존 검사는 변경하지 않은 기준 커밋에서도 동일하게 실패했다. 이 작업의 전체 검사가 모두 통과했다고 표현하지 않는다.

- `CombatQualitySmokeTest`: 이전 레이드의 큰 회피 버튼 크기 기대. 현재 레이드 디자인/터치 회귀는 별도로 통과.
- `V82PresentationUiSmokeTest`: 복원된 메뉴에 이전 `PortraitMenuScroll` 구조 기대. 설정 버튼은 유지되지만 이 이전 구조 검사는 기준에서도 실패.

`IndependentHuntSmokeTest`는 레벨 60 영웅의 몬스터 피격 검증을 1스테이지 대신 154스테이지에서 진행한다. 약한 적을 무피격으로 처치하는 결과로 몬스터의 공격 가능성을 판단하지 않기 위해서다. 여러 부대 처치·어그로 분산·실제 HP 감소 조건을 유지했다. `HuntAttackQualitySmokeTest`의 몬스터 공격 준비 검증은 몸체가 겹치지 않는 0.84 접촉 거리로 옮기고, 기절 직전에 실제 공격 준비에 진입했는지도 추가 확인했다.

Godot 4.6.3, Linux headless와 OpenGL/llvmpipe 실제 렌더를 사용했다. 실제 휴대폰의 발열·FPS·장시간 프레임 안정성은 측정하지 않았다. 기존 릴리스 엔진과 모바일 실기기 검증은 출시 전에 필요하다. 선택한 검사 범위 밖의 알려진 구버전 검사 전체를 이번 변경으로 해결했다는 주장도 하지 않는다.
