## 조작과 상태 보존

- 사냥의 `HuntPartyEdit`, `PortraitAutoButton`, `PortraitSpeedButton`, `PortraitDetailsButton`은 기존 편성·일시정지/재개·배속·설정을 실행합니다. `HuntOptionsClose`로 닫을 수 있고 Tab은 설정 창 안에 머물며 Escape는 이전 조작으로 초점을 돌려줍니다.
- 영웅의 `HeroRoster_*`, `HeroTab_*`, `HeroDeployAction`, `HeroGear_*`, 성장·승급·돌파 명령은 실제 영웅 데이터와 기존 비용/잠금 조건을 사용합니다. 긴 이름은 말줄임과 전체 이름 툴팁으로 처리합니다.
- 레이드의 `PortraitRaidStart`, `PortraitRaidDodge`, `PortraitRaidCastSkill`, `PortraitRaidCastUltimate`, `RaidOptionsButton`은 기존 기능을 유지합니다. 전장 뷰포트·투영·공격 예고·바닥 터치 좌표와 128×108 이상의 영웅 선택 영역을 보존했습니다.
- 진형의 `Formation_*`, `FormationClose`는 기존 선택 규칙을 사용합니다. 모달을 열거나 닫고 영웅을 선택하는 UI 동작은 HP·쿨다운·위치·재화·전리품 RNG를 바꾸지 않습니다. 실제 진형을 선택할 때에는 기존 진형 규칙을 그대로 적용합니다.

화면 교체 중 남아 있는 GPU 스킬 풀도 유효한 게임 호스트를 확인한 후 처리하도록 보완했습니다. 호스트가 없거나 교체 중이면 방출을 멈춰 메뉴 이동 시 잘못된 객체에 접근하지 않습니다.

## 캡처 조건

이미지는 생성 목업이 아니라 게임에서 렌더링한 픽셀입니다. [전투 캡처 조건](battle/capture-fixture.json)과 [영웅 캡처 설명](heroes/README.md)에 별도 검수 상태를 기록했습니다. 사냥/레이드는 스테이지 154·영웅 Lv.60·골드 49,000·보석 840, 영웅 메뉴는 스테이지 60·Lv.25 등 임시 값을 사용하며 사용자 저장 파일을 사용하지 않습니다. 전투 사진의 시각 효과와 소리는 UI 가독성 검수에서만 껐습니다.

재현 도구는 [CaptureBattleUi.gd](../../tools/diagnostics/ui-polish-2026-10-08/CaptureBattleUi.gd)와 [CaptureHeroUi.gd](../../tools/diagnostics/ui-polish-2026-10-08/CaptureHeroUi.gd)입니다. 1280×720 사진 9장과 960×540 사진 1장을 제공하며 영웅 상세 스크롤과 레이드 영웅 가로 스크롤로 나머지 내용에 접근합니다.

최종 사진에서는 진형 패널과 하단 안내가 화면 안에 들어오고, 레이드 진행 사진은 진입 셔터 애니메이션 종료 후 전체 전장과 네 가지 조작을 표시하는 것을 확인했습니다.

이번 기록은 UI와 조작 검수입니다. 새 FPS·메모리 벤치마크를 수행하거나 기존의 성능 수치를 이번 UI 변경의 측정 결과로 주장하지 않습니다.
