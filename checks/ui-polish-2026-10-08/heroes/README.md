영웅 메뉴 디자인 검수
=====================

Godot 4.7.2 Mobile 렌더러에서 실제 메뉴를 캡처했습니다. 논리 화면은 1280 × 720입니다.

- `hero-growth.png`: 레온하르트의 원화, 실제 계산된 전투 능력치, 경험치와 연구.
- `hero-skills.png`: 미라의 기존 스킬 이름·설명·재사용 시간·아이콘.
- `hero-equipment.png`: 미라가 장착한 실제 장비와 비교·교체 경로.
- `hero-noxfera-skills.png`: 다른 진영인 녹스페라의 발레리아 스킬 화면.

왼쪽 목록에는 이름과 레벨을 함께 표시하고, 선택한 영웅의 전체 이름은 오른쪽에 표시합니다. 원화는 가운데 크게 유지했습니다. 성장·스킬·장비·승급 탭은 상세 정보 바로 위에 모았으며 출전 여부와 잠금 상태는 기존 게임 상태를 사용합니다.

검수 화면은 별도 임시 저장 파일을 사용하는 예시 편성입니다. 골드 48,260, 보석 1,280, 레이드 정수 240, 스테이지 60과 레벨 25는 검수용 값이며 사용자 저장 파일을 변경하지 않습니다. 원화·스킬·장비 데이터와 가격·조건·연구·돌파 명령은 기존 구현을 그대로 사용합니다.

재현 도구: `tools/diagnostics/ui-polish-2026-10-08/CaptureHeroUi.gd`.
캡처 로그는 `HERO_UI_CAPTURE_OK`, 종료 코드는 0입니다. 이 이미지는 배치·색상·가독성 검수용이며 터치 입력과 성장 상태 검증은 기존 `HeroMenuUxSmokeTest.gd`, `HuntMenuStateSmokeTest.gd`에서 별도로 수행합니다.
