# 영웅 스킬 이펙트 삭제

2026-10-07 사용자 요청: “스킬이펙트 다삭제해”. 신규 효과 제작은 폐기하고 기존 효과도 제거했습니다.

- 30명 영웅의 A1·A2·패시브·궁극기 그래픽, 역할별 섬광, 스킬 잔상, 추가 타격 스파크·카메라 연출, 궁극기 컷인을 제거했습니다.
- 기존 `HeroSkillEffect`·`PortraitSkillBurst` 구현과 생성 경로를 삭제했습니다. 새로 작업하던 효과·제작 도구·시안은 게임 저장소에 포함하지 않았습니다.
- 스킬 피해·회복·보호막·상태 이상·쿨다운·게이지와 자동 시전 판단은 변경하지 않았습니다. 원화 공격 동작, 일반 피격 피드백·대미지 숫자·보스 위험 경고·음성은 유지합니다.
- 과거 그래픽 생성 함수는 게임 시전 코드와의 호환을 위해 빈 진입점으로 남겼습니다. 효과 설정이 켜진 저장 데이터를 불러와도 영웅 스킬 그래픽은 생성하지 않습니다.
- 과거 검수 이미지는 당시 작업 기록이며 현재 화면을 나타내지 않습니다.

검증 결과는 같은 폴더의 JSON에 기록합니다. 기존 이펙트 생성 기대치를 삭제 요구에 맞게 바꾼 회귀 검사와 실제 전투 상태 비교를 함께 실행합니다.


## 검증 결과

- 변경·신규 GDScript 10/10개 Godot 구문 검사 통과. 삭제 파일은 리소스 검색 대상에서 없어졌습니다.
- 집중 회귀 7/7개 통과: 효과 미생성, 30명 실제 시전 비교, 전체 스킬 키트, 기존 전투 표시, 효과 예산, 이전 시선·크기 수정, 레이드 디자인.
- 실제 Mobile/Vulkan GPU에서 사냥·레이드의 120개 스킬 진입점씩과 보스 위험 경고 250항목을 확인했습니다. 영웅 스킬 추가 그래픽 노드·투사체·범위 표시·컷인은 생성되지 않습니다.
- 실제 키트 시전 180개, 기존 Main A1 진입점 60개, 성공한 패시브 30개를 효과 설정 ON/OFF로 비교했습니다. 피해와 전투 상태가 같았습니다.
- 정적 리소스·링크 검사 통과: GDScript 495개, 회귀 진입점 233개.
- 과거 V62·V63 검사는 각각 154/155, 16/20으로 실패합니다. 삭제 이전 `bfbf1dd`의 원본 소스와 원본 검사를 다시 실행했으며 동일한 UI·보상 기대치 5개가 실패했습니다. 새로운 실패는 없습니다. 관련 기대치를 임의로 통과시키지 않았으며 [현재 결과](legacy.json)와 [기준 결과](legacy-baseline.json)를 보존합니다.
