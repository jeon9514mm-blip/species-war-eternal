# 검증·디자인 검토 자료

이 폴더는 **선별한 결과 JSON, 실제 Godot 화면, 검토 영상**을 보관합니다. 파일의 날짜·엔진·검사 범위는 해당 JSON 또는 기능 문서를 확인하세요. 옛 버전의 화면은 현재 디자인을 뜻하지 않습니다.

- `rune-stone-applied/`: 현재 돌바닥·발광 룬의 실제 Mobile·Forward+ 화면과 관련 회귀 결과.
- `source-cleanup/`: 소스 경로 정리의 실행 결과.
- `aurelia-*`, `hero-*`: 영웅 원화·관절·동작 검토 자료.
- 다른 기능별 폴더: 해당 작업 당시의 비교 화면·검증 수치.

재생성 가능한 원시 로그와 캡처 임포트 메타데이터를 이번 정리에서 제거했습니다. 이전 파일은 Git 이력에서 확인할 수 있으며 선별한 이미지·영상·결과 JSON은 유지합니다. 원시 로그·프레임·중간 렌더가 다시 쌓이지 않도록 `.gitignore`를 적용합니다.

새 검사 결과는 작업별 하위 폴더에 생성하고 필요한 결과·대표 화면만 검토 후 커밋하세요. 실행 가능한 검사는 `tests/`, 진단 도구는 `tools/diagnostics/`에 둡니다. `checks/.gdignore`는 이 폴더가 게임용 이미지·스크립트로 임포트되는 것을 막습니다.
