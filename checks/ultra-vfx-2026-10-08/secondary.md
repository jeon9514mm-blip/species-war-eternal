# 영웅·몬스터 보조 움직임 — 2026-10-08

영웅 30명의 기존 원화를 유지하면서 실제 Blender GLB의 헤어 카드를 300개에서 **600개 / 1200 삼각형**으로 다시 제작했다. 기본 영웅 드로우는 몸 6000 + 헤어 1200 = **7200 삼각형**이다. 별도로 몸 3000 + 헤어 600 = **3600 삼각형**의 실제 LOD 메시도 넣었다. 파일에는 양쪽 LOD가 함께 있지만 한 영웅은 선택한 LOD만 그린다. 화면 키 86.4px, 발 기준점, 원화 비율, 좌우 전환, 공격 프레임과 공격 앵커는 그대로 유지한다.

원화와 런타임 1024 아틀라스는 재작성하지 않았다. `tools/validate_ultra_actor_assets.py`가 30명 모두의 GLB 인덱스 개수를 직접 읽고, 기존 Git HEAD의 두 프레임 트랙/앵커와 현 아틀라스 SHA-256을 확인한다. 결과는 [actor-assets.json](actor-assets.json)에 있다. 전용 Blender 원본은 `assets/mobile25d/source/mobile25d-ultra-heroes.blend`이며 이전 전체 라이브러리와 바닥 파일을 덮어쓰지 않는다.

영웅 표현은 검은 3px / 60% 외곽선, 호흡 2.5px, Rim 25%, SSS 0.25, 그림의 어두운 부분에 약한 재질 AO를 사용한다. Hair는 별도의 실제 메시이며 Wind 0.15, Clump 0.3, Frizz 0.1, native anisotropy와 그림자 캐스트 설정을 쓴다. Forward+에서 SSS를 직접 사용하고 Mobile에서는 소량의 따뜻한 방출광으로 근사한다. 머리카드의 아래 중앙 영역을 잘라 얼굴 위에 헤어가 덮이지 않게 한다. 광원 그림자가 비활성인 실행 설정에서는 헤어 그림자를 별도로 그리지 않는다.

망토는 **고정된 뿌리 + 4개 움직이는 제어점**의 5점 체인이다. Wind 0.12, Stiffness 0.12, Damping 0.88, 길이 제약 3회, 작은 몸통 캡슐 충돌과 비인접 점의 자기 충돌을 적용한다. 원화의 망토 영역을 변형하는 제한된 2.5D 스트립 모델이며, 메시 전체의 천 표면·삼각형 충돌을 계산하는 완전한 cloth simulation은 아니다. 점 변위는 2.6px 안으로 제한하고, 일시정지·타격 정지에서는 기존 전투 시계를 따라 고정한다.

몬스터는 6개 실제 native MultiMesh 셸 인스턴스, Fur Wind 0.15 / Clump 0.3 / Frizz 0.1을 사용한다. 여섯 인스턴스는 한 재질·메시·Geometry 노드로 그리며, `INSTANCE_CUSTOM.r`에 저장한 서로 다른 1/6–1의 깊이 값으로 각각의 털을 만든다. LOD는 실제 `visible_instance_count`를 6/3/0으로 바꾸고, 죽음과 효과 끄기는 드로우 자체를 숨긴다. 영웅에는 중복 몬스터 fur Geometry 노드가 없으며 실제 hair 카드만 사용한다. 분리 25px, 정렬 15%, 응집 8%, 저체력 회피 40px, 성격 유지 시간 1–8초를 적용한다. 실제 공격 사거리 안에서는 군집 이동이 공격을 취소하거나 계속 원을 돌게 만들지 않는다. 성격 변경 시 50%의 독립된 RNG 확률로 기존 4종 몬스터 음원을 재생하며, 공동 8음성 예산 안의 `AudioStreamPlayer3D`를 사용한다. 통합 단계에서 실제 HP 비율을 전달하면 상처 표식이 생기며, 죽을 때는 기존 완전 원화의 사망 프레임과 필드의 소멸 연출을 유지한다. 몬스터의 솜털 자체는 작은 투명 셸이며 별도 물리 털/광원 그림자 시뮬레이션은 하지 않는다.

`MobileReliefPilot.secondary_lod`는 0: 전체, 1: 절반 메시/3 fur 셸/헤어 광원 그림자 끄기, 2: 보조 바람·망토 정지, 3: 헤어·fur 숨김을 제공한다. 실제 공격 원화의 시간과 영웅 키는 모든 LOD에서 유지한다. 필드가 거리와 배터리 옵션을 판단해 이 값을 지정한다. 만약 이 값이 지정되지 않으면 전체 상세를 그린다.

통합 후속: 실제 원화 잔상 5개를 native MultiMesh 인스턴스 풀로 미리 할당해 **한 드로우**로 0.40초 동안 재사용한다. 인스턴스별 위치와 `INSTANCE_CUSTOM.r`의 알파를 갱신하고, 공유된 원화·UV·앵커는 실제 타격 프레임의 값을 보관한다. LOD 잔상은 선택된 낮은 몸 메시를 사용하며, 원래 픽셀 좌표가 들어 있는 이전 원화 메시에는 잘못된 unit-mesh 변환을 하지 않는다. 일시정지 때는 위치·알파가 함께 멈춘다. 일반 타격은 40개 입자 경로를 한 캔버스 배치로 그리고, 크리티컬 보조 입자 20개와 레벨업 입자 20개도 각각 배치한다. 타격 최대 12개·레벨업 최대 4개·2D 대체 잔상 최대 50개의 예산을 유지한다. 카메라는 호흡 10초 / 3px, 일반·크리티컬 흔들림 5 / 10px, 최대 줌 펀치 1.15를 사용하며 레이드 바닥 투영과 터치 역변환이 안정적으로 유지되도록 실제 카메라 roll은 추가하지 않는다. 접촉 그림자는 70%로 진하게 조정했다.

궁극기만 `ContactTimeDilation.request_ultra()`를 호출해 0.08배 / 최대 180ms의 벽시계 연출을 요청할 수 있다. 연속 궁극기는 3초 간격으로 제한하고, 짧은 크리티컬 슬로우모션 위에 곱해서 중첩하지 않는다. 일반 크리티컬은 기존 0.15배 / 80ms / 1.5초 간격을 유지한다. `ContactScreenFlash.flash_ultra(color)`는 필드에만 180ms / 최대 알파 0.18을 3초 간격으로 적용하며, 일반 크리티컬 플래시는 기존 50ms / 알파 0.12다. 일시정지·비활성·효과 끄기·노드 종료 시 슬로우모션의 이전 엔진 시간을 복원하고 필드 플래시를 지운다.

재제작: `Blender --background --factory-startup --python tools/build_mobile25d.py -- --actors-only`.
